Broadcast के दौरान phone असल में करता क्या है

नीचे लिखी हर चीज़ वही है जो SplitCam Remote वाक़ई करता है और जो documentation में दर्ज है — यह इस बात की wishlist नहीं कि एक control surface सैद्धांतिक रूप से क्या-क्या कर सकता है.

Scenes अपने हाथ से switch कीजिए

जिसकी वजह से ज़्यादातर लोगों को control surface की ज़रूरत पड़ती है. Camera बदलिए, layout बदलिए, slides पर cut कीजिए — बिना computer तक वापस जाए और बिना full-screen game के पीछे छिपी window ढूँढे.

Stream और recording शुरू और बंद कीजिए

Live जाइए, broadcast ख़त्म कीजिए, recording शुरू या बंद कीजिए, snapshot लीजिए, pause या mute कीजिए — ठीक वो काम, ठीक उसी पल, जब keyboard की तरफ़ हाथ बढ़ाना आपके audience को सबसे ज़्यादा दिखता है.

देखिए कि असल में हो क्या रहा है

App आपकी stream का नाम और status वापस आपके हाथ में दिखाता है, इसलिए कमरे के दूसरे छोर से भी आप अंदाज़ा लगाने के बजाय जान सकते हैं कि आप live हैं या नहीं.

सेकंडों में pair, और आपके ही network पर

SplitCam Settings के Remote Control tab पर दिख रहा QR code scan कीजिए, या app को Wi-Fi पर ख़ुद अपना PC ढूँढने दीजिए. QR वाला रास्ता दोनों devices का परिचय कराने के लिए हमारे servers से होकर जाता है; Wi-Fi discovery सब कुछ आपके ही network पर रखती है.

Hardware के बिना यह करना क्यों सही है

Phone के हक़ में बात यह नहीं कि वो सस्ता है. बात यह है कि इस काम के लिए वो कमतर नहीं है.

Buttons पहले से आपकी जेब में हैं

एक control surface की जगह तभी बनती है जब camera से नज़र हटाए बिना उस तक हाथ पहुँच जाए. Keyboard के बगल में टिका phone उतना ही पास है जितना keys का box — और उसके पैसे आपने अलग से दिए ही नहीं.

Labels आपकी scenes के साथ बदलते हैं

Physical keys पर legends आपको ख़ुद set करने पड़ते हैं. Screen आपकी मौजूदा scene list वैसी ही दिखाती है जैसी वो है, इसलिए किसी scene का नाम बदलने पर button पर कोई पुराना label नहीं रह जाता.

Stage पर बिगड़ने को एक चीज़ कम

एक USB device कम, एक cable कम, और कमरा बदलते या setup किसी venue पर ले जाते वक़्त एक चीज़ कम जिसे unplug करना पड़े.

आपको Stream Deck ही कब ख़रीदना चाहिए

अपने आप से ईमानदार रहिए कि आप दबाना क्या चाहते हैं. अगर आपके buttons को SplitCam के बाहर कुछ भी करना है — कोई OBS scene चलानी है, किसी दूसरे app से sound effect बजाना है, कोई macro चलाना है, lights धीमी करनी हैं, Discord mute करना है, chat में link paste करना है — तो सही tool Stream Deck ही है और phone app उसकी जगह नहीं ले सकता, क्योंकि SplitCam Remote सिर्फ़ SplitCam को control करता है, और कुछ नहीं. यही बात तब भी लागू है जब आपको ऐसी tactile keys चाहिए जिन्हें देखे बिना दबाया जा सके, एक हमेशा जगा रहने वाला surface चाहिए जो stream के बीच न सोए और न कोई call ले ले, या हर key पर अपनी जलती हुई screen चाहिए. और अगर आप Android पर हैं, तो companion app अभी release नहीं हुआ है, इसलिए इन दोनों में से आज आपके लिए सिर्फ़ hardware ही काम करता है. यह कोई छोटी list नहीं है — Stream Deck एक अच्छा product है, और बहुत सारे लोगों के पास वो होना ही चाहिए.

पहले से Stream Deck है? उसे जोड़ने का तरीक़ा यह है

SplitCam का official plugin Elgato Marketplace पर है. यह free है, सिर्फ़ Windows के लिए है, और चल रहे app से सीधे बात करता है — न कोई port, न password, न pairing.

1. SplitCam update कीजिए

Stream Deck support Windows build 10.8.25 (जनवरी 2025) में आया था. उससे नया कुछ भी चलेगा; मौजूदा release ठीक है.

2. Plugin install कीजिए

Stream Deck app (6.9 या नया) में Marketplace खोलिए और SplitCam खोजिए, या सीधे listing से install कीजिए. इसे SplitCam ने ही publish किया है, किसी third party ने नहीं.

3. Keys पर actions रखिए

Stream शुरू/बंद, scene switch, recording शुरू/बंद, scene pause, mute और snapshot. Scenes के नाम SplitCam से लिए जाते हैं, इसलिए key पर वही scene दिखती है जिस पर वो switch करती है; keys SplitCam का live status और आपका session time भी दिखाती हैं.

4. चाहें तो chain कीजिए

ये actions Multi Actions के अंदर भी चलते हैं, इसलिए एक बार दबाने से scene switch हो सकती है, stream शुरू हो सकता है और उस key पर जो कुछ और रखा है वो भी चल सकता है. SplitCam के channel पर एक setup walkthrough है.

Plugin क्या नहीं करता: यह macOS पर नहीं चलता — Mac पर किसी control surface से scenes switch करने का रास्ता iPhone पर free SplitCam Remote app है. इसमें dial support नहीं है और इसके साथ कोई profiles नहीं आते. इन छह actions से आगे किसी भी चीज़ के लिए मौजूदा listing देखिए, जिसमें plugin की अपनी version history है.

Stream Deck alternative — अक्सर पूछे जाने वाले सवाल

क्या SplitCam Remote वाक़ई free है?

हाँ. यह SplitCam का companion app है, और SplitCam ख़ुद free है — कोई watermark नहीं और कोई paid tier नहीं. इन दोनों में unlock करने को कुछ है ही नहीं.

क्या यह Stream Deck की जगह पूरी तरह ले सकता है?

सिर्फ़ तब, जब आप जो कुछ दबाते हैं वो सब SplitCam का ही हो. यह scenes switch करता है, streaming और recording शुरू और बंद करता है, snapshots लेता है और mute करता है — पर दूसरे applications में buttons नहीं दबा सकता. अगर आपका workflow कई programs में फैला है, तो hardware ख़रीद लीजिए.

क्या इसका Android version है?

अभी नहीं. SplitCam Remote iOS के लिए App Store पर मौजूद है, और Android version अभी बन रहा है.

मेरे पास पहले से एक Stream Deck है. क्या SplitCam उसके साथ काम करता है?

हाँ, Windows पर. Elgato Marketplace से free official SplitCam plugin install कीजिए (Stream Deck app 6.9 या नया) और SplitCam को 10.8.25 या उसके बाद के version पर update कीजिए. Keys पर stream शुरू/बंद, scene switch, recording शुरू/बंद, scene pause, mute और snapshot मिलते हैं, और वे SplitCam का live status दिखाती हैं. Plugin का macOS version नहीं है.

Phone मेरा computer ढूँढता कैसे है?

या तो SplitCam Settings के Remote Control tab पर दिख रहा QR code scan कीजिए, या app को Wi-Fi पर अपने आप आपका PC ढूँढने दीजिए. दोनों चलते हैं; पहली बार QR code ज़्यादा तेज़ पड़ता है.

क्या connection आपके servers से होकर जाता है?

Phone का आपके computer से परिचय कराने के लिए pairing SplitCam के servers से होकर जाती है. सिर्फ़ यही handshake वहाँ से गुज़रता है — एक बार दोनों एक-दूसरे को ढूँढ लें, उसके बाद control traffic आपके अपने दोनों devices के बीच ही चलता है.
