◆ setDataCallback()

void splitcam::plugin::setDataCallback ( splitcam::plugin::IImageSource::DataCallback  cb,
void *  param 
)

SplitCam calls this function to set the callback used for passing images from the plugin back to SplitCam. Every time this function is called the image displayed on the screen by this plugin will be updated with a new one. It is important to pass the param parameter unchanged in every call to the callback function.

Parameters
cbCallback function to update the source instance image
paramSplitCam set parameter that must be passed back unchanged in a call to callback function
