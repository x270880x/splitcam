สำหรับโบสถ์

โปรแกรมสตรีมสำหรับโบสถ์ ฟรี — ถ่ายทอดพิธีวันอาทิตย์ไปทุกแพลตฟอร์ม

ถ่ายทอดสดไปยัง Facebook + YouTube + เว็บไซต์โบสถ์ พร้อมกัน สลับฉากแบบหลายกล้อง คำบรรยายล่างสำหรับผู้เทศน์ และโอเวอร์เลย์เนื้อเพลง ไม่มีค่าสมาชิก ไม่มีลายน้ำ ไม่จำกัดจำนวนผู้ชม ใช้กับพีซีหรือแล็ปท็อปที่โบสถ์มีอยู่แล้วได้เลย

สรุปสั้น ๆ — ถ่ายทอดพิธีนมัสการฟรีใน 5 ขั้นตอน
SplitCam เป็นซอฟต์แวร์ฟรีที่ถ่ายทอดพิธีวันอาทิตย์ไปยัง Facebook Live, YouTube Live และปลายทาง RTMP ของเว็บไซต์โบสถ์พร้อมกัน วิธีตั้งค่า:
  1. ติดตั้ง SplitCam บนพีซีในห้องควบคุมเสียง (Windows หรือ macOS)
  2. เพิ่มกล้อง เป็นเลเยอร์ของฉาก — ภาพมุมกว้าง แท่นเทศน์ วงนมัสการ
  3. ต่อเสียง จากมิกเซอร์ของโบสถ์ผ่านออดิโออินเทอร์เฟซ USB
  4. เพิ่ม Browser Source สำหรับคำบรรยายล่างและเนื้อเพลง (เอาต์พุตเครือข่ายของ ProPresenter ใช้ได้)
  5. วาง stream key ของแต่ละแพลตฟอร์ม → กด\"ไลฟ์สด\" สตรีมจะส่งไปทุกแพลตฟอร์มพร้อมกัน

ถ่ายทอดสดพิธีวันอาทิตย์ — ทีละขั้นตอน

การติดตั้งระบบสตรีมสำหรับโบสถ์แบบครบชุดใช้เวลาราว 10 นาทีในครั้งแรก เมื่อตั้งค่าเสร็จแล้ว วันอาทิตย์ถัด ๆ ไปก็แค่คลิกเดียวก็ไลฟ์สด ขั้นตอนเดียวกันนี้ใช้ได้ไม่ว่าคุณจะใช้กล้องตัวเดียวหรือสี่ตัว

1
ติดตั้ง SplitCam บนพีซีในห้องควบคุมเสียง ~ 2 นาที

ติดตั้ง SplitCam บนแล็ปท็อปของโบสถ์ที่ใช้แสดงสไลด์ หรือเครื่องในห้องควบคุม AV โดยโปรแกรมทำงานบน Windows 10/11 และ macOS 11+ ฟรี ไม่ต้องสมัครบัญชี ไม่จำกัดเวลาการถ่ายทอด และไม่เคยประทับลายน้ำลงบนภาพ

ทำไม\"ฟรี\"จึงสำคัญสำหรับโบสถ์: ตัวเลือกแบบเสียเงินส่วนใหญ่ (vMix, Resi, BoxCast) ราคา $60–$500 ต่อเดือน หรือ $1,200 จ่ายครั้งเดียว งบเท่านั้นเอาไปซื้อกล้องตัวที่สองหรือชุดไมค์ไร้สายได้เลย
2
เพิ่มกล้องเป็นเลเยอร์ของฉาก ~ 3 นาที

เสียบกล้องแต่ละตัวเข้ากับพีซีแล้วเพิ่มเป็นแหล่งสัญญาณ SplitCam รองรับ:

• เว็บแคม USB — Logitech C920 / Brio ราคาต่ำกว่า $200
• DSLR และกล้องวิดีโอ ผ่านการ์ดแคปเชอร์ HDMI (Elgato Cam Link 4K, ~$130)
• โทรศัพท์ เป็นมุมเสริมผ่าน Wi-Fi โดยใช้แอป SplitCam สำหรับ iOS / Android
• วิดีโอที่อัดไว้ล่วงหน้า เป็นแหล่งสัญญาณ (คลิปเปิด วิดีโอพิธีบัพติศมา ประกาศ)

จัดฉากสำหรับแต่ละช็อตที่คุณต้องการ: ภาพมุมกว้าง, แท่นเทศน์, วงนมัสการ, สไลด์เนื้อเพลง, เดี๋ยวกลับมา สลับด้วยปุ่ม F1–F5 ระหว่างพิธี

เคล็ดลับ: วางสไลด์เนื้อเพลงไว้ในฉากแยกต่างหาก แทนที่จะโอเวอร์เลย์ค้างไว้ตลอด ผู้ควบคุมการถ่ายทอดจะสลับไปฉากนั้นเมื่อเริ่มนมัสการ แล้วสลับกลับมาที่กล้องแท่นเทศน์เมื่อศิษยาภิบาลพูด เหมือนกับการใช้โปรเจกเตอร์ในห้อง
3
ต่อเสียงจากมิกเซอร์ ~ 2 นาที

นี่คือจุดที่ยกระดับคุณภาพได้มากที่สุด เสียงของการถ่ายทอดควรเป็น สัญญาณเสียงหลังมิกซ์ จากมิกเซอร์ของโบสถ์ ไม่ใช่ไมโครโฟนในตัวของพีซีที่รับเสียงก้องในห้อง

ใช้ออดิโออินเทอร์เฟซ USB (Behringer UMC22 ~$50, Focusrite Scarlett Solo ~$120) เพื่อป้อนสัญญาณ aux/monitor จากมิกเซอร์เข้าสู่พีซี แล้วเลือกอินเทอร์เฟซ USB ตัวนั้นเป็นแหล่งเสียงใน SplitCam ทุกอย่างที่ผู้ร่วมพิธีได้ยิน ทั้งคำเทศนา วงนมัสการ และออร์แกน คือสิ่งที่ผู้ชมทางไกลได้ยิน

เสียงสำคัญกว่าภาพ ผู้ชมยอมรับภาพศิษยาภิบาลที่ 720p ได้ แต่จะทนเสียงที่อู้อี้และดังแผ่ว ๆ ไม่ได้ ทุ่มงบกับเสียงก่อนจะคิดถึงกล้องตัวที่สี่
4
เพิ่มคำบรรยายล่างและเนื้อเพลง ~ 2 นาที

คำบรรยายล่างของผู้เทศน์: เพิ่มแหล่งข้อความที่มีชื่อศิษยาภิบาลและหัวข้อคำเทศนา วางไว้มุมล่างซ้าย เปิด/ปิดการแสดงผลแยกตามฉาก แสดงเมื่ออยู่ที่ช็อตแท่นเทศน์ ซ่อนระหว่างนมัสการ

เนื้อเพลง: ใส่ Browser Source ที่โหลดหน้าเว็บเนื้อเพลงของคุณ ถ้าโบสถ์ใช้ ProPresenter ให้เปิดเอาต์พุต Network → Web URL แล้วป้อนที่อยู่นั้นให้ SplitCam เนื้อเพลงจะปรากฏในการถ่ายทอดพร้อมกับที่ผู้นำนมัสการเลื่อนสไลด์ ส่วน OpenLP ฟรีก็ทำงานแบบเดียวกันผ่าน URL หน้าจอแสดงผลบนเวที

เรื่องลิขสิทธิ์: การสตรีมเนื้อเพลงบน Facebook / YouTube ต้องมีใบอนุญาตสตรีม เช่น CCLI Streaming License (โดยทั่วไป $50–$300 ต่อปี) ใบอนุญาตครอบคลุมแพลตฟอร์ม ไม่เกี่ยวกับตัวซอฟต์แวร์
5
มัลติสตรีมไปยัง Facebook + YouTube + เว็บไซต์โบสถ์ ~ 1 นาที

เปิด Stream Settings แล้วติ๊กแพลตฟอร์มที่ต้องการ:

• Facebook Live — วาง stream key จากเพจ Facebook ของคุณ → Live Producer
• YouTube Live — วาง stream key จาก studio.youtube.com → Go Live → Stream
• เว็บไซต์โบสถ์ — วาง RTMP URL + key ของคุณเอง (Wowza, Vimeo, AWS IVS หรือ Nginx-RTMP ที่โฮสต์เอง)
• แพลตฟอร์มอื่น ๆ — Twitch, Kick, X/Twitter และปลายทางที่ตั้งค่าไว้ล่วงหน้ากว่า 84 แห่ง

กด \"ไลฟ์สด\" ครั้งเดียว ทุกแพลตฟอร์มจะได้รับการถ่ายทอดพร้อมกัน สตรีมส่ง ตรงแบบ peer-to-peer จากพีซีของคุณไปยังเซิร์ฟเวอร์รับสัญญาณของแต่ละแพลตฟอร์ม ไม่มีตัวกลางบนคลาวด์ ไม่มีค่ารายเดือน ไม่มีค่าใช้จ่ายต่อผู้ชม

ซ้อมใหญ่วันเสาร์: ลองสตรีมทดสอบเต็มรูปแบบ 30 นาทีในวันเสาร์ โดยตั้งความเป็นส่วนตัวเป็น \"ไม่แสดงต่อสาธารณะ\" หรือ \"เฉพาะฉัน\" ตรวจสอบระดับเสียง การจัดเฟรมกล้อง และโอเวอร์เลย์เนื้อเพลง วันอาทิตย์แรกที่ไลฟ์สดไม่ใช่เวลาที่จะมาพบว่าไมค์เปิดค้างหรือยังปิดฝาเลนส์อยู่
ทำไมมัลติสตรีมจึงสำคัญสำหรับโบสถ์

สมาชิกแต่ละคนดูบนแพลตฟอร์มต่างกัน ผู้สูงอายุ คลิกลิงก์บนเว็บไซต์โบสถ์ ลูก ๆ ที่โตแล้ว ซึ่งไปเยี่ยมพ่อแม่ดูผ่าน Facebook Live คนรุ่นใหม่ ดูบน YouTube ส่วน ผู้ที่ออกจากบ้านไม่สะดวก ก็เปิดอะไรก็ตามที่เปิดได้เร็วที่สุดบนแท็บเล็ต

เลือกแพลตฟอร์มเดียว คุณก็เสียที่เหลือไป SplitCam สตรีมไปยังทุกแพลตฟอร์ม พร้อมกัน แบบ peer-to-peer และฟรี ใช้แทน Restream $19/เดือน และ StreamYard $25/เดือนได้

ดูวิธีการทำงานของมัลติสตรีม

โบสถ์ต้องใช้ฮาร์ดแวร์อะไรบ้าง?

สามระดับแบบตรงไปตรงมา เริ่มจาก\"ขั้นต่ำ\"แล้วค่อยขยายเมื่อผู้ชมการถ่ายทอดของคุณเพิ่มขึ้น

ขั้นต่ำ — ~$0–$200

กล้องเดียว เสียงจากมิกเซอร์

  • แล็ปท็อปของโบสถ์ที่มีอยู่ (Intel i5 + 8 GB)
  • เว็บแคม USB หนึ่งตัว (Logitech C920, $80)
  • ออดิโออินเทอร์เฟซ USB จากมิกเซอร์ ($50)
  • สตรีม 720p ฉากเดียว
แนะนำ — ~$500

สองกล้อง โอเวอร์เลย์เนื้อเพลง มัลติสตรีม

  • พีซีแยกต่างหาก (Intel i5 รุ่นที่ 8 ขึ้นไป, 16 GB)
  • สองกล้อง (เว็บแคม + DSLR ผ่าน Cam Link)
  • ออดิโออินเทอร์เฟซ USB จากมิกเซอร์
  • สตรีม 1080p สลับฉาก เนื้อเพลงจาก ProPresenter
หลายกล้อง — ~$1,500

สามกล้อง + พีซีสตรีมแยกต่างหาก

  • พีซีสตรีม (i7 / Ryzen 7, 16 GB, การ์ดจอ NVENC)
  • 3 กล้อง (มุมกว้าง / แท่นเทศน์ / วงนมัสการ)
  • การ์ดแคปเชอร์หลายช่อง
  • หลายกล้อง 1080p 60fps คลิปไฮไลต์รีเพลย์

เคล็ดลับจากโบสถ์ที่สตรีมทุกวันอาทิตย์

รายละเอียดเล็ก ๆ ที่ทำให้การถ่ายทอดดูเป็นมืออาชีพแทนที่จะดูสมัครเล่น

🎤 เริ่มด้วยการปิดเสียงเสมอ

เริ่มทุกสตรีมด้วยไมค์ที่ปิดเสียงและสไลด์ค้างไว้ว่า \"ยินดีต้อนรับ — พิธีเริ่ม 10:30 น.\" แล้วค่อยเปิดเสียงเมื่อพิธีเริ่มจริง เลี่ยงไม่ให้คนที่เข้ามาก่อนได้ยินคำว่า \"ใช้ได้ไหมนะ?\"

📺 ต่อสายอีเทอร์เน็ตที่พีซี

Wi-Fi หลุดกลางพิธีทำให้การถ่ายทอดพังได้ เดินสายอีเทอร์เน็ตไปที่ห้องควบคุมเสียง สายยาว 8 เมตรราคา $10 เป็นการอัปเกรดความเสถียรที่ถูกที่สุด

🎬 สร้างฉาก \"คั่นเวลา\"

ฉาก 1: \"พิธีเริ่ม 10:30 น.\" พร้อมเพลง ฉาก 2: \"กำลังร้องเพลง — ร่วมกับเรา\" ระหว่างนมัสการ ฉาก 3: แท่นเทศน์ระหว่างคำเทศนา ฉาก 4: \"ขอบคุณที่ร่วมพิธี — สัปดาห์หน้า 10:30 น.\"

📊 มอบหมายให้คนหนึ่งดูสถิติ

ตัวอ่านค่าสดของ SplitCam รายงานภาระตัวเข้ารหัสและสถานะการเชื่อมต่อตลอดพิธี ถ้าตัวบ่งชี้เป็นสีแดง ให้ลดบิตเรตลง อย่าปล่อยให้การถ่ายทอดที่คุณภาพตกดำเนินไปตลอดคำเทศนา

📝 ซ้อมใหญ่ในวันเสาร์

ทุกวันเสาร์แรก — ซ้อมใหญ่เต็มรูปแบบของสตรีมพิธีในวันรุ่งขึ้น 30 นาที ตั้งความเป็นส่วนตัวเป็น \"ไม่แสดงต่อสาธารณะ\" ช่วยเค้นปัญหาให้โผล่ออกมาก่อนจะออกอากาศจริง

⛪ เคารพใบอนุญาต CCLI

คำถามที่พบบ่อยเกี่ยวกับสตรีมโบสถ์

โปรแกรมสตรีมสำหรับโบสถ์ฟรีที่ดีที่สุดคืออะไร?

SplitCam เป็นหนึ่งในตัวเลือกฟรีที่ดีที่สุดสำหรับโบสถ์ มีมัลติสตรีมในตัวไปยัง Facebook + YouTube + เว็บไซต์โบสถ์พร้อมกัน สลับฉากแบบหลายกล้อง คำบรรยายล่างและเนื้อเพลงผ่าน Browser Source ไม่มีลายน้ำ ไม่มีค่าสมาชิก OBS Studio ก็ฟรีเช่นกัน แต่ต้องใช้ปลั๊กอินสำหรับมัลติสตรีม และเรียนรู้ยากกว่าสำหรับอาสาสมัครที่ควบคุม

ฉันสตรีมพิธีวันอาทิตย์ไปยัง Facebook และ YouTube พร้อมกันได้ไหม?

ได้ — SplitCam มีมัลติสตรีมในตัว วาง stream key ของ Facebook Live และ YouTube Live กด\"ไลฟ์สด\" ครั้งเดียว ทั้งสองแพลตฟอร์มก็ได้รับการถ่ายทอดพร้อมกัน และยังส่งไปยังเว็บไซต์โบสถ์ของคุณเองผ่าน RTMP ได้ในเวลาเดียวกัน สตรีมส่งตรงแบบ peer-to-peer จากพีซีของโบสถ์ ไม่มีตัวกลางบนคลาวด์ ไม่มีค่ารายเดือน ดูรายละเอียดมัลติสตรีม

โปรแกรมสตรีมสำหรับโบสถ์ราคาเท่าไหร่?

SplitCam ฟรี 100% ไม่มีลายน้ำ ไม่จำกัดเวลา ตัวเลือกแบบเสียเงิน: vMix Basic HD $60 จ่ายครั้งเดียว (จำกัด 4 อินพุต ไม่มีมัลติสตรีม), vMix Pro $1,200 จ่ายครั้งเดียว (ฟีเจอร์ครบ), ProPresenter $499+ (เน้นงานนมัสการ ไม่ใช่ตัวเข้ารหัสสตรีมเต็มรูปแบบ), Resi $99–$249/เดือน (บนคลาวด์), BoxCast $99–$499/เดือน

ฉันต้องใช้พีซีแยกต่างหากสำหรับสตรีมพิธีวันอาทิตย์ไหม?

ไม่จำเป็น — SplitCam ทำงานบนพีซีเครื่องเดียวกับที่ใช้แสดงสไลด์โปรเจกเตอร์หรือ ProPresenter ได้ ตราบใดที่เครื่องมี CPU/GPU เหลือพอ (แนะนำ Intel i5 รุ่นที่ 8 ขึ้นไป, RAM 16 GB) สำหรับการตั้งค่าหลายกล้องตั้งแต่ 3 ตัวขึ้นไปที่ 1080p แนะนำให้ใช้พีซีสตรีมแยกต่างหาก เพื่อเลี่ยงเฟรมตก

ฉันจะเพิ่มเนื้อเพลงลงในการถ่ายทอดสดของโบสถ์ได้อย่างไร?

เพิ่ม Browser Source ใน SplitCam ที่ชี้ไปยังหน้าเนื้อเพลงของคุณ ถ้าคุณใช้ ProPresenter ให้เปิดเอาต์พุต Network → Web URL ของมัน แล้วชี้ Browser Source ของ SplitCam ไปยัง URL นั้น ถ้าคุณใช้ OpenLP หรือตัวเลือกฟรีอื่น ให้ชี้ไปยัง URL หน้าจอแสดงผลบนเวที เนื้อเพลงจะปรากฏสดในสตรีมขณะที่ทีมนมัสการเลื่อนสไลด์ หมายเหตุ: การสตรีมเนื้อเพลงที่มีลิขสิทธิ์ต้องมี CCLI Streaming License

ฉันใช้กล้องหลายตัวสำหรับสตรีมของโบสถ์ได้ไหม?

ได้ — SplitCam รองรับกล้องไม่จำกัดจำนวนเป็นแหล่งสัญญาณของฉาก เสียบกล้องแต่ละตัวเข้ากับพีซี (เว็บแคม USB, DSLR ผ่านการ์ดแคปเชอร์ HDMI อย่าง Elgato Cam Link หรือโทรศัพท์ที่รันแอป SplitCam เป็นมุมไร้สายเสริม) จัดฉากสำหรับภาพมุมกว้าง ภาพระยะใกล้ที่แท่นเทศน์ วงนมัสการ และสไลด์เนื้อเพลง สลับระหว่างฉากด้วยปุ่มลัด (F1, F2, F3...) ระหว่างพิธี

SplitCam ใช้งานบนคอมพิวเตอร์โบสถ์รุ่นเก่าได้ไหม?

SplitCam ทำงานบน Windows 10/11 และ macOS 11+ ด้วยความต้องการฮาร์ดแวร์ไม่สูง สำหรับสตรีมหลายกล้องที่ 1080p เครื่อง Intel i5 รุ่นที่ 8 หรือ Ryzen 5 พร้อม RAM 16 GB ก็สบาย ๆ สำหรับสตรีมกล้องเดียวที่ 720p แล็ปท็อปรุ่นเก่ากว่าที่ใช้ i3 / RAM 8 GB ก็พอใช้ได้ การเข้ารหัสด้วยฮาร์ดแวร์ (NVENC / QuickSync / AMF) ช่วยลดภาระจาก CPU

SplitCam เสถียรพอสำหรับพิธีวันอาทิตย์แบบสดไหม?

เสถียร — SplitCam พัฒนาอย่างต่อเนื่องมาตั้งแต่ปี 2003 และมีโบสถ์กับผู้แพร่ภาพทั่วโลกใช้งาน ตัวเข้ารหัสใช้การเร่งความเร็วด้วยฮาร์ดแวร์เพื่อความเสถียร ตัวตรวจสอบสถานะแสดงเฟรมที่ตกแบบเรียลไทม์ และระบบมัลติสตรีมเป็นแบบ peer-to-peer (ถ้าแพลตฟอร์มหนึ่งล่ม ก็ไม่ดึงตัวอื่นล่มตาม) ลองซ้อมใหญ่ในวันเสาร์ก่อนไลฟ์สดวันอาทิตย์ครั้งแรกของคุณ
