SplitCam/การใช้งาน/ครูผู้สอน
For Educators

ตั้งค่าการสอนออนไลน์ — สไลด์และใบหน้าของคุณในภาพกล้องเดียว

ทุกสิ่งที่คุณแสดง — สไลด์หนึ่งหน้า แอปพลิเคชัน ภาพวาด หรือเว็บแคมของคุณ — จะอยู่บนภาพเดียวกัน ซ้อนกันเป็นชั้น ๆ SplitCam เรียกแต่ละอย่างว่าเลเยอร์ แล้วส่งภาพที่ประกอบเสร็จไปยังแอปประชุมของคุณในฐานะกล้องธรรมดา: Zoom, Google Meet, Microsoft Teams และแอปกว่า 60+ ตัวจะเห็นมันในเมนูเลือกกล้อง ชั้นเรียนของคุณเห็นทั้งตัวคุณและเนื้อหาไปพร้อมกัน และขั้นตอนแชร์หน้าจอ เลิกแชร์ ถามว่า "ทุกคนเห็นไหม?" ก็เลิกเป็นส่วนหนึ่งของบทเรียน

คำตอบเร็ว ๆ — การตั้งค่าการสอนออนไลน์ประกอบกันอย่างไร
  1. ติดตั้ง SplitCam บนคอมพิวเตอร์ที่คุณใช้สอน — ฝั่งปลายทางของบทเรียนไม่เปลี่ยนแปลงเลยแม้แต่น้อย
  2. ลากเนื้อหาของบทเรียนลงบนฉาก: ไฟล์ PDF หน้าจอหรือหน้าต่าง โฟลเดอร์รูปภาพ หรือเว็บแคมของคุณ
  3. ปรับขนาดให้เป็นแบบที่ชั้นเรียนจะเห็น — เนื้อหาใหญ่ เว็บแคมอยู่มุมที่คุณไม่เคยเขียนทับ
  4. บันทึกการจัดวางแต่ละแบบเป็นฉาก — บรรยาย ตัวอย่างการแก้โจทย์ การสาธิต — แล้วสลับฉากขณะที่คุณสอน
  5. เลือก "SplitCam Camera" เป็นกล้องในแอปประชุมของคุณ

วิธีตั้งค่าการสอนออนไลน์ทีละขั้นตอน

นี่คือเลเยอร์ที่ควรรู้จักสำหรับการสอน บางเลเยอร์มีอยู่บนแพลตฟอร์มเดียวเท่านั้น จึงมีการระบุแพลตฟอร์มไว้บนทุกการ์ด — ให้ความสำคัญกับป้ายกำกับนี้อย่างจริงจัง เพราะช่วงเวลาที่แย่ที่สุดในการพบว่าขาดแหล่งสัญญาณคือกลางคาบเรียน

1
ติดตั้ง SplitCam — เฉพาะบนเครื่องที่ใช้สอนเท่านั้น ~ 2 นาที

SplitCam ติดตั้งบนคอมพิวเตอร์ที่คุณใช้สอนอยู่แล้ว — Windows 10 หรือ 11 หรือ macOS 13 ขึ้นไป — และเพิ่มกล้องอีกหนึ่งตัวเข้ากับกล้องที่ระบบของคุณมีอยู่แล้ว ครึ่งที่สำคัญของเรื่องนี้คือครึ่งที่ไม่เปลี่ยนแปลง: นักเรียนของคุณเปิดลิงก์ประชุมเดิม ในแอปเดิม บนอุปกรณ์เดิม และไม่มีใครถูกบอกว่ามีอะไรต่างไป หากเครื่องที่ใช้สอนถูกดูแลโดยคนอื่น พวกเขาจะต้องรันตัวติดตั้งให้คุณ

2
นำเนื้อหาที่คุณเตรียมไว้แล้วเข้ามา ~ 4 นาที

บทเรียนมีอยู่แล้วที่ไหนสักแห่งบนดิสก์ของคุณ: งานนำเสนอที่คุณส่งออก ใบงานที่คุณสแกน เว็บไซต์ที่คุณตั้งใจจะสาธิต หรือโฟลเดอร์รูปถ่าย ลากไฟล์ลงบนฉากได้เลย แล้วมันจะกลายเป็นเลเยอร์ สิ่งที่เปลี่ยนการสอนคือทุกอย่างสามารถแสดงพร้อมกันได้ในคราวเดียวแทนที่จะทีละอย่าง — คุณเลิกต้องเลือกว่าจะให้ชั้นเรียนเห็นเพียงสิ่งเดียว เพิ่มครั้งเดียวแล้วมันยังอยู่ที่นั่นในเทอมหน้า การ์ดถัดลงไปด้านล่างครอบคลุมแต่ละประเภทและระบุแพลตฟอร์มที่มันอยู่ บน Windows ให้เพิ่มแหล่งสัญญาณ Application Audio ด้วยหากคุณวางแผนจะเปิดคลิป เพื่อให้เสียงของคลิปไปถึงชั้นเรียนพร้อมกับไมโครโฟนของคุณ

3
ทำให้เนื้อหาใหญ่และตัวคุณเล็ก ~ 2 นาที

ลากเนื้อหาจนเต็มเฟรมเกือบทั้งหมด แล้ววางเว็บแคมของคุณไว้ในมุมที่คุณจะไม่เขียนทับ — มุมขวาล่างสำหรับคนส่วนใหญ่ ตอนนี้ลองประเมินแบบที่ชั้นเรียนจะเห็น: ไม่ว่าคุณแสดงอะไร มันจะไปปรากฏที่ปลายทางในกรอบเล็ก ๆ ขนาดราวโปสการ์ด บนแล็ปท็อปหรือบนโทรศัพท์ที่ถือห่างระยะแขน หากคุณอ่านป้ายกำกับแกนกราฟของตัวเองที่ขนาดนั้นไม่ออก ก็ไม่มีใครอ่านออก บน Windows คุณยังขยายทั้งภาพได้ด้วย — ชี้ไปที่รายละเอียดแล้วหมุนลูกกลิ้งเมาส์โดยไม่เลือกเลเยอร์ใด คลิกไอคอน Lock ข้างเว็บแคมของคุณในรายการสื่อก่อน แล้วมันจะอยู่กับที่ในขณะที่ทุกอย่างอื่นขยายขึ้น

4
บันทึกการจัดวาง แล้วเปลี่ยนโดยไม่ต้องหยุด ~ 1 นาที

จัดวางเลเยอร์เพียงครั้งเดียว แล้วบันทึกการจัดวางนั้นเป็นฉากในรายการฉาก และเพิ่มหนึ่งฉากต่อสิ่งที่คุณทำจริง ๆ — มุมมองบรรยาย มุมมองตัวอย่างการแก้โจทย์ มุมมองการสาธิต การสลับคือการคลิกที่ฉากที่คุณต้องการ หรือปุ่มลัดหนึ่งปุ่มต่อหนึ่งฉาก เพื่อให้คุณเปลี่ยนเลย์เอาต์ได้โดยไม่ต้องเอื้อมไปหยิบเมาส์ สิ่งที่สำคัญคือมันดูเป็นอย่างไรจากที่นั่งของนักเรียน: เนื้อหาเปลี่ยน แต่ภาพยังคงขนาดและรูปทรงเดิมเหมือนเมื่อวินาทีก่อน และกล้องไม่เคยดับ ไม่มีใครเห็นกรอบดำ ๆ และคุณไม่ต้องพูดว่า "ขอหยุดแชร์ก่อนนะ" อีกต่อไป

5
เลือก SplitCam Camera ใน Zoom, Meet หรือ Teams ~ 1 นาที

เปิดการตั้งค่ากล้องในแอปประชุมของคุณ แล้วเลือก "SplitCam Camera" จากรายการเดียวกับที่เว็บแคมของคุณอยู่ — ใน Zoom และ Google Meet มันอยู่ใต้ Settings → Video ส่วนใน Microsoft Teams อยู่ใต้ Settings → Devices มันปรากฏเป็นเว็บแคมธรรมดาในแอปกว่า 60+ ตัว โดยไม่ต้องใช้ปลั๊กอินและไม่ต้องเชื่อมต่อเฉพาะแต่ละแอป รายการเดียวกันนี้จึงใช้ได้กลางคาบ: สลับมาใช้หลังจากคาบเรียนเริ่มไปแล้วและภาพก็จะเปลี่ยนไปเฉย ๆ บน macOS กล้องเป็นส่วนขยายของระบบ ดังนั้น Mac จะขออนุญาตจากคุณในครั้งแรก

สิ่งที่คุณนำมาแสดงต่อหน้าชั้นเรียนออนไลน์ได้

ไฟล์ PDF ของสไลด์หรือใบงานของคุณ — Windows และ macOS

ส่งออกสไลด์ของคุณเป็น PDF หรือใช้ใบงานที่คุณมีอยู่แล้ว แล้วเพิ่มไฟล์เป็นเลเยอร์ PDF คุณพลิกหน้าภายในเลเยอร์ขณะที่บทเรียนดำเนินอยู่ ดังนั้นคำถามเกี่ยวกับหน้าสี่จึงตอบได้ที่หน้าสี่ทันที แทนที่จะต้องไล่หาผ่านเมนู

ชุดรูปภาพในรูปแบบสไลด์โชว์ — Windows และ macOS

เพิ่มเลเยอร์สไลด์โชว์แล้วใส่รูปภาพของคุณลงไป: จัดลำดับใหม่ ลบรูปที่ไม่ต้องการ เลื่อนภาพตามช่วงเวลาที่กำหนด วนซ้ำทั้งชุด และใช้ GIF เคลื่อนไหวในจุดที่การเคลื่อนไหวไม่กี่วินาทีอธิบายได้มากกว่าภาพนิ่ง บน macOS คุณยังลากรูปภาพตั้งแต่สามภาพขึ้นไปลงบนฉากได้โดยตรง แล้วเลเยอร์สไลด์โชว์จะสร้างขึ้นเอง

ไวท์บอร์ดสำหรับวาด — เฉพาะ Windows

เลเยอร์ที่คุณวาดด้วยมืออิสระด้วยเมาส์หรือแทร็กแพด; กด Shift ค้างไว้แล้วเส้นจะออกมาตรง และเลเยอร์นี้มีปุ่ม Undo, Redo และ Clear All วาดมืออิสระเป็นสิ่งเดียวที่มันทำได้ ซึ่งทำให้มันเป็นที่สำหรับแก้โจทย์ทีละขั้นต่อหน้าชั้นเรียน มากกว่าจะเป็นวิธีจำลองภาพที่พิมพ์ไว้ ตัว macOS ไม่มีฟีเจอร์นี้

หน้าจอของคุณ หน้าต่างเดียว หรือเฉพาะบางส่วน — Windows และ macOS

จับภาพทั้งหน้าจอ หน้าต่างแอปพลิเคชันเดียว หรือเฉพาะส่วนของหน้าจอที่สำคัญ ได้สูงสุดถึง 4K โดยแสดงเคอร์เซอร์ให้เห็น เพื่อให้ชั้นเรียนตามได้ว่าคุณกำลังชี้ตรงไหน บน Windows การจับภาพแบบ Full Screen ยังแสดงการคลิกเมาส์และการกดปุ่มของคุณได้ด้วย — ความต่างระหว่างการสาธิตซอฟต์แวร์ที่นักเรียนทำตามได้กับที่พวกเขาได้แต่มองดู

หน้าเว็บที่คุณคลิกโต้ตอบได้ — Windows และ macOS

เพิ่มเลเยอร์ Browser สำหรับสิ่งใดก็ตามที่อยู่ในเบราว์เซอร์: เครื่องมือทำสไลด์บนเว็บ เว็บวาดกราฟ หรือแบบจำลอง ดับเบิลคลิกที่เลเยอร์เพื่อเข้าสู่โหมดโต้ตอบ แล้วคุณจะคลิกและพิมพ์ในหน้าเว็บได้ขณะที่ชั้นเรียนกำลังดูอยู่ โดยไม่ต้องออกจาก SplitCam หรือเปิดหน้าต่างอื่น

โทรศัพท์ของคุณเป็นกล้องตัวที่สอง — Windows และ macOS

เพิ่มแหล่งสัญญาณ Phone Camera แล้วสแกน QR code ด้วยโทรศัพท์ของคุณ มันเชื่อมต่อผ่านเครือข่าย โดยไม่ต้องใช้สายและไม่ต้องมีฮาร์ดแวร์จับภาพ ดังนั้นคุณจึงเล็งไปที่หนังสือ แผนภาพที่พิมพ์ไว้ หรือวัตถุบนโต๊ะ แล้วสลับไปมุมนั้นได้เมื่อคำอธิบายต้องใช้ของจริง

ข้อความที่แปลตัวเองได้ — เฉพาะ Windows

เลเยอร์ข้อความเก็บชื่อเรื่อง คำสั่ง หรือคำสำคัญที่คุณพูดซ้ำ ๆ พร้อมสีของตัวเอง แผงพื้นหลังด้านหลัง และเส้นขอบรอบตัวอักษรเพื่อให้อ่านออกบนสไลด์ที่รก บน Windows มันยังแปลสิ่งที่คุณพิมพ์เป็นอีกภาษาโดยอัตโนมัติได้ ซึ่งน่ารู้ไว้หากส่วนหนึ่งของชั้นเรียนของคุณเรียนตามในภาษาที่สอง มันแปลข้อความที่พิมพ์ ไม่ใช่สิ่งที่คุณพูดออกมา

เลย์เอาต์บทเรียนสามแบบที่ควรบันทึกเป็นฉาก

ความอ่านง่ายคือหัวใจทั้งหมดของงานนี้ ทุกการจัดวางด้านล่างตัดสินด้วยคำถามเดียว — ตอนนี้ชั้นเรียนควรกำลังอ่านอะไร และมันใหญ่พอจะอ่านออกไหม? สร้างครั้งเดียว บันทึกแต่ละแบบเป็นฉาก แล้วที่เหลือของเทอมก็แค่กดปุ่ม

บรรยาย — สไลด์เต็มเฟรม

หน้า PDF หรือภาพสไลด์โชว์กินพื้นที่เกือบทั้งภาพ; เว็บแคมของคุณอยู่เล็ก ๆ ในมุม พ้นจากข้อความ ชั้นเรียนอ่านสไลด์ที่ขนาดใกล้เคียงกับการแชร์เต็มจอ และยังเห็นว่าใครกำลังพูดและคุณกำลังมองไปทางไหน

ตัวอย่างการแก้โจทย์ — กระดานเต็มเฟรม

บน Windows เลเยอร์ไวท์บอร์ดกินพื้นที่ทำงานและคุณเขียนลงไปขณะพูด เขียนให้ใหญ่กว่าที่รู้สึกว่าเป็นธรรมชาติสองหรือสามเท่า — คุณกำลังเขียนสำหรับกรอบเล็ก ไม่ใช่สำหรับจอมอนิเตอร์ของคุณ — และล้างกระดานระหว่างโจทย์แทนที่จะเลื่อนหาพื้นที่ว่างใหม่

การสาธิต — แอปพลิเคชันเต็มเฟรม

จับภาพหน้าต่าง (Window Capture) ของซอฟต์แวร์ที่คุณกำลังสอน โดยแสดงเคอร์เซอร์ และบน Windows ยังแสดงการคลิกและการกดปุ่มของคุณด้วย; เว็บแคมของคุณอยู่เล็ก ๆ ในมุมของมัน ชั้นเรียนเห็นว่าคุณเปิดเมนูไหนและกดปุ่มใด ไม่ใช่แค่ผลลัพธ์ที่ปรากฏ

อภิปราย — คุณเต็มเฟรม

หนึ่งฉากที่มีแต่เว็บแคมของคุณ ขนาดเต็ม สลับมาใช้เมื่อคุณเลิกแสดงเนื้อหาและเริ่มถามคำถาม แล้วชั้นเรียนจะเห็นใบหน้าของคุณในขนาดที่อ่านสีหน้าออก นี่ยังเป็นฉากที่ควรเตรียมไว้เมื่อนักเรียนถามบางอย่างที่สไลด์ไม่ได้ตอบ

เคล็ดลับจากครูที่นำเสนอออนไลน์ทุกสัปดาห์

ประเมินทุกเลย์เอาต์ที่ขนาดซึ่งนักเรียนได้เห็นจริง

ก่อนคาบเรียน ย่อหน้าตัวอย่าง (preview) ของ SplitCam ลงจนมีขนาดราวกรอบที่นักเรียนได้เห็นจริง แล้วมองเนื้อหาของคุณเองจากอีกฟากของโต๊ะ อะไรก็ตามที่คุณต้องโน้มตัวเข้าไปอ่านคือเล็กเกินไป — ตัวอักษรใหญ่ขึ้น สิ่งบนจอพร้อมกันน้อยลง และหนึ่งความคิดต่อหนึ่งการจัดวาง แทนที่จะเป็นหน้าเต็มที่ย่อลงให้พอดี

ตัดสินใจว่ามุมไหนเป็นของคุณ ก่อนคาบเรียน

เลือกมุมที่เว็บแคมของคุณอยู่ แล้วอย่าเขียน ชี้ หรือวางแผนภาพลงในมุมนั้นเด็ดขาด เลเยอร์ที่คุณต้องย้ายกลางคาบคือเลเยอร์ที่ทั้งชั้นเรียนมองดูคุณย้ายมัน

วางเนื้อหาไว้ตรงที่แนวสายตาของคุณตกลง

จัดฉากให้สิ่งที่คุณกำลังพูดถึงอยู่สูงบนหน้าจอของคุณ ใกล้กับกล้อง สุดท้ายคุณจะมองที่ชั้นเรียนแทนที่จะก้มลงและเหลือบไปด้านข้าง และไม่มีใครเสียเวลาทั้งคาบสงสัยว่าคุณกำลังอ่านอะไรอยู่จริง ๆ

ปล่อยให้ตัวจับเวลาเป็นตัวจบกิจกรรม ไม่ใช่ความจำของคุณ

สำหรับกิจกรรมที่กำหนดเวลาแน่นอน เลเยอร์ Automation Timer นับถอยหลังต่อหน้าชั้นเรียน จึงไม่มีใครต้องถามว่าเหลือเวลาอีกเท่าไร บน Windows ตัวจับเวลาสามารถสลับฉากเมื่อหมดเวลาได้ ดังนั้นบทเรียนจึงกลับมาเองแทนที่จะรอตอนที่คุณนึกขึ้นได้

ซ้อมการสลับฉาก ไม่ใช่ซ้อมบทเรียน

ห้านาทีของการสลับฉากโดยไม่มีใครดูก็เพียงพอแล้ว บทเรียนคุณรู้อยู่แล้ว; ความจำกล้ามเนื้อใหม่อย่างเดียวคือฉากไหนเก็บการจัดวางแบบใด — และปุ่มไหนเรียกมันขึ้นมา ทำสักครั้งแล้วคุณจะเลิกคิดถึงตัวซอฟต์แวร์ระหว่างคาบเรียน ซึ่งคือจุดประสงค์ทั้งหมดของการตั้งค่ามัน

บันทึกไว้ขณะที่คุณสอน

SplitCam เขียนภาพที่ชั้นเรียนกำลังเห็นลงเป็นไฟล์บนเครื่องของคุณเอง ดังนั้นนักเรียนที่พลาดคาบเรียนจะได้สิ่งที่ทุกคนได้เห็นแบบเดียวกันเป๊ะ บน Windows ไฟล์ถูกเขียนเป็น fragmented MP4 ดังนั้นโปรแกรมล่มหรือไฟดับก็ไม่ทำให้คุณเสียการบันทึกทั้งไฟล์

สิ่งที่ครูทำกันอยู่ทุกวันนี้ และอะไรที่เปลี่ยนไปจริง ๆ

ไม่ใช่ตารางเปรียบเทียบผู้ขาย — นี่คือสี่สิ่งที่ครูทำกันอยู่แล้วเพื่อแสดงบางอย่างในบทเรียน แต่ละอย่างทำสิ่งที่ SplitCam ทำไม่ได้ และบทบาทของ SplitCam ก็แคบกว่าที่ตารางเปรียบเทียบจะบ่งบอก แอปประชุมยังคงเป็นตัวดำเนินคาบเรียน

การแชร์หน้าจอ

มันใช้งานได้และแอปประชุมทุกตัวมี แต่ใบหน้าของคุณกลายเป็นภาพย่อข้างสิ่งที่แชร์แทนที่จะเป็นส่วนหนึ่งของภาพเดียวกัน ทุกครั้งที่เปลี่ยนเนื้อหาหมายถึงต้องหาหน้าต่างอื่นและเลือกใหม่ว่าจะแชร์อะไร และอะไรก็ตามที่ไม่ได้เปิดอยู่บนคอมพิวเตอร์ของคุณ — หนังสือ ภาพร่างที่คุณเพิ่งวาด — ก็ใส่เข้าไปไม่ได้เลย

กล้องเอกสาร

ไม่มีอะไรอื่นที่แสดงมือของคุณทำงานบนหน้ากระดาษจริง และสำหรับวัสดุที่จับต้องได้ มันยังคงเป็นคำตอบที่ดีที่สุด แต่มันเป็นมุมตายตัวมุมเดียว และเป็นอุปกรณ์อีกชิ้นที่ต้องมี อีกทั้งไม่ใช่ทางเลือกแบบอย่างใดอย่างหนึ่ง: ส่วนใหญ่เชื่อมต่อเป็นเว็บแคมธรรมดา ดังนั้น SplitCam จึงรับมันเป็นเลเยอร์หนึ่งข้างสไลด์ของคุณ แทนที่จะใช้แทนกัน

การมิเรอร์แท็บเล็ต

ลายมือออกมาดีและปากกาก็เป็นเครื่องมือที่เหมาะกับงานนี้ แต่มันต้องใช้อุปกรณ์ตัวที่สอง แอปมิเรอร์ และหน้าต่างแชร์ และในขณะที่มิเรอร์อยู่ ใบหน้าของคุณจะเป็นภาพย่อข้างสิ่งที่แชร์ แทนที่จะเป็นส่วนหนึ่งของภาพเดียวกันที่ชั้นเรียนกำลังอ่าน

แท็บเล็ตปากกาที่ควบคุม PowerPoint หรือ Keynote

หมึกที่วาดบนสไลด์ของคุณภายในแอปนำเสนอดูดีและติดอยู่กับสไลด์ แต่มันมีอยู่แค่ภายในแอปนั้นเท่านั้น: ย้ายไปที่เบราว์เซอร์หรือซอฟต์แวร์ที่คุณกำลังสาธิต แล้วปากกาก็ไม่มีอะไรให้เขียนลงไป

ภาพกล้องเดียวแทน

SplitCam ประกอบภาพขึ้นมาและส่งให้แอปประชุมในฐานะกล้อง คุณและเนื้อหาอยู่ในเฟรมเดียวกัน การจัดวางเปลี่ยนได้โดยไม่มีอะไรหยุดชะงัก และเนื้อหาจะเป็น PDF หน้าจอ หน้าเว็บ หรือกล้องของโทรศัพท์คุณในเวลาเดียวกันก็ได้ การวาดเป็นแบบมืออิสระด้วยเมาส์หรือแทร็กแพด บน Windows

คำถามที่พบบ่อยเกี่ยวกับการตั้งค่าการสอนออนไลน์

นักเรียนของฉันต้องติดตั้งอะไรไหม?

ไม่ต้อง SplitCam ทำงานบนคอมพิวเตอร์ของคุณเท่านั้น โดยปรากฏเป็นกล้องเพิ่มอีกตัว ชั้นเรียนของคุณเข้าลิงก์ประชุมเดิมในแอปเดิมที่ใช้อยู่เสมอ และสิ่งที่ไปถึงพวกเขาคือภาพจากกล้อง — วิดีโอชนิดเดียวกับที่เว็บแคมของพวกเขาเองส่งออกไป

"SplitCam Camera" จะปรากฏใน Zoom, Google Meet และ Microsoft Teams ไหม — และฉันสลับมาใช้กลางคาบได้ไหม?

ได้ทั้งสองอย่าง เปิด Settings → Video ใน Zoom, Teams หรือ Meet แล้ว "SplitCam Camera" จะอยู่ในเมนูเลือกกล้องเคียงข้างเว็บแคมของคุณ; มันปรากฏแบบเดียวกันในแอปกว่า 60+ ตัว โดยไม่ต้องใช้ปลั๊กอินและไม่ต้องเชื่อมต่อเฉพาะแต่ละแอป คุณเปิดเมนูนั้นหลังจากคาบเรียนเริ่มไปแล้วได้ และภาพจะเปลี่ยนไปโดยไม่ต้องออกหรือเข้าร่วมใหม่

ฉันจะนำสไลด์ PowerPoint หรือ Keynote เข้ามาได้อย่างไร?

มีสองทางที่ตรงไปตรงมา ส่งออกสไลด์เป็น PDF แล้วเพิ่มไฟล์เป็นเลเยอร์ PDF — จากนั้นคุณพลิกหน้าภายในเลเยอร์ขณะสอน หรือถ้าคุณอยากควบคุม PowerPoint หรือ Keynote โดยตรงพร้อมภาพเคลื่อนไหวทั้งหมดและปากกาของมันเอง ให้ใช้ Window Capture กับหน้าต่างงานนำเสนอแล้วใส่สิ่งนั้นลงในฉากแทน

ฉันวาดบนสไลด์ได้ไหม?

สิ่งที่ SplitCam ระบุไว้ในเอกสารคือเลเยอร์ไวท์บอร์ดของมันเอง บน Windows: เส้นวาดมืออิสระ กด Shift เพื่อเส้นตรง Undo, Redo และ Clear All มันเป็นพื้นผิวสำหรับวาด ไม่ใช่ปากกาที่ลอยทับเนื้อหาอื่นของคุณ — ดังนั้นการจัดวางที่พบบ่อยคือสไลด์กินพื้นที่ส่วนใหญ่ของเฟรมโดยมีกระดานอยู่ข้าง ๆ หรือฉากที่คุณสลับไปเมื่อเริ่มลงมือแก้โจทย์ หากคุณต้องการหมึกที่ติดอยู่บนตัวสไลด์เอง ให้วาดด้วยปากกาของ PowerPoint หรือ Keynote เองแล้วจับภาพหน้าต่างนั้น

ฉันใช้ปากกาหรือแท็บเล็ตกราฟิกวาดได้ไหม?

ไวท์บอร์ดถูกระบุไว้ว่าเป็นการวาดมืออิสระด้วยเมาส์หรือแทร็กแพด; ไม่มีข้อมูลเผยแพร่เกี่ยวกับแรงกดปากกาหรือการรองรับสไตลัส ดังนั้นอย่าวางแผนบทเรียนโดยพึ่งมัน หากการป้อนด้วยปากกาเป็นหัวใจของวิธีที่คุณสอน ให้วาดในแอปพลิเคชันที่รองรับแท็บเล็ตของคุณอย่างเหมาะสม แล้วนำหน้าต่างนั้นเข้าสู่ฉากด้วย Window Capture

ฉันอยากเปิดคลิปวิดีโอ — ชั้นเรียนจะได้ยินเสียงไหม?

เพิ่มคลิปเป็นเลเยอร์วิดีโอแล้วมันจะเล่นภายในฉาก สำหรับเสียงที่ออกมาจากอีกโปรแกรม เช่น วิดีโอในแท็บเบราว์เซอร์ Windows มีแหล่งสัญญาณ Application Audio ที่รับเสียงของโปรแกรมนั้นโดยตรงและผสมเข้ากับไมโครโฟนของคุณ ตัวเลือก Accentuate ของไมโครโฟนจะลดเสียงแหล่งอื่นลงทุกครั้งที่ได้ยินเสียงคุณ คุณจึงพูดทับคลิปได้ — มันตอบสนองต่อเสียงใด ๆ ไม่ใช่แค่เสียงของคุณเท่านั้น ดังนั้นสวมหูฟังเมื่อใช้งาน

ฉันบันทึกบทเรียนไว้ให้นักเรียนที่พลาดคาบได้ไหม?

ได้ SplitCam บันทึกภาพที่ประกอบเสร็จลงเป็นไฟล์บนเครื่องของคุณเอง — ไม่มีคลาวด์ ไม่มีพอร์ทัล ไม่มีลิงก์ ดังนั้นคุณแชร์ไฟล์ด้วยวิธีที่โรงเรียนของคุณใช้แชร์ไฟล์อยู่แล้ว บน Windows มันถูกเขียนเป็น fragmented MP4 ซึ่งหมายความว่าการบันทึกที่ถูกขัดจังหวะก็ยังเปิดเล่นได้

ทั้งหมดนี้ใช้งานบน Mac ได้ไหม?

ส่วนหลักใช้ได้: เลเยอร์ PDF, สไลด์โชว์, การจับภาพหน้าจอและหน้าต่าง, เลเยอร์ Browser, Phone Camera, การบันทึก และตัวกล้องเสมือนเองล้วนทำงานบน macOS 13 ขึ้นไป โดยกล้องถูกติดตั้งเป็นส่วนขยายของระบบที่คุณอนุญาตในครั้งแรกที่เปิด ระบุไว้เฉพาะบน Windows เท่านั้น: ไวท์บอร์ด, Application Audio, แหล่งสัญญาณ Replay และแหล่งสัญญาณ Color แบบสีทึบ หากการสอนของคุณพึ่งไวท์บอร์ด ให้สอนจาก Windows

ลองใช้กับบทเรียนเดียว

หยิบบทเรียนที่คุณเตรียมไว้แล้ว ใช้เวลาสักไม่กี่นาทีจัดเนื้อหาของมันลงในฉาก แล้วสอน ไม่มีส่วนใดตกเป็นภาระเพิ่มของชั้นเรียน: ลิงก์ประชุมเดิม แอปเดิม ไม่ต้องติดตั้งอะไร ไม่เสียเวลาสักนาทีอธิบายเครื่องมือใหม่ ความต่างเดียวที่พวกเขาเห็นได้คือคุณและสิ่งที่คุณกำลังอธิบายในที่สุดก็อยู่ในภาพเดียวกัน — และถ้ามันกลายเป็นว่าไม่เข้ากับวิธีที่คุณสอน คุณก็เลือกเว็บแคมของคุณเองกลับคืนจากเมนูเดิม แล้วบทเรียนก็ดำเนินต่อไป
