วิธีสตรีมบน YouTube — ซอฟต์แวร์ฟรี ตั้งค่าใน 5 นาที

คู่มือทีละขั้นแบบครบถ้วน SplitCam ฟรีจะเป็นตัวเข้ารหัสของคุณ — ไม่ต้องสมัคร ไม่ต้องใส่บัตร ไม่มีลายน้ำบนสตรีม จัดฉาก สลับแหล่งภาพ ไลฟ์ที่ 1080p 60fps โบนัส: สตรีมเดียวไปยัง YouTube + Twitch พร้อมกัน

วิธีสตรีมบน YouTube ใน 5 นาที:
  1. ดาวน์โหลด SplitCam (ฟรี ไม่ต้องสมัคร) สำหรับ Windows / macOS / iOS / Android
  2. เพิ่มกล้อง (เว็บแคม การจับภาพหน้าจอ หรือเกม) เป็นเลเยอร์ในฉาก
  3. คัดลอกสตรีมคีย์: studio.youtube.com → สร้าง → เริ่มถ่ายทอดสด → สตรีม
  4. วางคีย์ ใน SplitCam → การตั้งค่าสตรีม → YouTube บิตเรตสำหรับ 1080p — 4.5 Mbps
  5. กด „ไลฟ์“ ใน SplitCam แล้วกด „เริ่มถ่ายทอดสด“ ใน YouTube Studio คุณก็ไลฟ์แล้ว

ทีละขั้น: ไลฟ์สดบน YouTube

จากศูนย์ถึงออกอากาศ — ราว 5 นาที ทดสอบบน Windows 11 และ macOS 14 แล้ว บนแพลตฟอร์มอื่นทุกอย่างเหมือนกันเป๊ะ

1
ดาวน์โหลด SplitCam ~ 1 นาที

SplitCam คือสตูดิโอสตรีมมิ่งฟรีที่รู้วิธีคุยกับ YouTube อยู่แล้ว: ที่อยู่ RTMP ฝังอยู่ในเทมเพลตสำเร็จรูป ไม่ต้องกรอกอะไรเอง ตัวติดตั้งเบาและทำงานบน Windows 10/11, macOS 11+, iOS 13+ และ Android 8+ ไม่ต้องมีบัญชี ไม่ต้องใส่บัตร ไม่มีการจำกัดเวลา

ดีกว่าตัวเข้ารหัสทั่วไปตรงไหน: เทมเพลต YouTube ช่วยประหยัดการตั้งค่าสตรีมด้วยมือ, Replay Source ด้วยคีย์ลัดตัดไฮไลต์ล่าสุดให้ และการเปลี่ยนพื้นหลังทำงานบนอุปกรณ์โดยตรง — ไม่ต้องใช้กรีนสกรีน ครีเอเตอร์เดี่ยวทำไลฟ์ให้เรียบร้อยได้โดยไม่ต้องมีคนช่วย
2
จัดภาพให้ผู้ชม ~ 2 นาที

เปิด SplitCam แล้วนำแหล่งภาพขึ้นแคนวาส: เว็บแคม — สำหรับช็อตหน้า, Game Capture — สำหรับเกม DirectX/OpenGL, Screen Capture — สำหรับสอนและรีแอ็กชัน, Browser Source — สำหรับโอเวอร์เลย์ บวกรูปภาพ คลิป หรือมุมที่สองจากโทรศัพท์ผ่าน Wi-Fi

จัดเลเยอร์เหล่านี้เป็นฉากที่ตั้งชื่อไว้หลายฉาก — Intro, หลัก, Just Chatting, BRB — แล้วผูกแต่ละฉากกับคีย์ลัด (F1, F2…) ระหว่างไลฟ์สลับไปมาได้ทันที และเพื่อภาพที่ดูเป็นภาพยนตร์ขึ้น ใช้ทรานซิชัน Fade / Luma Wipe / Slide

เคล็ดลับสำหรับครีเอเตอร์: เล็ง Browser Source ไปที่วิดเจ็ตแจ้งเตือน — แจ้งผู้ติดตามใหม่ Super Chat แถบเป้าหมาย ความเคลื่อนไหวทั้งหมดอยู่ตรงหน้าผู้ชม โดยที่แอปแจ้งเตือนแยกไม่กินทรัพยากร
3
เอาสตรีมคีย์จาก YouTube ~ 30 วินาที

เข้า studio.youtube.com → กด สร้าง (มุมขวาบน) → เริ่มถ่ายทอดสด ในเมนูด้านซ้ายเปิดแท็บ สตรีม

กรอกชื่อ คำอธิบาย และหมวดหมู่ของสตรีม ในแผงตั้งค่าด้านขวาคัดลอก สตรีมคีย์ (หน้าตาเหมือน xxxx-xxxx-xxxx-xxxx-xxxx)

⚠ ความปลอดภัย: สตรีมคีย์เหมือนรหัสผ่าน: อย่าโชว์สาธารณะและอย่าอัปขึ้น git ถ้าคีย์รั่ว ใครก็สตรีมในช่องของคุณได้ รีเซ็ตได้ทุกเมื่อใน YouTube Studio
4
เชื่อม SplitCam กับ YouTube ~ 1 นาที

ใน SplitCam เปิด การตั้งค่าสตรีม → เลือก YouTube (ตั้งค่ามาให้แล้ว) วางสตรีมคีย์ลงในช่อง กด „ตรวจสอบการเชื่อมต่อ“ — เครื่องหมายถูกสีเขียวหมายความว่าเชื่อมต่อครบแล้ว

ตัวเข้ารหัสฮาร์ดแวร์ของ SplitCam ตรวจจับให้เองตอนเริ่ม — NVENC บนการ์ด Nvidia, QuickSync บนชิป Intel, AMF บน AMD — การตั้งค่าการเข้ารหัสจึงแทบไม่ต้องแตะเลย การเข้ารหัสไปอยู่บนชิปการ์ดจอ ส่วน CPU เหลือไว้ให้เกมหรือแอปที่คุณกำลังสตรีม ค่าบิตเรตแนะนำ — ด้านล่าง:

ความละเอียดเฟรมเรตบิตเรต
1080p60 fps4500–9000 Kbps
1080p30 fps3000–6000 Kbps
720p60 fps2250–6000 Kbps
720p30 fps1500–4000 Kbps
เคล็ดลับ: ก่อนอื่นรัน Upload Speed Test ในตัว มันจะแสดงเพดานบิตเรตที่ปลอดภัยตามการเชื่อมต่อจริงของคุณ การสตรีมที่ 6 Mbps ทั้งที่นิ่งอยู่แค่ 3 Mbps = เฟรมตกและกระตุก
5
กด „ไลฟ์“ ~ 5 วินาที

ใน SplitCam กดปุ่มใหญ่ „ไลฟ์“ สตรีมเริ่มวิ่งไป YouTube แล้ว หลัง ~10–15 วินาที ตัวอย่างใน YouTube Studio จะปรากฏ — คุณจะเห็นสตรีมของตัวเองที่นั่น

เมื่อตัวอย่างดูเรียบร้อยดี กด „เริ่มถ่ายทอดสด“ ใน YouTube Studio (มุมขวาบน) ตั้งแต่วินาทีนั้นผู้ชมจะเห็นสตรีม คุณก็ไลฟ์แล้ว

เท่านี้แหละ การตั้งค่าครั้งแรกราว 5 นาที หลังจากนั้น: เปิด SplitCam กด „ไลฟ์“ ยืนยันใน YouTube Studio ราวสิบวินาที
โบนัส — สตรีมไป YouTube + Twitch และอื่น ๆ พร้อมกัน

SplitCam มี มัลติสตรีม ในตัว หลังขั้นที่ 4 ติ๊กเลือกนอกจาก YouTube ยังมี Twitch / Facebook Live / Kick / TikTok Live วางสตรีมคีย์ของแต่ละแพลตฟอร์ม กด „ไลฟ์“ ครั้งเดียว — แล้วทุกแพลตฟอร์มที่เลือกได้รับสตรีมพร้อมกัน

ไม่มีตัวกลางบนคลาวด์ ไม่มีค่าบริการรายเดือน สตรีมวิ่งตรงจากเครื่องของคุณไปยังเซิร์ฟเวอร์รับสัญญาณของแต่ละแพลตฟอร์ม ทางเลือกฟรีแทน Restream ($19/เดือน) และ StreamYard ($25/เดือน) 84+ แพลตฟอร์มตั้งค่ามาให้แล้ว

เคล็ดลับให้ไลฟ์ลื่นไหล

สิ่งที่สตรีมเมอร์มือเก๋าทำโดยอัตโนมัติ แต่มือใหม่มักมองข้าม

🔇 ปิดไมค์ก่อนเริ่มไลฟ์

เริ่มด้วยไมค์ปิดเสมอ แล้วค่อยเปิดเมื่อพร้อม ช่วยให้รอดจากประโยค „นี่มันทำงานไหมเนี่ย?“ ที่หลุดออกอากาศ

🔌 ต่อสายแลน

Ethernet สำหรับสตรีมเสถียรกว่า Wi-Fi เสมอ ถ้าเลี่ยง Wi-Fi ไม่ได้ — นั่งใกล้เราเตอร์และใช้คลื่น 5 GHz

🔒 ทดสอบแบบ „ไม่จำกัด/ลิงก์“ ก่อน

ใน YouTube Studio ตั้งสตรีมแรกเป็นการเข้าถึง „ไม่แสดงในสาธารณะ (ลิงก์)“ เช็กเสียง ภาพ การจัดเฟรม เมื่อทุกอย่างเรียบร้อย — สลับเป็นสาธารณะ

⏪ Replay Source สำหรับไฮไลต์

Replay Source ใน SplitCam เก็บ 5–10 วินาทีล่าสุดของฉากไว้แล้วแทรกด้วยคีย์ลัด สโลว์โมชันทันทีหรือรีเพลย์โมเมนต์เด็ดในเกม

📈 จับตาสถิติระหว่างไลฟ์

SplitCam แสดงโหลดตัวเข้ารหัส เฟรมที่ตก และแบนด์วิดท์ได้สดระหว่างถ่ายทอด เห็นปัญหา — ลดคุณภาพลงนิด: 1080p ที่นุ่มลงหน่อยดีกว่าไลฟ์ที่กระตุก

🎞️ ใช้ฉากหลายฉาก ไม่ใช่กล้องเดียว

สร้างอย่างน้อย 3 ฉาก: „เริ่มเร็ว ๆ นี้“ / ไลฟ์ / „เดี๋ยวกลับมา“ การสลับไปมาทำให้ภาพดูมีชีวิตและเป็นมืออาชีพ

คำถามที่พบบ่อยเกี่ยวกับการสตรีม YouTube

SplitCam ฟรีสำหรับสตรีมบน YouTube ไหม?

ใช่ — ฟรี 100% ทั้งสำหรับใช้งานส่วนตัวและเชิงพาณิชย์ ไม่มีลายน้ำบนสตรีม ไม่มีการจำกัดเวลา ไม่มีการบีบให้ „ซื้อเวอร์ชันโปร“ ทุกฟีเจอร์ปลดล็อกตั้งแต่วันแรก

ควรตั้งบิตเรตเท่าไรสำหรับสตรีม YouTube?

สำหรับ 1080p 30fps: 3000–6000 Kbps สำหรับ 1080p 60fps: 4500–9000 Kbps สำหรับ 720p: 1500–4000 Kbps Upload Speed Test ในตัวของ SplitCam จะตรวจการเชื่อมต่อของคุณก่อนเริ่มไลฟ์

สตรีมไป YouTube และ Twitch พร้อมกันได้ไหม?

ได้ — SplitCam มีมัลติสตรีมในตัว เพิ่มสตรีมคีย์ของ YouTube และ Twitch กด „ไลฟ์“ ครั้งเดียว — ทั้งสองแพลตฟอร์มได้รับสตรีมพร้อมกัน ไม่มีตัวกลางบนคลาวด์ ไม่มีค่าบริการรายเดือน รายละเอียด — ดูที่ คู่มือมัลติสตรีม

จะเปิดใช้การไลฟ์สดในช่อง YouTube ได้อย่างไร?

ต้องมีบัญชี YouTube ที่ยืนยันแล้ว (ยืนยันทางโทรศัพท์) และไม่มีข้อจำกัดการถ่ายทอดในช่วง 90 วันที่ผ่านมา การไลฟ์จากมือถือต้องมีผู้ติดตาม 50+ คน ส่วนการสตรีมจากคอมพิวเตอร์ไม่มีข้อกำหนดเรื่องผู้ติดตาม — บัญชีที่ยืนยันแล้วทุกบัญชีไลฟ์ได้

ต้องใช้ OBS ไหม หรือ SplitCam ใช้แทนได้?

สำหรับยูทูบเบอร์ส่วนใหญ่ SplitCam ทำงานได้เองครบ: กล้องเสมือน พื้นหลัง AI มัลติสตรีม และการสลับฉาก มีมาในตัว ส่วนชุดฉาก OBS ที่มีอยู่ มันอ่านได้ถ้าคุณสร้างไว้แล้ว ส่วนคนที่พึ่งปลั๊กอิน OBS ตัวใดตัวหนึ่ง อาจสะดวกกว่าที่จะอยู่กับ OBS

SplitCam จะทำให้ FPS ในเกมลดไหม?

แทบไม่เห็นด้วยตา SplitCam ส่งการเข้ารหัสไปยังฮาร์ดแวร์แยกของการ์ดจอ — NVENC บน Nvidia, QuickSync บน Intel, AMF บน AMD — เลือกตัวเข้ารหัสให้อัตโนมัติเมื่อเริ่มใช้งาน CPU และคอร์เรนเดอร์หลักเหลือไว้ให้เกม เฟรมเรตจึงคงเดิม คอนฟิกส่วนใหญ่เสีย FPS แค่ 0–3%

สตรีมบน YouTube จากโทรศัพท์ได้ไหม?

ได้ — SplitCam สำหรับ iOS และ Android สตรีมบน YouTube ตรงจากโทรศัพท์ได้ การไลฟ์จากมือถือ YouTube กำหนดผู้ติดตามช่อง 50+ คน แคนวาสแนวตั้ง 9:16 บนมือถือเปิดเป็นค่าเริ่มต้น — เหมาะกับ YouTube Shorts Live พอดี
