การดาวน์โหลด SplitCam ทุกเวอร์ชันฟรี — สตรีมสดและมัลติสตรีมสำหรับ Windows, macOS, iOS และ Android พร้อม SplitCam Remote แอปคู่หูบนมือถือที่ควบคุมสตรีมบนเดสก์ท็อปได้โดยไม่ต้องแตะคีย์บอร์ด ไม่มีลายน้ำ ไม่มีค่าสมาชิก

สตรีมจากอุปกรณ์ไหนก็ได้

สตูดิโอสตรีมของ SplitCam แบบเต็มรูปแบบ — เวอร์ชันเดสก์ท็อปและมือถือใช้เอนจินมัลติสตรีมเดียวกัน โมเดลฉากและแหล่งสัญญาณเดียวกัน และราคาเท่ากันคือศูนย์

SplitCam สำหรับ Windows v10.9.2

Windows 10 · Windows 11

SplitCam ตัวต้นฉบับ สตูดิโอสตรีมสดและมัลติสตรีมพร้อมกล้องเสมือน พื้นหลัง AI และการจัดองค์ประกอบฉาก ที่สตรีมเมอร์ โบสถ์ และผู้แพร่ภาพใช้งานมาตั้งแต่ปี 2003

  • มัลติสตรีมไปยังแพลตฟอร์มกว่า 84 แห่งแบบ peer-to-peer
  • กล้องเสมือนสำหรับ Zoom, Teams, Meet, Discord
  • พื้นหลัง AI — ไม่ต้องใช้กรีนสกรีน
  • นำเข้าโปรเจกต์ OBS ด้วยคลิกเดียว
  • เข้ารหัสด้วยฮาร์ดแวร์: NVENC · QuickSync · AMF
ฟรี ดาวน์โหลดตรงดาวน์โหลดสำหรับ Windows ดูบันทึกการเปลี่ยนแปลง v10.9.2

SplitCam สำหรับ macOS v1.19

macOS 13+ · Apple Silicon

เวอร์ชันเนทีฟสำหรับ Mac ที่ปรับให้เหมาะกับ Apple Silicon ใช้เอนจินมัลติสตรีมเดียวกับ Windows — กล้องเสมือนทำงานได้ในทุกแอปวิดีโอบน Mac เข้ารหัสด้วยฮาร์ดแวร์ผ่าน VideoToolbox

  • มัลติสตรีมไปยังแพลตฟอร์มกว่า 84 แห่งพร้อมกัน
  • กล้องเสมือนสำหรับ FaceTime, Zoom, Teams, Meet
  • ฉากจากหลายแหล่งสัญญาณพร้อมเอฟเฟกต์เร่งด้วย GPU
  • จับภาพหน้าจอและหน้าต่างได้สูงสุด 4K
  • มิกเซอร์เสียงพร้อมระบบลดเสียงรบกวน
ดาวน์โหลดบนMac App Store ดูบันทึกการเปลี่ยนแปลง v1.19

iOS 16+ · iPhone · iPad

  • ฟิลเตอร์ AR และเอฟเฟกต์ภาพแบบเรียลไทม์กำลังพัฒนา
  • ภาพซ้อนภาพ — สตรีมต่อไปขณะที่คุณเปิดแอปอื่นกำลังพัฒนา

SplitCam Remote — สตรีมของคุณ อยู่ในมือคุณ

แอปบนมือถือที่ควบคุม SplitCam เวอร์ชันเดสก์ท็อปบน Mac หรือ Windows ของคุณ อยู่หน้ากล้องได้ตลอด สลับฉาก ปรับระดับเสียงของแต่ละเลเยอร์ เริ่มอัดหรือหยุดสตรีมชั่วคราว โดยไม่ต้องเอื้อมไปแตะคีย์บอร์ด

แตะครั้งเดียว ไม่ต้องเอื้อมไปคีย์บอร์ดอย่างเก้ ๆ กัง ๆ

เปิด SplitCam บนพีซีสตรีม แล้วเปิด SplitCam Remote บนโทรศัพท์ — จับคู่อัตโนมัติบน Wi-Fi เดียวกัน หรือสแกน QR code จาก SplitCam โทรศัพท์ของคุณจะกลายเป็นแผงควบคุมของผู้กำกับ

  • สลับฉาก — มุมกว้าง / แท่นเทศน์ / เกมเพลย์ / เนื้อเพลง แตะครั้งเดียว
  • ระดับเสียงรายเลเยอร์ — ไมค์ เพลง เสียงเกม สายแขกรับเชิญ แยกอิสระแต่ละตัว
  • ปิดเสียง / ซ่อนเลเยอร์ — ปิดกล้องหรือแหล่งสัญญาณกลางสตรีมได้
  • เริ่ม / หยุดสตรีม — ไลฟ์สดและจบไลฟ์ได้จากอีกฝั่งของห้อง
  • หยุดสตรีมชั่วคราว — พักสักครู่แล้วกลับมาต่อได้อย่างไร้รอยต่อ
  • เริ่ม / หยุดการอัด — เก็บคลิปได้ทันทีระหว่างสตรีม

SplitCam Remote ค้นหาเดสก์ท็อปของคุณบนเครือข่ายภายในให้เอง — หรือสแกน QR code บนหน้าจอเดสก์ท็อปเพื่อจับคู่ทันที ไม่ต้องสร้างบัญชี ไม่มีตัวกลางบนคลาวด์

ขั้นตอน 01

เปิด SplitCam บนคอมพิวเตอร์ของคุณ

เปิด SplitCam บน Windows หรือ Mac ตามปกติ แล้วเปิด การควบคุมระยะไกล ในการตั้งค่า ซึ่งจะเปิดตัวรับสัญญาณบนเครือข่ายภายใน

ขั้นตอน 02

ติดตั้ง SplitCam Remote บนโทรศัพท์

ฟรีบน App Store สำหรับ iPhone และ iPad (iOS 17+) ส่วนเวอร์ชัน Android อยู่ระหว่างการทดสอบแบบปิด — สมัครเป็นผู้ทดสอบเพื่อลองใช้ก่อนใคร ตรวจสอบให้แน่ใจว่าโทรศัพท์อยู่บน Wi-Fi เดียวกับพีซีสตรีม

ขั้นตอน 03

แตะเพื่อจับคู่ แล้วควบคุม

แอปจะค้นหาเดสก์ท็อปของคุณบน Wi-Fi เดียวกันให้เอง — หรือสแกน QR code ที่แสดงใน SplitCam เพื่อจับคู่ทันที ตอนนี้โทรศัพท์ของคุณคือแผงควบคุมของผู้กำกับ สลับฉาก จัดการเสียง และไลฟ์สดได้เลย
