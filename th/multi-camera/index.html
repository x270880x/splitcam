SplitCam/Multi-camera
สตรีมหลายกล้อง

โปรแกรมสตรีมสดหลายกล้องฟรี — สลับไปมาระหว่างกล้อง หรือโชว์พร้อมกันทุกตัว

«หลายกล้อง» มีความหมายสองอย่างที่ต่างกัน และคนค้นหาทั้งสองอย่างด้วยคำเดียวกัน อย่างแรกคือการสลับ: มีกล้องตัวเดียวอยู่ในเฟรม และคุณเลือกว่าจะเป็นตัวไหน อย่างที่สองคือการประกอบภาพ: มีกล้องสองตัวอยู่ในเฟรมพร้อมกัน SplitCam ทำได้ทั้งสองอย่างด้วยแนวคิดเดียวกันสองข้อ — เลเยอร์ภายในฉาก และฉากที่คุณสลับได้ระหว่างไลฟ์ — บน Windows และ macOS ฟรี

⬇ ดาวน์โหลดฟรี วิธีใช้งาน
ฟรี ไม่มีลายน้ำเว็บแคม, IP, NDI, มือถือWindows และ macOSคีย์ลัดและ Stream Deck
ตั้งค่าในสี่ขั้นตอน
  1. เพิ่มกล้องของคุณเป็นเลเยอร์ เว็บแคม USB, กล้อง IP ผ่าน RTSP, แหล่งภาพ NDI หรือมือถือของคุณผ่านแหล่งภาพ Phone Camera แต่ละตัวจะกลายเป็นเลเยอร์ที่คุณจัดวางและปรับขนาดได้
  2. สร้างหนึ่งฉากต่อหนึ่งช็อต ช็อตมุมกว้าง ช็อตระยะใกล้ สไลด์ที่มีกล้องเล็ก ๆ อยู่ตรงมุม ฉากก็แค่การจัดเรียงของเลเยอร์ สร้างได้มากเท่าที่รายการของคุณต้องการ
  3. สลับฉากระหว่างไลฟ์ คลิกที่ฉาก กดคีย์ลัดของมัน หรือกดปุ่มบน Stream Deck หรือบนแอป SplitCam Remote ในมือถือของคุณ เลือกทรานซิชัน: ตัด เฟด สไลด์ ไวป์ หรือสติงเกอร์
  4. ส่งผลลัพธ์ไปได้ทุกที่ ไปยัง 84+ แพลตฟอร์มพร้อมกัน ไปยังการอัด หรือเข้า Zoom, Teams และ Meet ผ่านกล้องเสมือน — พวกมันจะเห็นฉากที่กำลังออกอากาศอยู่

การสลับ: กล้องตัวเดียวในเฟรม คุณเลือกว่าตัวไหน

นี่คืองานของผู้กำกับ — กว้าง ใกล้ กว้างอีกครั้ง ใน SplitCam มันคือหนึ่งฉากต่อหนึ่งช็อต และการสลับระหว่างฉากเหล่านั้น

หนึ่งฉากคือหนึ่งช็อต

วางกล้องมุมกว้างไว้ในฉากหนึ่ง และกล้องระยะใกล้ไว้ในอีกฉากหนึ่ง การเปลี่ยนช็อตก็คือการสลับฉาก และผู้ชมจะเห็นการตัดภาพที่สะอาด ไม่ใช่เลเยอร์ที่ถูกลากไปมา

ทรานซิชันระหว่างฉาก

ตัด เฟด สไลด์ สไวป์ ลูมาไวป์ หรือสติงเกอร์ — ไวป์แบบเคลื่อนไหวของคุณเอง ทรานซิชันเป็นคุณสมบัติของการสลับ ฉากเดียวกันจึงเข้าได้ต่างกันเมื่อมาจากคนละที่

สลับโดยไม่ต้องใช้เมาส์

ตั้งคีย์ลัดให้แต่ละฉาก บน Windows หรือ macOS ถ้าคุณมี Stream Deck อยู่แล้ว ก็มีปลั๊กอิน SplitCam อย่างเป็นทางการสำหรับมันบน Windows (SplitCam 10.8.25 ขึ้นไป) ส่วนแอป SplitCam Remote ฟรีบน iPhone ก็ทำแบบเดียวกันได้จากอีกฟากของห้อง

กล้อง IP หลายตัวในรายการเดียว

กล้อง IP สามตัวขึ้นไปในฉากเดียวเป็นการตั้งค่าที่ระบุไว้ในเอกสารและผ่านการทดสอบแล้ว แต่ละตัวเป็นเลเยอร์ และแต่ละตัวอยู่ในกี่ฉากก็ได้ตามต้องการ

การประกอบภาพ: กล้องสองตัวในเฟรมพร้อมกัน

ภาพซ้อนภาพ วางเคียงข้างกัน กล้องทับบนการแชร์หน้าจอ ไม่มีการสลับใด ๆ เลย — นี่คือเลเยอร์ที่ซ้อนกันอยู่ภายในฉากเดียว

ซ้อน จัดวาง ปรับขนาด

ทุกแหล่งภาพคือเลเยอร์ที่มีตำแหน่งและขนาด วางกล้องตัวที่สองไว้ตรงมุมของตัวแรก หรือแบ่งเฟรมครึ่งกลาง สิ่งที่คุณเห็นบนแคนวาสคือสิ่งที่ออกอากาศ

กล้องทับบนอะไรก็ได้

เลเยอร์ที่สองไม่จำเป็นต้องเป็นกล้อง สไลด์ หน้าเว็บ เกมเต็มจอ หรือการจับภาพหน้าต่างอยู่ด้านล่าง ใบหน้าของคุณอยู่ด้านบน — กลไกเดียวกัน

มือถือของคุณเป็นมุมกล้องที่สอง

เพิ่มแหล่งภาพ Phone Camera สแกน QR code แล้วมือถือจะเข้าร่วมพร้อมวิดีโอและเสียงผ่านเบราว์เซอร์ของมัน — ไม่ต้องติดตั้งอะไรบนมือถือ วางบนขาตั้งเล็ก ๆ สำหรับมุมจากด้านบนหรือมุมกว้าง

ทั้งสองพร้อมกันในวิดีโอคอล

เลือก SplitCam เป็นกล้องใน Zoom, Teams หรือ Meet แล้วการประชุมจะได้รับฉากที่ประกอบแล้ว: กล้องสองตัว หรือกล้องกับสไลด์ เป็นภาพเดียว

สิ่งที่ SplitCam ทำไม่ได้สำหรับงานหลายกล้อง

รู้เพดานให้ชัดก่อนจะสร้างรายการบนมัน ไม่มี Preview/Program — คุณสลับไปที่ฉากโดยตรง ไม่ได้คิวไว้ก่อน — และไม่มีผนัง MultiView ที่แสดงพรีวิวของทุกแหล่งภาพ การอัดจะจับฉากที่ประกอบแล้วเป็นไฟล์เดียว ไม่ได้แยกแต่ละกล้องไว้สำหรับตัดต่อ ไม่มีอะไรแพน เอียง หรือซูมกล้องให้คุณ NDI รับเข้าได้แต่ส่งออกไม่ได้ ไม่มีการสลับอัตโนมัติไปหาคนที่กำลังพูด และไม่มีลิงก์เบราว์เซอร์สำหรับแขกระยะไกล ถ้าโปรดักชันของคุณต้องการสิ่งเหล่านี้ข้อใดข้อหนึ่ง มันต้องใช้สวิตเชอร์ออกอากาศ — vMix บน Windows หรือ ATEM แบบฮาร์ดแวร์ — และหน้านี้จะไม่พยายามเกลี้ยกล่อมคุณเป็นอย่างอื่น แต่ถ้าต้องการแค่กล้องในฉากและสลับฉากได้อย่างสะอาด นั่นคือสิ่งที่มีอยู่ตรงนี้พอดี

แหล่งภาพไหนใช้ได้ บนระบบไหน

แก่นหลัก — ฉาก เลเยอร์ การสลับ กล้องเสมือน การอัด และมัลติสตรีม — ทำงานได้ทั้งบน Windows 10/11 และ macOS 13+ มีแหล่งภาพบางส่วนที่ระบุไว้ในเอกสารเฉพาะบน Windows เท่านั้น

สตรีมหลายกล้อง — คำถามที่พบบ่อย

นี่เป็นโปรแกรมสตรีมสดหลายกล้องที่ฟรีจริง ๆ ใช่ไหม?

ใช่ ฉาก เลเยอร์ การสลับพร้อมทรานซิชัน กล้องเสมือน การอัด และมัลติสตรีมไปยัง 84+ แพลตฟอร์ม ทั้งหมดอยู่ในไฟล์ดาวน์โหลดฟรี ไม่มีลายน้ำ และไม่มีรุ่นเสียเงินที่อยู่เหนือขึ้นไป

ใช้กล้องได้กี่ตัว?

SplitCam ไม่ได้ประกาศขีดจำกัดตายตัว และเราจะไม่แต่งตัวเลขขึ้นมาเองตรงนี้ กล้อง IP สามตัวขึ้นไปในฉากเดียวเป็นการตั้งค่าที่ระบุไว้ในเอกสาร ในทางปฏิบัติ เพดานคือ CPU, GPU และแบนด์วิดท์ USB ของคอมพิวเตอร์คุณ ไม่ใช่ตัวเลขในซอฟต์แวร์

การสลับกับการโชว์สองกล้องพร้อมกันต่างกันอย่างไร?

การสลับคือมีกล้องตัวเดียวในเฟรมในแต่ละครั้ง — เป็นฉากแยกกัน แล้วคุณตัดภาพระหว่างฉาก การโชว์สองกล้องพร้อมกันคือเลเยอร์ภายในฉากเดียว — ภาพซ้อนภาพหรือวางเคียงข้างกัน SplitCam ทำได้ทั้งสองอย่าง สิ่งที่คุณต้องการจะเป็นตัวตัดสินว่าจะสร้างหลายฉากหรือฉากเดียว

สลับกล้องโดยไม่แตะคีย์บอร์ดได้ไหม?

ได้ แต่ละฉากตั้งคีย์ลัดได้บน Windows และ macOS รองรับ Stream Deck บน Windows และแอป SplitCam Remote ฟรีสลับฉากได้จาก iPhone

อัดแต่ละกล้องแยกกันได้ไหม?

ไม่ได้ การอัดจะจับฉากที่ประกอบแล้วเป็นไฟล์เดียว ถ้าคุณต้องการทุกกล้องเป็นไฟล์ของตัวเองสำหรับตัดต่อ นั่นคือการบันทึก ISO และต้องใช้สวิตเชอร์ออกอากาศอย่าง vMix

กล้องมือถือต้องใช้แอปไหม?

ไม่ต้อง เพิ่มแหล่งภาพ Phone Camera สแกน QR code ด้วยมือถือ แล้วมันจะเข้าร่วมผ่านเบราว์เซอร์พร้อมวิดีโอและเสียง การจับคู่วิ่งผ่านเซิร์ฟเวอร์ของ SplitCam เพื่อแนะนำอุปกรณ์ทั้งสองให้รู้จักกัน จากนั้นวิดีโอจะไหลระหว่างมือถือกับคอมพิวเตอร์ของคุณ

หลายกล้องใช้บน Mac ได้ไหม?

ได้ — ฉาก เลเยอร์ การสลับ คีย์ลัด แหล่งภาพ Phone Camera การอัด และกล้องเสมือน ทำงานบน macOS 13 ขึ้นไป ส่วนแหล่งภาพ Whiteboard, Application Audio, Replay และ Color ระบุไว้ในเอกสารเฉพาะบน Windows เท่านั้น
