三步完成配对

SplitCam Remote 自动发现局域网内的电脑——或扫描屏幕上的二维码立即配对。无需注册账号，无需云端中转。

像往常一样在 Windows 或 Mac 上打开 SplitCam，在设置中启用远程控制——电脑即可被局域网内的手机发现。

步骤 02

在手机上安装 SplitCam Remote
