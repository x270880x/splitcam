逐步操作：在 YouTube 上进行直播

从零到开播约需 5 分钟。已在 Windows 11 和 macOS 14 上验证，其他平台流程完全相同。

1
下载 SplitCam 约 1 分钟

SplitCam 是免费的直播工作室，内置 YouTube 推流预设——RTMP 地址已配置好，无需手动填写任何内容。安装包轻巧，支持 Windows 10/11、macOS 11+、iOS 16+ 和 Android 8+。无需账号、无需信用卡、无时间限制。

比普通编码器好在哪里：YouTube 预设省去手动配置推流地址的步骤；Replay Source 可用快捷键截取最近的精彩片段；背景替换直接在设备上运行，无需绿幕。独立创作者可以井然有序地开播，不需要第二双手。
2
搭建观众看到的画面 约 2 分钟

打开 SplitCam，将素材源添加到画布：摄像头用于人物画面，Game Capture 用于 DirectX/OpenGL 游戏，Screen Capture 用于教程和反应视频，Browser Source 用于叠加层，还可添加图片、视频片段或通过 Wi-Fi 接入的手机第二机位。

将这些图层整理为多个命名场景——片头、主场景、Just Chatting、BRB——并为每个场景绑定快捷键（F1、F2……）。直播中可即时切换，搭配 Fade / Luma Wipe / Slide 转场效果，画面更具电影质感。

创作者技巧：将 Browser Source 指向提醒小组件——新订阅者通知、Super Chat 提示、目标进度条。所有动态都在观众眼前呈现，而无需额外运行一个占资源的通知应用。
3
从 YouTube 获取推流密钥 约 30 秒

登录 studio.youtube.com → 点击右上角创建 → 开始直播。在左侧菜单中打开串流选项卡。

填写直播标题、说明和分类。在右侧设置面板中复制推流密钥（格式类似 xxxx-xxxx-xxxx-xxxx-xxxx）。

⚠ 安全提示：推流密钥相当于密码——不要公开展示，也不要提交到 git。密钥泄露后，任何人都可以向你的频道推流。你可以随时在 YouTube Studio 中重置密钥。
4
将 SplitCam 连接到 YouTube 约 1 分钟

在 SplitCam 中打开推流设置 → 选择 YouTube（已预设）。将推流密钥粘贴到输入框，点击「测试连接」——绿色对勾表示连接成功。

SplitCam 启动时会自动识别最佳硬件编码器——Nvidia 显卡用 NVENC，Intel 芯片用 QuickSync，AMD 用 AMF——通常无需手动调整编码设置。编码任务由显卡芯片承担，CPU 留给游戏或直播应用。码率参考如下：

5
点击「开始直播」 约 5 秒

点击 SplitCam 中的大按钮「开始直播」，推流即开始发送到 YouTube。约 10–15 秒后，YouTube Studio 中会出现预览画面。

顺畅直播的实用技巧

经验丰富的主播早已养成的好习惯，新手往往会忽略的细节。

🔇 开播前先静音麦克风

始终在麦克风静音状态下开始，准备好后再打开。这能避免那句「这能用吗？」意外上线。

🔌 使用有线网络连接

直播时以太网始终比 Wi-Fi 更稳定。如果必须用 Wi-Fi，请靠近路由器并使用 5 GHz 频段。

🔒 先用链接权限测试

在 YouTube Studio 中将首次直播设置为「仅限链接」可见。检查音频、画面和取景效果，确认无误后再切换为公开。

⏪ 用 Replay Source 截取精彩片段

SplitCam 的 Replay Source 会保留场景最近 5–10 秒的内容，按快捷键即可插入回放。一键实现慢动作或游戏高光重播。

📈 关注直播实时数据

SplitCam 在直播过程中实时显示编码器负载、丢帧率和带宽占用。发现问题时稍微降低画质——略软的 1080p 远好过卡顿的直播。

🎞️ 用场景代替单一摄像头

至少建立 3 个场景：「即将开始」 / 主播场景 / 「马上回来」。场景之间的切换让画面保持活跃，观感更专业。

YouTube 直播常见问题

SplitCam 用于 YouTube 直播是免费的吗？

是的——永久免费。直播画面无水印，也没有任何功能被锁在付费订阅后面。多平台直播、1080p 60fps、场景切换和虚拟摄像头从第一次启动起就全部可用。你的 YouTube 收益 100% 归你所有。

YouTube 直播应该设置多少码率？

1080p 30fps：3000–6000 Kbps。1080p 60fps：4500–9000 Kbps。720p：1500–4000 Kbps。SplitCam 内置 Upload Speed Test，可在开播前检测你的实际上行带宽。

可以同时向 YouTube 和 Twitch 推流吗？

可以。在推流设置中勾选 YouTube 和 Twitch（或其他任意平台），分别粘贴各平台的推流密钥，然后点击一次「开始直播」——SplitCam 会以点对点方式同时将推流发送到所有勾选的目标平台。无需云端服务器，无月费。详情请参阅多平台直播指南。

如何在 YouTube 频道上开启直播功能？

需要已验证的 YouTube 账号（手机号验证），且过去 90 天内无直播限制。移动端直播需要 50+ 订阅者。电脑端直播无订阅者数量要求——任何已验证账号均可开播。

还需要 OBS 吗，还是 SplitCam 可以替代它？

对大多数 YouTube 创作者来说，SplitCam 已足够独立完成工作：虚拟摄像头、AI 背景、多平台直播和场景切换全部内置，如果你已有 OBS 场景集合，它也可以直接导入。如果你依赖特定的 OBS 插件，继续使用 OBS 可能更方便。

SplitCam 会影响游戏帧率吗？

影响几乎可以忽略不计。SplitCam 将编码任务交给显卡的独立硬件——Nvidia 用 NVENC、Intel 用 QuickSync、AMD 用 AMF，启动时自动选择。CPU 和游戏渲染核心不受影响，绝大多数配置的帧率损失仅为 0–3%。

可以用手机在 YouTube 上直播吗？

可以——iOS 和 Android 版 SplitCam 支持直接从手机在 YouTube 上开播。YouTube 移动端直播需要频道拥有 50+ 订阅者。移动端默认支持 9:16 竖屏画布，非常适合 YouTube Shorts 直播。

配置 YouTube 直播需要多长时间？

首次配置约需 5 分钟——安装 SplitCam、添加摄像头、填入 YouTube 推流密钥。之后所有设置均已保存，后续开播几乎即时完成：打开应用，点击「开始直播」，在 YouTube Studio 中确认即可。
