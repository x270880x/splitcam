简明版——5 步免费直播教会礼拜
SplitCam 是一款免费软件，可同时将主日礼拜推流到 Facebook Live、YouTube Live 和教会网站（RTMP）。设置方法：
  1. 在音控台电脑上安装 SplitCam（Windows 或 macOS）。
  2. 添加摄像机作为场景图层——全景、讲台、诗班。
  3. 接入音频——从教会调音台通过 USB 音频接口输入。
  4. 添加 Browser Source，用于字幕和歌词叠加（ProPresenter 的网络输出即可）。
  5. 填入各平台推流密钥 → 点击「开始直播」，同时推送到所有平台。

主日礼拜直播——分步操作指南

完整的教会直播配置约 10 分钟即可完成——而且只需设置一次。之后每个主日直播只需点击一下。无论你用一台还是四台摄像机，流程都完全相同。

1
在音控台电脑上安装 SplitCam 约 2 分钟

在播放幻灯片的教会笔记本或控制室电脑上安装 SplitCam——支持 Windows 10/11 和 macOS 13+。完全免费，无需账号，不限直播时长，永远不会在画面上打水印。

为什么「免费」对教会很重要：大多数付费方案（vMix、Resi、BoxCast）从一次性 $60 起，直到每月 $500 或一次性 $1200。这笔钱用来买一台好摄像机或一套无线麦克风岂不更值？
2
将摄像机作为场景图层添加 约 3 分钟

将每台摄像机连接到电脑并添加为视频源。SplitCam 支持：

• USB 网络摄像头——Logitech C920 / Brio 均在 $200 以内
• DSLR 和摄像机——通过 HDMI 采集卡（Elgato Cam Link 4K，约 $130）
• 手机——通过 SplitCam iOS/Android App 作为 Wi-Fi 无线第二机位
• 预录视频——作为视频源播放（片头、洗礼视频、通知）

为每个所需机位创建场景：全景、讲台、诗班、歌词幻灯片、稍后回来。礼拜时用 F1–F5 快捷键切换。

建议：将歌词幻灯片单独设为一个场景，而不是一直叠加在画面上。直播操作员在敬拜开始时切到歌词场景，牧师讲道时切回讲台摄像头——就像现场投影仪的操作一样。
3
接入调音台的音频 约 2 分钟

这是提升直播质量最立竿见影的一步。直播音频必须来自教会调音台的输出，而不是电脑内置麦克风——后者只会收到满是回声的大厅环境音。

购买一个 USB 音频接口（Behringer UMC22 约 $50，Focusrite Scarlett Solo 约 $120），将调音台的 Aux/监听输出接入电脑，在 SplitCam 中选择该接口作为音频源。会众在现场听到的一切——讲道、诗班演唱、风琴——线上观众同样能听到。

音频比画面更重要。观众能接受 720p 的讲道画面，但无法忍受沉闷模糊的声音。先把预算花在音频上，摄像机可以之后再升级。
4
添加字幕和歌词 约 2 分钟

讲道者字幕条（下三分之一）：添加文字源，显示讲道者姓名和讲道主题，置于画面左下角。每个场景可单独控制显示——讲台场景显示字幕，敬拜场景隐藏。

歌词：添加 Browser Source，加载歌词页面。如果教会使用 ProPresenter，启用其 Network → Web URL 输出，将 SplitCam 的 Browser Source 指向该地址。敬拜领唱切换幻灯片时，歌词实时同步出现在直播画面中——免费的 OpenLP 通过其舞台显示的网页地址同样可以实现。

关于版权：在 Facebook / YouTube 直播带有版权的歌词需要流媒体许可证——例如 CCLI Streaming License（通常每年 $50–$300）。该许可证覆盖平台，与直播软件无关。
5
同时推流到 Facebook + YouTube + 教会网站 约 1 分钟

打开 Stream Settings（推流设置），勾选目标平台：

• Facebook Live——填入你的 Facebook 主页 → Live Producer 的推流密钥。
• YouTube Live——填入 studio.youtube.com → 「开始直播」的推流密钥。
• 教会网站——填入你的 RTMP 地址和密钥（Wowza、Vimeo、AWS IVS 或自建 Nginx-RTMP）。
• 更多平台——Twitch、Kick、X/Twitter 及 84+ 个预设推流目标。

点击一次「开始直播」，每个平台同时收到直播流。直播流从你的电脑直接传输到各平台的接收服务器——无需云端中转，无月费，不按观众数量收费。

周六彩排：直播前一天做一次完整的 30 分钟测试直播，隐私设置为「仅自己可见」。检查音量、摄像机取景和歌词显示。第一次主日直播不是发现麦克风噪音或镜头盖没摘的时候。
为什么多平台推流对教会至关重要

不同的会众在不同的平台上观看。年长的成员通过教会网站的链接观看。在外地的子女在 Facebook 上收看。年轻人在 YouTube 上观看。行动不便的成员在平板上打开最快加载的那个。

只选一个平台，就会失去其他所有人。SplitCam 可以同时向所有平台直播，从你的电脑直接推送，完全免费。替代 Restream（$19/月）和 StreamYard（$25/月）。

每周直播教会的实战技巧

这些细节决定了一场直播是专业还是业余。

🎤 始终以静音状态开始直播

每次直播开始时静音麦克风，显示「欢迎——礼拜将于 10:30 开始」的幻灯片。礼拜正式开始时再取消静音。这样早到的观众就不会听到「能听到吗？」的测试声。

📺 给直播电脑接有线网络

礼拜中途 Wi-Fi 断线会直接让直播中断。给控制室拉一根网线，8 米的网线只需 $10，却是提升稳定性最划算的投入。

🎬 制作「过渡」场景

场景 1：「礼拜将于 10:30 开始」配背景音乐。场景 2：「我们正在敬拜——欢迎加入」（敬拜时段）。场景 3：讲台（讲道时段）。场景 4：「感谢您的参与——下周日 10:30 再见」。

📊 安排专人监控直播状态

SplitCam 的实时指标全程显示编码器负载和连接状态。如果指示灯变红，立即降低码率——别让整场讲道在画质劣化的状态下播完。

📝 坚持周六彩排

每个周六做一次完整的直播彩排，30 分钟，隐私设为「仅自己可见」。把问题扼杀在上线之前。

⛪ 遵守 CCLI 许可证要求

在直播中播放圣诗和赞美歌曲需要 CCLI Streaming License（根据教会规模，每年 $50–$300）。没有该许可证，Facebook 和 YouTube 可能会自动静音或屏蔽你的直播。

教会直播常见问题

教会直播最好的免费软件是什么？

SplitCam 是教会最佳免费选项之一：内置多平台推流（同时推到 Facebook + YouTube + 教会网站）、多摄像机场景切换、Browser Source 歌词叠加，无水印、无订阅费。OBS Studio 也免费，但多平台推流需要插件，对志愿者操作员来说上手较难。

我能同时将主日礼拜直播到 Facebook 和 YouTube 吗？

可以——SplitCam 内置多平台推流。填入 Facebook Live 和 YouTube Live 的推流密钥，点击一次「开始直播」，两个平台同时接收直播流。同时还可以通过 RTMP 推送到教会自己的网站。直播流从教会电脑直传各平台，无需云端中转，也没有月费。查看多平台推流详情。

教会直播软件要多少钱？

SplitCam 100% 免费，无水印，不限时长。付费选项参考：vMix Basic HD 一次性 $60（4 路输入，1080p，含推流）、vMix Pro 一次性 $1200（完整功能）；vMix 还有免费的 Basic 版，分辨率上限 768×576；ProPresenter $499+（侧重敬拜展示，不是完整直播编码器）、Resi $99–$249/月（云端）、BoxCast $99–$499/月。

主日礼拜直播需要单独的电脑吗？

不一定——如果机器性能足够（建议 Intel i5 第 8 代及以上 + 16 GB RAM），SplitCam 可以跑在同一台运行幻灯片或 ProPresenter 的电脑上。3 台及以上摄像机 1080p 配置建议使用独立直播电脑，以避免丢帧。

如何在教会直播中添加歌词？

在 SplitCam 中添加 Browser Source，指向歌词页面。如果使用 ProPresenter，启用其 Network → Web URL 输出，将 SplitCam 的 Browser Source 指向该地址。如果使用 OpenLP 等免费软件，指向其舞台显示的网页地址。诗班切换幻灯片时，歌词会实时出现在直播画面中。注意：直播有版权保护的歌词需要 CCLI Streaming License。

教会直播可以使用多台摄像机吗？

可以——SplitCam 支持无限数量的摄像机作为场景视频源。将每台摄像机接入电脑（USB 网络摄像头、Elgato Cam Link 等 HDMI 采集卡接 DSLR，或通过 SplitCam 手机 App 作为无线第二机位）。创建全景、讲台近景、诗班、歌词幻灯片等场景，礼拜时用快捷键（F1、F2、F3……）快速切换。

SplitCam 能在教会的旧电脑上运行吗？

SplitCam 支持 Windows 10/11 和 macOS 13+，硬件要求不高。多摄像机 1080p 直播建议 Intel i5 第 8 代或 Ryzen 5 + 16 GB RAM；单摄像机 720p 直播，i3 / 8 GB RAM 的旧笔记本也能胜任。硬件编码（NVENC / QuickSync / AMF）可大幅降低 CPU 负载。

SplitCam 用于主日礼拜直播够稳定吗？

够——SplitCam 自 2003 年持续开发，被全球各地的教会和电视台使用。编码器采用硬件加速保障稳定性，状态监视器实时显示丢帧情况，多平台推流系统直连各平台——某个平台中断不影响其他平台。建议在周日首次直播前的周六进行一次彩排。
