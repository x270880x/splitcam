在线教学设置——把你的幻灯片和你的画面合成一路摄像头信号。

你展示的一切——一页幻灯片、一个应用程序、一幅手绘、你的网络摄像头——都叠放在同一幅画面里，一层压着一层。SplitCam 把它们每一个都称为一个图层，并把合成好的画面当作一台普通摄像头交给你的会议应用：Zoom、Google Meet、Microsoft Teams 以及总共 60+ 款应用都能在摄像头下拉列表里找到它。你的学生同时看到你和讲解材料，而共享屏幕、停止共享、“大家都能看到吗？”这一套流程不再是课堂的一部分。

快速回答——在线教学设置是如何搭起来的
  1. 把 SplitCam 装在你用来上课的电脑上——课堂另一端的一切都不会有任何改变。
  2. 把这节课的材料拖到场景上：一份 PDF、一个屏幕或窗口、一个图片文件夹、你的网络摄像头。
  3. 按学生看到的样子调整大小——材料放大，网络摄像头放在你从不书写的角落。
  4. 把每一种布局保存为一个场景——讲课、例题演算、操作演示——并在授课时切换场景。
  5. 在会议应用里选择“SplitCam Camera”作为摄像头。

如何一步步搭建在线教学

以下是教学中值得了解的图层。其中有几个只存在于某一个平台上，所以每张卡片都标注了所属平台——请认真对待这个标签，因为发现缺了某个源的最糟糕时机，就是课上到一半的时候。

1
安装 SplitCam——只装在授课电脑上 ~ 2 分钟

SplitCam 装在你本来就用来上课的电脑上——Windows 10 或 11，或者 macOS 13 及更高版本——并在系统已有的摄像头之外再添加一台。真正重要的那一半，恰恰是不变的那一半：你的学生打开同一个会议链接，用同一个应用，在同一台设备上，完全不会被告知有任何不同。如果这台授课电脑由别人管理，就需要请对方替你运行安装程序。

2
导入你已经准备好的材料 ~ 4 分钟

这节课其实已经躺在你硬盘的某个地方：你导出的演示文稿、你扫描的练习题、你打算演示的网站、那一整个照片文件夹。把文件直接拖到场景上，它就变成一个图层。真正改变教学的一点是，它们可以同时全部处于实时状态，而不是一次只显示一个——你不必再纠结只让学生看到哪一样东西。添加一次，下学期它们还在。再往下的卡片会逐一介绍每种类型，并标明它所在的平台。在 Windows 上，如果你打算播放视频片段，请再添加一个应用程序音频源，这样片段的声音就能和你的麦克风一起传到学生那里。

3
把材料放大，把自己缩小 ~ 2 分钟

把材料拖到几乎填满整个画面，然后把网络摄像头放到一个你不会在上面书写的角落——对大多数人来说是右下角。现在，用学生的视角来判断：你展示的一切，到了另一端都被塞进一个差不多明信片大小的画面块里，显示在笔记本电脑上，或者一部举在手边的手机上。如果在那个尺寸下你连自己的坐标轴标签都看不清，那谁都看不清。在 Windows 上，你还可以放大整幅画面——在不选中任何图层的情况下把鼠标指向细节处并滚动滚轮。先点击媒体列表中网络摄像头旁边的锁定图标，这样在其他一切都被放大时，它仍会保持原位。

4
保存布局，然后不停顿地切换它 ~ 1 分钟

把图层布置好一次，然后把这套布局作为一个场景保存到场景列表里，你实际会做的每一件事都对应加一个场景——一个讲课视图、一个例题演算视图、一个操作演示视图。切换只需点击你想要的那个场景；在 Windows 上，你还可以给每个场景设一个快捷键，不用碰鼠标就能换布局。真正重要的是从学生座位看过去的样子：材料在变，而画面还是一秒钟前的那个尺寸和形状，摄像头从不中断。没有人会看到一块黑屏，你也再不用说“让我停止共享一下”。

5
在 Zoom、Meet 或 Teams 中选择 SplitCam Camera ~ 1 分钟

打开会议应用里的摄像头设置，从你的网络摄像头已经在其中的那份列表里选择“SplitCam Camera”——在 Zoom 和 Google Meet 里它在设置 → 视频下，在 Microsoft Teams 里在设置 → 设备下。它在 60+ 款应用中都表现为一台普通网络摄像头，无需插件，也无需针对每个应用做集成，所以同一份列表在课上到一半时照样管用：课已经开始后再切换到它，画面就这么换了过来。在 macOS 上，这台摄像头是一个系统扩展，所以 Mac 会在第一次使用时请你予以允许。

你可以摆在在线课堂面前的东西

一份幻灯片或练习题的 PDF——Windows 和 macOS

把你的幻灯片导出为 PDF，或者拿你手头已有的练习题，把文件作为一个 PDF 图层添加进来。课程进行时你在图层内部翻页，于是关于第四页的问题就在第四页上得到解答，而不是在菜单里翻找一通之后。

一组图片做成幻灯片放映——Windows 和 macOS

添加一个幻灯片放映图层，把你的图片放进去：重新排序、移除不需要的、按固定间隔自动切换、循环播放整组，还可以用一张动态 GIF——在几秒钟的动画比一张静图更能说明问题的地方。在 macOS 上，你也可以把三张或更多图片直接拖到场景上，幻灯片放映图层就会自动搭好。

一块可以书写的白板——仅限 Windows

一个用鼠标或触控板手绘的图层；按住 Shift，画出的线就是直的，这个图层还带有撤销、重做和清除全部。它只能手绘，这让它成为一处在全班面前一步步解题的地方，而不是一种复现印刷图表的手段。macOS 版本没有这个功能。

你的屏幕、某一个窗口，或者一块区域——Windows 和 macOS

捕获整个屏幕、单个应用程序窗口，或者只截取屏幕上要紧的那一部分，最高可达 4K，并显示光标，让全班能跟上你指向哪里。在 Windows 上，全屏捕获还能显示你的鼠标点击和按键——这正是一场学生能跟着做的软件演练与一场他们只能干看的演练之间的差别。

一个你可以在里面点击的网页——Windows 和 macOS

为任何存在于浏览器里的东西添加一个浏览器图层：一个网页版幻灯片工具、一个绘图网站、一个仿真模拟。双击该图层进入交互模式，你就能在全班看着这个页面的同时在里面点击和输入，无需离开 SplitCam，也无需另开一个窗口。

把你的手机当作第二台摄像头——Windows 和 macOS

添加一个手机摄像头源，用你的手机扫描二维码。它通过网络接入，不需要线缆，也不需要采集硬件，于是你可以把它对准一本书、一张印刷图表或桌上的某件物品，在讲解需要一件实物时切换到那个角度。

能自我翻译的文字——仅限 Windows

一个文字图层可以放一个标题、一条指示，或者你反复强调的那个关键术语，它有自己的颜色、身后有一块背景面板，字母周围还有一圈描边，这样在花哨的幻灯片上它仍然清晰可读。在 Windows 上，它还能把你输入的内容自动翻译成另一种语言，如果你班上有一部分人是用第二语言在听课，这一点值得了解。它翻译的是输入的文字，而不是你口头说出来的话。

三种值得保存为场景的课堂布局

清晰可读，就是这里的全部功课。下面每一种布局都由一个问题决定——此刻全班应该在读的是什么，它够不够大、读得清吗？搭建一次，各自保存为一个场景，这一学期剩下的时间就只是按一下键的事。

讲课——幻灯片铺满画面

一页 PDF 或一张幻灯片放映图片占据几乎整幅画面；你的网络摄像头小小地待在一角，避开文字。全班以接近全屏共享所能给到的尺寸阅读幻灯片，同时依然看得到是谁在讲、你在看哪里。

例题演算——白板铺满画面

在 Windows 上，一个白板图层占据演算区域，你边讲边往里写。写得比你觉得自然的大两三倍——你是在给一个画面块写字，而不是给你的显示器写——并在两道题之间清空白板，而不是滚动去找新的空白。

操作演示——应用程序铺满画面

对你正在讲的软件做窗口捕获，显示光标，并且在 Windows 上还显示你的点击和按键；你的网络摄像头依旧小小地待在它的角落。全班看得到你打开了哪个菜单、按了哪个键，而不只是最后出现的结果。

讨论——你铺满画面

一个场景里只有你的网络摄像头，占满全画面。当你从展示转为提问时切换到它，全班就以一个看得清表情的尺寸看到你的脸。当有学生问到幻灯片答不上来的问题时，这也是该备好的场景。

来自每周在线讲课的老师们的专业建议

以学生拿到的尺寸来评判每一种布局

上课前，把 SplitCam 预览缩小到差不多学生实际拿到的那个画面块大小，然后隔着一张桌子的距离看你自己的材料。任何要你凑近才看得清的东西都太小了——字号更大、屏幕上一次显示的东西更少、每种布局只讲一个要点，而不是把一整页缩小硬塞进去。

上课前就定好哪个角落是你的

选定你的网络摄像头待的那个角落，然后就绝不往里书写、指点或丢图表。一个你得在课上到一半时挪动的图层，就是一个全班都看着你挪动的图层。

把材料放在你视线落点的地方

把场景布置成让你正在讲的东西位于屏幕靠上、靠近摄像头的位置。这样你最终是看着全班，而不是低头偏向一侧，也没有人会整节课都在猜你到底在读什么。

让计时器来结束活动，而不是靠你的记性

对于时长固定的活动，一个自动化计时器图层会在全班看得见的地方倒计时，这样没人需要问还剩多久。在 Windows 上，计时器归零时可以切换场景，于是课程会自己回来，而不是等你想起来才回来。

排练切换，而不是排练课程

在没人看的时候花五分钟切来切去场景就够了。课你早就熟了；唯一要建立的新肌肉记忆是哪个场景装着哪种布局——在 Windows 上，还有哪个键能把它调出来。做上一遍，你在上课时就不再去想这个软件了，而这正是搭建它的全部意义。

边讲边把它录下来

SplitCam 会把全班正在看的画面写入你自己电脑上的一个文件，于是缺席这次课的学生拿到的正是其他所有人看到的东西。在 Windows 上，文件以分段 MP4 写入，所以一次崩溃或一次断电不会让你损失整段录制。

老师们如今怎么做，以及真正改变的是什么

这不是一张厂商对比表——下面是老师们在课上展示东西时早已在做的四件事。它们各自都能做到 SplitCam 做不到的事，而 SplitCam 所负责的部分，比一张对比图表暗示的要窄得多。课堂仍然由会议应用来运行。

共享你的屏幕

它管用，而且每个会议应用都有。但你的脸变成了共享内容旁边的一个小缩略图，而不是同一幅画面的一部分，每换一次材料都意味着要另找一个窗口、重新挑选共享什么，而任何没在你电脑上打开的东西——一本书、一幅你刚画的草图——根本没法放进去。

一台实物展台

没有别的东西能像它这样展示你的双手在一张真实纸页上操作，对于实物材料它仍然是最好的答案。不过它只有一个固定角度，也是又一台要拥有的设备。它也不是非此即彼：大多数实物展台都作为一台普通网络摄像头接入，所以 SplitCam 可以把它当作幻灯片旁边的一个图层收进来，而不是用它取代幻灯片。

投屏一台平板

手写效果很好，触控笔正是干这个的合适工具。它需要第二台设备、一个投屏应用和一个共享窗口，而且在投屏开着的时候，你的脸是共享内容旁的一个缩略图，而不是全班正在读的同一幅画面的一部分。

一块数位板来驱动 PowerPoint 或 Keynote

在演示应用内部画在幻灯片上的墨迹看起来很对，而且会跟着幻灯片保存下来。不过它只存在于那个应用内部：一旦切到浏览器或你正在演示的某个软件，这支笔就无处可写了。

改用一路摄像头信号

SplitCam 把画面组装好，当作一台摄像头交给会议应用。你和材料留在同一幅画面里，布局切换时没有任何东西中断，而材料可以在同一刻既是一份 PDF、一个屏幕、一个网页，也是你手机的摄像头。手绘用鼠标或触控板完成，仅限 Windows。

在线教学设置常见问题

我的学生需要安装什么东西吗？

不需要。SplitCam 只在你的电脑上运行，在那里它表现为一台额外的摄像头。全班用他们一直在用的同一个应用加入同一个会议链接，而到达他们那里的是一路摄像头画面——和他们自己的网络摄像头发送的是同一种视频。

“SplitCam Camera”会出现在 Zoom、Google Meet 和 Microsoft Teams 里吗——我能在课上到一半时切换到它吗？

两个都能。在 Zoom、Teams 或 Meet 里打开设置 → 视频，“SplitCam Camera”就和你的网络摄像头一起出现在摄像头下拉列表中；它在 60+ 款应用中都以同样的方式出现，无需插件，也无需针对每个应用做集成。你可以在课已经开始之后打开那个下拉列表，画面就这么换过去，不用退出也不用重新加入。

我怎么把 PowerPoint 或 Keynote 的幻灯片放进来？

两条实在的路子。把幻灯片导出为 PDF，把文件作为一个 PDF 图层添加进来——然后你在授课时于图层内部翻页。或者，如果你更愿意直接驱动 PowerPoint 或 Keynote、用上它全部的动画和它自带的笔，那就对演示窗口做窗口捕获，把它放进场景里。

我能在幻灯片上书写吗？

SplitCam 有文档记载的，是它自己的一个白板图层，在 Windows 上：手绘线条，按 Shift 画直线，撤销、重做和清除全部。它是一块用来书写的画布，而不是一支浮在你其他材料之上的记号笔——所以通常的布局是幻灯片占据画面大部分、白板在它旁边，或者是当演算开始时切换过去的一个场景。如果你想要落在幻灯片本身上的墨迹，那就用 PowerPoint 或 Keynote 自带的笔来画，并捕获那个窗口。

我能用触控笔或数位板来书写吗？

白板在文档中记载的是用鼠标或触控板手绘；关于笔压或触控笔支持没有任何公开说明，所以不要围绕它来设计一节课。如果笔输入是你教学方式的核心，那就在一个能正确支持你数位板的应用里书写，再用窗口捕获把那个窗口带进场景。

我想播放一段视频片段——全班听得到声音吗？

把片段作为一个视频图层添加进来，它就在场景里播放。对于从另一个程序里发出的声音，比如浏览器标签页里的一段视频，Windows 提供了一个应用程序音频源，直接接过那个程序的声音，并把它和你的麦克风混在一起。麦克风的“Accentuate”选项会在每次听到你说话时压低其他声源，这样你就能盖过片段说话——它对任何声音都会作出反应，而不只是你的嗓音，所以使用它时请戴上耳机。

我能为缺席的学生录下这节课吗？

可以。SplitCam 把组装好的画面录制成你自己电脑上的一个文件——没有云、没有门户网站、没有链接，所以你怎么分享文件都行，用你学校本来就在用的方式。在 Windows 上，它以分段 MP4 写入，这意味着一段被中断的录制仍然是可以播放的。

这一切在 Mac 上都能用吗？
