SplitCam/Multi-camera
多机位直播

免费多机位直播软件——在摄像头之间切换，或让它们同时出镜。

「多机位」其实是两件不同的事，而人们用同样的词搜索它们。一是切换：画面里只有一台摄像头，由你决定是哪一台。二是合成：两台摄像头同时出现在画面里。SplitCam 用同样的两个概念把两件事都做到了——场景里的图层，以及直播中实时切换的场景——支持 Windows 和 macOS，完全免费。

四步搭好
  1. 把摄像头添加为图层。USB 网络摄像头、通过 RTSP 接入的 IP 摄像头、一路 NDI 信号源，或者通过 Phone Camera 素材源接入的手机。每一个都会成为一个可以摆放和缩放的图层。
  2. 每种镜头搭一个场景。一个全景、一个特写、一页幻灯片加上角落里的小摄像头画面。场景只是图层的一种排布；节目需要多少就建多少。
  3. 直播中切换场景。点击场景、按下它的快捷键，或者按 Stream Deck 上的按键、手机上 SplitCam Remote 应用里的按钮。选一种转场：硬切、淡入淡出、滑动、划像，或者 stinger 转场动画。
  4. 把结果送到任何地方。同时推到 84+ 个平台、录制成文件，或通过虚拟摄像头送进 Zoom、Teams 和 Meet——它们看到的就是当前直播中的那个场景。

切换：画面里只有一台摄像头，由你选哪一台

这是导播的活儿——全景、特写、再回全景。在 SplitCam 里，就是每种镜头一个场景，然后在场景之间切换。

一个场景就是一种镜头

把全景摄像头放进一个场景，把特写摄像头放进另一个。切换镜头就是切换场景，观众看到的是干净的一刀切，而不是一个图层被拖来拖去。

场景之间的转场

硬切、淡入淡出、滑动、扫动、亮度划像，或者 stinger——你自己的转场动画。转场是切换动作本身的属性，所以从不同的地方进入同一个场景，可以用不同的方式。

不用鼠标也能切换

在 Windows 或 macOS 上给每个场景绑定一个快捷键。如果你有 Stream Deck，Windows 上有 SplitCam 官方插件可用（需要 SplitCam 10.8.25 或更新版本）。iPhone 上免费的 SplitCam Remote 应用隔着房间也能做同样的事。

一场节目里的多台 IP 摄像头

一个场景里放三台或更多 IP 摄像头，是有文档记录并经过测试的配置。每一台都是一个图层；每一台都可以出现在任意多个场景里。

合成：两台摄像头同时出现在画面里

画中画、左右分屏、屏幕共享上叠一个摄像头。完全不涉及切换——这是在同一个场景里堆叠图层。

堆叠、摆放、缩放

每个素材源都是一个带位置和尺寸的图层。把第二台摄像头放到第一台的一角，或者把画面从中间一分为二。画布上看到的是什么，输出的就是什么。

摄像头叠在任何东西上

第二个图层不一定非得是摄像头。底下是一页幻灯片、一个浏览器页面、一个全屏游戏或一个窗口捕获，上面是你的脸——同一套机制。

手机当第二机位

添加一个 Phone Camera 素材源，扫描二维码，手机就通过自带的浏览器接入，视频和音频一并传来——手机上什么都不用装。把它架在小三脚架上，拍俯视或全景。

视频通话里两台同时出镜

在 Zoom、Teams 或 Meet 里选择 SplitCam 作为摄像头，通话收到的就是合成后的场景：两台摄像头，或一台摄像头加一页幻灯片，合成一幅画面。

多机位工作中，SplitCam 做不到的事

在把节目建立在它之上以前，先看清上限。没有 Preview/Program——你是直接切到某个场景，而不是先预监再切——也没有展示各路素材源预览的多画面墙。录制捕获的是合成后的场景，只有一个文件，而不是每台摄像头各自一份供后期剪辑。没有任何功能能替你让摄像头平移、俯仰或变焦。NDI 只进不出。没有自动切到正在说话的人，也没有给远程嘉宾的浏览器链接。如果你的制作需要其中任何一项，它需要的是一台导播切换台——Windows 上的 vMix，或者硬件 ATEM——本页不会劝你放弃。如果它需要的是把摄像头放进场景、把场景干净利落地切换，那正是这里提供的东西。

多机位直播——常见问题

这真的是免费的多机位直播软件吗？

是的。场景、图层、带转场的切换、虚拟摄像头、录制，以及向 84+ 个平台的多平台直播，全都在免费下载里，无水印，也没有更高的付费档位。

我能用多少台摄像头？

SplitCam 没有公布固定的上限，我们也不会在这里编一个。一个场景里放三台或更多 IP 摄像头是有文档记录的配置；实际的上限取决于你电脑的 CPU、GPU 和 USB 带宽，而不是软件里的某个数字。

切换摄像头和两台摄像头同时出镜，有什么区别？

切换是画面里一次只有一台摄像头——各自独立的场景，你在它们之间切。同时出镜是同一个场景里的图层——画中画或左右分屏。SplitCam 两者都能做；你想要哪一种，决定了你是搭好几个场景还是只搭一个。

不碰键盘也能切换摄像头吗？

可以。在 Windows 和 macOS 上，每个场景都可以绑定快捷键；Windows 上支持 Stream Deck；免费的 SplitCam Remote 应用可以在 iPhone 上切换场景。

它会把每台摄像头分别录制吗？

不会。录制捕获的是合成后的场景，只有一个文件。如果你需要每台摄像头各自一个文件供后期剪辑，那是 ISO 独立录制，需要 vMix 这样的导播切换台。

手机摄像头需要装 App 吗？

不需要。添加一个 Phone Camera 素材源，用手机扫描二维码，手机就通过自带的浏览器接入，视频和音频一并传来。配对会经过 SplitCam 的服务器，把两台设备介绍给对方；之后视频在你的手机和电脑之间直接传输。

多机位在 Mac 上能用吗？

能——场景、图层、切换、快捷键、Phone Camera 素材源、录制和虚拟摄像头都能在 macOS 13 及更高版本上运行。Whiteboard、Application Audio、Replay 和 Color 素材源只在 Windows 上有文档记录。
