常见问题

快速解答。

下载前你需要了解的一切。

SplitCam 真的免费吗？

是的——个人和商业用途完全免费。无水印、无时间限制、不会逼你升级到“Pro”版本。所有功能从第一天起就全部解锁。

它支持哪些操作系统？

SplitCam 支持 Windows 10/11、macOS 11+、iOS 16+（iPhone 和 iPad）以及 Android 8+。下载按钮会自动识别你的操作系统。

我能导入 OBS Studio 的场景吗？

可以——SplitCam 一键导入 OBS 场景集合。你所有的素材源、场景、转场和快捷键都会原样迁移，无需重新搭建。看看两者的对比：SplitCam 对比 OBS。

我可以同时推流到多少个平台？

最多可同时推流到 8 个平台；没有硬性上限——实际瓶颈是你的上传带宽。推流以点对点方式从你的电脑直接发送到每个平台，无需云端服务器中转。多平台直播完整指南 →

SplitCam 会拖慢我的游戏吗？

不会——SplitCam 默认使用硬件编码器（Nvidia 用 NVENC、Intel 用 QuickSync、AMD 用 AMF）。编码在独立的 GPU 编码单元上运行，让 CPU 和显卡的主要核心专心跑游戏。大多数用户的帧率损失只有 0–3%。

我能把 SplitCam 当作 Zoom/Teams 里的虚拟摄像头用吗？

可以——SplitCam 把你的整个画面（包含场景、特效、叠加层、AI 抠背景）作为虚拟摄像头输出到 Zoom、Microsoft Teams、Google Meet、Discord 以及 60 多款其他应用。竖屏（9:16）和横屏（16:9）模式都支持。

我需要什么样的硬件？

最低配置：Intel Core i3 / AMD Ryzen 3、4 GB 内存、核芯显卡。游戏直播推荐配置：Intel Core i5+ / AMD Ryzen 5+、8 GB 内存、支持 NVENC/AMF 的独立显卡。在较旧的笔记本电脑上也能流畅运行。

SplitCam 会收集我的数据吗？

你的场景、录制文件和推流设置都保存在你自己的电脑上。除非你主动开启「云端项目」来在多设备间同步设置，否则 SplitCam 不会上传任何内容到云端。
