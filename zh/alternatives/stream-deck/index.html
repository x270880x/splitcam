下面列出的都是 SplitCam Remote 有据可查的功能——不是一个控制台理论上可能做到的愿望清单。

在手上切换场景

这正是大多数人想要控制台的原因。换摄像头、换布局、切到幻灯片——不用走回电脑前，也不用在全屏游戏后面翻找窗口。

开始和停止直播与录制

开播、下播、开始或停止录制、抓拍快照、暂停或静音——正是那些一伸手去够键盘就会被观众看得一清二楚的时刻，你最需要的操作。

App 会把直播名称和状态回传到你手上，站在房间另一头也能确认是否正在直播，而不用靠猜。

几秒配对，只走你的局域网

扫描 SplitCam 设置里「Remote Control」标签页上的二维码，或者让 App 自己通过 Wi-Fi 找到你的电脑。扫码这条路径会经过我们的服务器来给两台设备牵线；Wi-Fi 自动发现则始终留在你自己的网络里。

为什么不买硬件也值得这么用

选手机的理由不是它更便宜，而是就这件事而言，它并不更差。

按键本来就在你口袋里

标签随场景自动变化

实体按键的图标和文字得手动设置。而屏幕直接显示当前的场景列表，重命名场景之后，按键上不会留下一个过时的旧标签。

SplitCam 做不到的事

这里每一篇对比文章都放了同一份清单，因为你应该能很快把我们排除掉，而不是下载之后才发现这些。

嘉宾无法通过链接加入

没有可以发给别人的浏览器链接。你可以用窗口捕获把嘉宾所在的 Zoom、Meet 或 Discord 窗口放进场景里，这确实可行，但那是变通办法，不是正式功能。

没有 Preview/Program 预监切换，没有多画面监看

你是直接切到某个场景，而不是先预监再切出。也没有一整面素材源预览墙。如果你习惯按正规切换台的流程导播，会立刻觉得别扭。

不能按摄像头分别录制，不支持 PTZ 控制

录制的是合成后的场景，而不是每个摄像头各存一个文件供后期剪辑。SplitCam 里没有任何功能能替你让摄像头平移、俯仰或变焦。

NDI 只进不出

你可以把 NDI 作为素材源接进来。但 SplitCam 不是 NDI 发送端，不能供另一台机器拾取。

部分素材源仅限 Windows

文档中注明仅 Windows 可用的有：Whiteboard、Application Audio、Replay 源和纯色 Color 源。场景、图层、虚拟摄像头、多平台直播和录制在两个系统上都能用。

手机遥控目前只有 iOS 版

SplitCam Remote 已上架 App Store；Android 版正在开发中，尚未发布。把手机当摄像头用是另一回事，并不限于 iOS。

关于 Stream Deck 替代方案的常见问题

SplitCam Remote 真的免费吗？

是的。它是 SplitCam 的配套 App，而 SplitCam 本身就免费，无水印，也没有付费版本。两者都没有需要解锁的东西。

它能完全取代 Stream Deck 吗？

只有当你要按的一切都属于 SplitCam 时才可以。它能切换场景、开始和停止直播与录制、抓拍快照和静音——但没法在其他应用里按按钮。如果你的工作流横跨多个程序，那就买硬件。

有 Android 版吗？

暂时还没有。SplitCam Remote 的 iOS 版已在 App Store 上架，Android 版正在开发中。

我已经有 Stream Deck 了，SplitCam 能配合它使用吗？

可以。SplitCam 从 Windows 版 10.8.25 起加入了 Stream Deck 支持。

手机是怎么找到我的电脑的？

两种方式：扫描 SplitCam 设置里「Remote Control」标签页上的二维码，或者让 App 通过 Wi-Fi 自动发现你的电脑。两种都行；第一次连接时扫二维码更快。

连接会经过你们的服务器吗？

配对会经过 SplitCam 的服务器，由它把手机介绍给你的电脑。只有这一次握手会走服务器——两台设备找到彼此之后，控制指令就在你自己的两台设备之间传输。
