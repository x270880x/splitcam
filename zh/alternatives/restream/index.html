Restream 替代软件

免费的 Restream 替代软件，直播永远不离开你的电脑。

Restream 从你这里接收一路直播，再用它自己的服务器转发出去，并为此按月向你收费。SplitCam 只在你的电脑上编码一次，然后自己向每个平台建立连接——84+ 个目标平台，不经任何第三方中转，也没有任何订阅。

快速上手——用 SplitCam 取代 Restream
  1. 在你平时直播的那台电脑上安装 SplitCam。需要 Windows 10/11 或 macOS 13+。
  2. 添加你的目标平台，粘贴各平台的推流密钥——84+ 个平台已预先配置好。
  3. 为每个目标平台单独设置码率，或直接沿用 SplitCam 为该平台选好的默认值。
  4. 运行内置的上传测速，确认你的带宽足以覆盖所有目标平台的总和。
  5. 点击「开始直播」。每个平台都直接从你的电脑收到画面。

那笔月费究竟买到了什么

云端多平台直播服务本质上是一个中转站。你把一路直播发给它，它在自己的服务器上留一份副本，再把这份副本转发到你连接的每个平台。便利是真的，背后的安排也同样真实：你的直播要经过一段并不由你掌控的基础设施，而账单每月照样寄来——不管你那个月直播了四次，还是一次都没播。

你的直播要绕一段路

每一帧画面都先送到中转服务，之后才到观众那里。这多出一段网络跳转，也多出一个在你直播期间必须一直正常运行的服务。

账单按月来，直播却不是

订阅费是按日历收的，而不是按你实际播出的时长。一个月只播两次，那没播的二十六天照样要付钱。

上限由别人来定

画质、目标平台数量和功能，取决于你在哪一档套餐。想改动其中任何一项，都不是改个设置那么简单，而是一次花钱的决定。

编码这件事，你的电脑本来就在做

直播里最耗资源的部分是视频编码，而这件事你的电脑本来就在做。画面一旦编码完成，把它发给四个平台和发给一个平台的区别，只是四条网络连接而已。SplitCam 自己把这些连接建起来——在 Windows 上用 NVENC、QuickSync 或 AMF 硬件编码，在 Mac 上用 VideoToolbox，然后直连每个平台的接收服务器。

编码一次，同时发往多处

分辨率和码率相同的目标平台共用同一次编码；给某个平台单独设置参数，它就会单独占用一次编码——这也正是下面那项「按目标平台单独设置」是一项真功能、而不只是一个开关的原因。

按目标平台单独设置码率

想给 Twitch 6 Mbps、给 Facebook 2.5 Mbps？分别设置就行，不必让所有平台共用中转服务的同一套参数。

你和平台之间没有中间人

只要平台是通的、你的网络是通的，你的直播就是通的。中间没有第三方服务，也就不会有谁替你出故障。

84+ 个平台已预先配置

Twitch、YouTube、Facebook、Kick、TikTok、X 等平台都已经在列表里，并配好了合理的默认值。

一个平台掉线，不会拖垮其余平台

每个目标平台都从你的电脑单独建立一条连接，所以某个平台宕机，其他平台照常直播。走中转服务则是一路上传供给所有平台——正常时更省心，出问题时就是单点故障。

什么时候 Restream 才是更好的选择

这是直连方式实实在在的局限，换过来之前值得先弄清楚。中转服务只需要你上传一路。而直连需要所有目标平台的码率总和同时从你家里发出去——按推荐设置同时推四个平台，大约需要 19–20 Mbps 的上传带宽：Twitch 6、YouTube 4.5、Facebook 3，第四个平台 2.5，视频合计 16 Mbps，再加上大约 20% 的余量。如果你的网络撑不住这个量，云端中转就不只是图省事，而是让多平台直播根本得以成立的前提。SplitCam 内置了上传测速，你可以在下决心之前先测一测；你也随时可以少推几个平台、把码率调低——但如果瓶颈就在上传带宽上，那么 Restream 解决的问题，SplitCam 解决不了。用笔记本在酒店网络或手机网络下直播也是同理：网络的不稳定会被中转服务吸收掉，而不是让观众直接看到。

SplitCam 做不到的事

这里每一篇对比文章都放了同一份清单，因为你应该能很快把我们排除掉，而不是下载之后才发现这些。

嘉宾无法通过链接加入

没有可以发给别人的浏览器链接。你可以用窗口捕获把嘉宾所在的 Zoom、Meet 或 Discord 窗口放进场景里，这确实可行，但那是变通办法，不是正式功能。

没有 Preview/Program 预监切换，没有多画面监看

你是直接切到某个场景，而不是先预监再切出。也没有一整面素材源预览墙。如果你习惯按正规切换台的流程导播，会立刻觉得别扭。

不能按摄像头分别录制，不支持 PTZ 控制

录制的是合成后的场景，而不是每个摄像头各存一个文件供后期剪辑。SplitCam 里没有任何功能能替你让摄像头平移、俯仰或变焦。

NDI 只进不出

你可以把 NDI 作为素材源接进来。但 SplitCam 不是 NDI 发送端，不能供另一台机器拾取。

部分素材源仅限 Windows

文档中注明仅 Windows 可用的有：Whiteboard、Application Audio、Replay 源和纯色 Color 源。场景、图层、虚拟摄像头、多平台直播和录制在两个系统上都能用。

手机遥控目前只有 iOS 版

SplitCam Remote 已上架 App Store；Android 版正在开发中，尚未发布。把手机当摄像头用是另一回事，并不限于 iOS。

Restream 替代软件常见问题

SplitCam 真的是免费的 Restream 替代软件吗？

就多平台直播这部分而言，是的。SplitCam 免费、无水印、无订阅，可以同时直播到 84+ 个平台。区别在架构，而不是功能档位：SplitCam 是从你的电脑把每一路直播发出去，而不是由云端服务中转。

和用 Restream 相比，我需要更高的上传带宽吗？

是的，这是最需要先确认的一点。中转服务只从你这里取一路上传；直连则需要所有目标平台的码率之和同时发出——按推荐设置推四个平台大约需要 19–20 Mbps。SplitCam 内置了上传测速，一分钟就能测出来，不必等到直播中途才发现。

我能继续用现有的推流密钥吗？

可以。每个目标平台用的还是平台发给你的那把推流密钥。你的频道和它们的设置什么都不用改——变的只是连接从哪里发起。

我的场景和叠加层怎么办？

在 SplitCam 里直接搭建：同一画布上的分层素材源、AI 背景去除、特效，以及用于叠加层的浏览器素材源。如果你同时也在用 OBS，SplitCam 可以一键导入 OBS 场景集合。

直播的同时能录制吗？

可以，录制保存在你自己的电脑上；无论线上服务当时状况如何，本地录制都照常进行。

免费版有什么隐藏条件吗？

不用注册账号，没有时间限制，也没有水印。SplitCam 自 2003 年起一直免费，当前版本为 v10.9.2。
