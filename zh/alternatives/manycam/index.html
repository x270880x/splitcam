摄像头工具通常从哪里开始收费

虚拟摄像头是一个做着朴素工作的小软件：接收你的各路素材源，把它们合成一个画面，再把结果当作一个普通摄像头交给其他应用。各家的差别很少在于思路，而在于哪些部分要等你付费才放出来。SplitCam 一样都不扣，而且自 2003 年起一直免费。

任何画质下都没有水印

画面上不会被盖上任何标记。预览里的场景是什么样，会议应用、录制文件和直播收到的就是什么样。

输出数量没有上限

最多 64 路同时输出，虚拟摄像头被 60 多款应用识别——Zoom、Teams、Meet、Discord、OBS、Slack、Webex 等等，无需为每个应用单独装插件。

特效不是附加项

无需绿幕的 AI 背景去除、美颜与磨皮、色彩滤镜、面具和叠加层——实时生效，由 GPU 承担，免费版里就有。

直播是顺带的

大多数虚拟摄像头工具止步于摄像头。SplitCam 还能把同一个场景点对点多平台直播到 84+ 个平台，一个工具同时管住会议和开播。

你实际能在里面搭出什么

SplitCam 是一个带摄像头输出的场景合成工具，而不是叠在摄像头画面上的滤镜。图层放在同一个画布上，下游的每一个应用看到的都是成品画面。

同一个画布上的多层素材源

摄像头、最高 4K 的屏幕或单个窗口、可以在里面点击操作的浏览器页面、图片、视频文件、通过 RTSP 接入的 IP 摄像头，或者通过网络把手机用作第二机位。

可以直播中切换的具名场景

每套布局排好一次并保存下来，通话或直播进行中随时切换，摄像头不会中断。

音频也在同一个地方

把麦克风和系统声音混在一起，逐个素材源调音量并做噪声抑制，画面和声音不再是两件分开处理的事。

硬件编码

Windows 上的 NVENC、QuickSync 和 AMF，Mac 上的 VideoToolbox——编码交给 GPU，而不是你的 CPU。

SplitCam 做不到的事

这里每一篇对比文章都放了同一份清单，因为你应该能很快把我们排除掉，而不是下载之后才发现这些。

嘉宾无法通过链接加入

没有可以发给别人的浏览器链接。你可以用窗口捕获把嘉宾所在的 Zoom、Meet 或 Discord 窗口放进场景里，这确实可行，但那是变通办法，不是正式功能。

没有 Preview/Program 预监切换，没有多画面监看

你是直接切到某个场景，而不是先预监再切出。也没有一整面素材源预览墙。如果你习惯按正规切换台的流程导播，会立刻觉得别扭。

不能按摄像头分别录制，不支持 PTZ 控制

录制的是合成后的场景，而不是每个摄像头各存一个文件供后期剪辑。SplitCam 里没有任何功能能替你让摄像头平移、俯仰或变焦。

NDI 只进不出

你可以把 NDI 作为素材源接进来。但 SplitCam 不是 NDI 发送端，不能供另一台机器拾取。

部分素材源仅限 Windows

文档中注明仅 Windows 可用的有：Whiteboard、Application Audio、Replay 源和纯色 Color 源。场景、图层、虚拟摄像头、多平台直播和录制在两个系统上都能用。

手机遥控目前只有 iOS 版

SplitCam Remote 已上架 App Store；Android 版正在开发中，尚未发布。把手机当摄像头用是另一回事，并不限于 iOS。

关于 ManyCam 替代软件的常见问题

SplitCam 是免费的 ManyCam 替代软件吗？

是。两者的核心工作相同——把你的各路素材源合成一个画面，再当作摄像头交给其他应用。SplitCam 免费、无水印，也不会把输出数量、特效或画质锁在付费套餐后面。

会议应用会把它当成普通摄像头吗？

会。在应用的摄像头设置里选择「SplitCam Camera」——Zoom 和 Google Meet 在「设置 → 视频」中，Microsoft Teams 在「设置 → 设备」中。它出现在 60 多款应用里，无需插件，也不用逐个应用做集成。

不用绿幕也能去背景吗？

可以，AI 背景去除是内置且免费的。你可以虚化背景，也可以把它换成图片或视频。

同时可以有多少个应用使用这个摄像头？

最多 64 路同时输出，因此一场通话、一个录制软件和一个浏览器标签页可以同时取用同一路画面。

它只能给应用供画面，还是也能直播？

都可以，而且在同一个窗口里完成。同一个场景可以直接从你的电脑多平台直播到 84+ 个平台，中间没有云中转。

系统要求是什么？

Windows 10 或 11，或 macOS 13 及以上。硬件编码在 Windows 上使用 NVENC、QuickSync 或 AMF，在 Mac 上使用 VideoToolbox。
