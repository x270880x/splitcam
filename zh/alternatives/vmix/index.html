为并不需要 vMix的人准备的 vMix 替代软件。

vMix 是一套专业的导播制作软件，它的价格物有所值：Preview/Program 预监与主输出、MultiView 多画面、ISO 独立录制、PTZ 云台控制、远程嘉宾。但大多数直播用不到这些。如果你的直播也是如此，SplitCam 只做你真正会用到的那一部分——完全免费，而且能在 Mac 上运行，这是 vMix 根本做不到的。

  1. 你需要 vMix 的情况：你会在切到 Program 之前先在 Preview 中预览镜头，要盯着 MultiView 多画面墙，要把每路摄像头各自录成一个文件，要控制 PTZ 云台，或者要通过 vMix Call 接入嘉宾。这些 SplitCam 一样都没有。

不付费，你会失去什么

对此要有清醒的认识。以下是 vMix 能做而 SplitCam 做不到的事，如果你的制作依赖其中任何一项，它们都不是小事。

Preview/Program 与 MultiView

vMix 提供 Preview 预监窗口和 Program 主输出，你可以在两者之间硬切、淡入淡出或加转场，还有最多两路可随意排布的 MultiView 输出。SplitCam 是直接切到某个场景；没有预览这一步，也没有多画面墙。

每路输入的 ISO 独立录制

vMix MultiCorder 把每路输入各自写成一个文件，供后期剪辑——仅限 4K、Pro 和 MAX 版本。SplitCam 录制的是合成后的场景，只有一个文件。

PTZ 云台摄像机控制

vMix 在 4K 和 Pro 版本中可通过 VISCA 协议控制云台摄像机。SplitCam 没有任何功能能让摄像头转动。

远程嘉宾

vMix Call 通过浏览器接入嘉宾——HD 版 1 位、4K 版 4 位、Pro 和 MAX 版 8 位；Basic 各版本不支持。SplitCam 没有嘉宾链接。变通办法是把嘉宾的 Zoom 或 Meet 窗口捕获为一个图层。

向 84+ 平台多平台直播

从你自己的电脑直接推到每个平台的接入点，每个目标平台独立设置码率、分辨率和帧率。vMix 也能推流——Basic HD 起最多同时 5 路——但那要从 $60 起步。

适用于 60+ 应用的虚拟摄像头

合成后的场景变成一个摄像头，Zoom、Teams、Meet、Discord 和 OBS 都能选用。vMix 也有这个功能；区别在于这里它就在同一个免费下载里。

原生支持 macOS

SplitCam 支持 macOS 13+。vMix 在 Mac 上完全无法运行，除非在 Intel 机型上用 Boot Camp，而且官方表示不会推出 macOS 版本。

vMix 替代软件常见问题

SplitCam 是免费的 vMix 替代软件吗？

对于使用场景、叠加层、虚拟摄像头和多平台直播的直播来说——是的，而且是全分辨率。对于依赖 Preview/Program、ISO 独立录制、PTZ 控制或 vMix Call 的制作来说——不是；那些正是 vMix 的用武之地，SplitCam 没有这些功能。

vMix 能在 Mac 上运行吗？

不能原生运行。vMix 表示没有推出 macOS 版本的计划；它只能通过 Boot Camp 在 Intel Mac 上运行，Apple Silicon 则不行。SplitCam 支持 macOS 13 及更高版本。

vMix 是免费的吗？

有一个免费的 vMix Basic 版，限制为 768×576 分辨率、4 路输入和 3 路同时推流。高清输出要从 $60 的 Basic HD 许可证起步。另外还有完整版的 60 天试用。

SplitCam 有 Preview/Program 或 MultiView 吗？

没有。你是直接切到某个场景。如果你习惯先预览再切换的导播工作流程，SplitCam 会立刻让你觉得不对劲，那 vMix 才是正确的工具。

我能把每路摄像头分别录制吗？

SplitCam 不能——它把合成后的场景录成一个文件。vMix MultiCorder 在 4K、Pro 和 MAX 版本中支持每路输入单独录制。

vMix 许可证包含永久更新吗？

vMix 永久许可证包含 12 个月的免费更新；之后更新需要付费。MAX 订阅在有效期内包含更新。SplitCam 的更新是免费的。
