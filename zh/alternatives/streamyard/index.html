StreamYard 替代软件

StreamYard 在云端替你合成节目，所以每一套布局、每一个叠加层、每一路摄像头画面，都受限于一个浏览器标签页和一条上传链路。SplitCam 在你自己的电脑上把画面合成好，再把成品直接送出去——免费，画质取决于你的硬件真正能做到的水平。

简要回答：你得到什么，又放弃什么
  1. 你得到画质。场景是在你自己的 CPU 和 GPU 上合成的，而不是在一个浏览器标签页里，所以分辨率和帧率的上限取决于你的电脑，而不是一个网页应用。
  2. 你得到价格。SplitCam 免费、无水印，也不存在某个套餐专门用来解锁你早就为之买过电脑的那个分辨率。
  3. 你放弃了浏览器嘉宾。在 StreamYard 里，远程嘉宾点一个链接就能进来，什么都不用装。SplitCam 没有对应的功能——这是它实实在在的优势，不是细枝末节。
  4. 你放弃了随便换台电脑就能开工。浏览器演播室在 Chromebook 或借来的笔记本上也能跑。SplitCam 必须装在 Windows 或 macOS 上。

为什么在本机合成能出更好的画面

这才是两者真正的差别，和功能清单没有关系。差别在于画面是在哪里合成的。

画质上限由你的硬件决定

你的摄像头画面要先编码一次才能送进云端，云端把节目合成好之后，为了送到平台还得再编码一次。一共两次编码，而第二次是从一张已经被压过的画面开始的。SplitCam 只在本机合成并编码一次，用的是你自己的 GPU——离开你电脑的画面，就是平台收到的画面。

只上传一次，而不是两次

云端演播室必须先收到你的画面，才能把它送到别的地方。你的摄像头画面先传上去，做好的节目再传下来、再送出去。SplitCam 在本机合成，只上传一次，所以你的带宽承载的是成品直播，而不是它的原材料。

标签页出问题，节目不会跟着出问题

误刷新、Wi-Fi 断一下、直播中途浏览器自动更新——这些麻烦只有把演播室放在标签页里才会遇到。本地应用把你的场景、素材源和音频路由都存在磁盘上。

录制不是另一档套餐

SplitCam 以采集时的画质在本机录制，因为文件本来就在你的电脑上。没有什么需要在服务器端渲染，事后也没有什么需要下载。

什么时候 StreamYard 才是更好的选择

SplitCam 做不到的事

这里每一篇对比文章都放了同一份清单，因为你应该能很快把我们排除掉，而不是下载之后才发现这些。

嘉宾无法通过链接加入

没有可以发给别人的浏览器链接。你可以用窗口捕获把嘉宾所在的 Zoom、Meet 或 Discord 窗口放进场景里，这确实可行，但那是变通办法，不是正式功能。

没有 Preview/Program 预监切换，没有多画面监看

你是直接切到某个场景，而不是先预监再切出。也没有一整面素材源预览墙。如果你习惯按正规切换台的流程导播，会立刻觉得别扭。

不能按摄像头分别录制，不支持 PTZ 控制

录制的是合成后的场景，而不是每个摄像头各存一个文件供后期剪辑。SplitCam 里没有任何功能能替你让摄像头平移、俯仰或变焦。

NDI 只进不出

你可以把 NDI 作为素材源接进来。但 SplitCam 不是 NDI 发送端，不能供另一台机器拾取。

部分素材源仅限 Windows

文档中注明仅 Windows 可用的有：Whiteboard、Application Audio、Replay 源和纯色 Color 源。场景、图层、虚拟摄像头、多平台直播和录制在两个系统上都能用。

手机遥控目前只有 iOS 版

SplitCam Remote 已上架 App Store；Android 版正在开发中，尚未发布。把手机当摄像头用是另一回事，并不限于 iOS。

StreamYard 替代软件常见问题

SplitCam 真的是免费的 StreamYard 替代软件吗，还是另有付费套餐？

它是免费的，上面也没有更高一档的套餐。多平台直播、场景、特效、音频混音器和录制全都在免费下载的版本里，输出画面上也没有水印。

我能像在 StreamYard 里那样邀请嘉宾进入直播吗？

不能。这正是 StreamYard 做得到、而 SplitCam 没有答案的那一件事。嘉宾点浏览器链接、什么都不用装就能加入，这不是 SplitCam 的功能；如果你的节目离不开它，那 StreamYard 就是更合适的工具。

为什么桌面应用会比浏览器演播室画面更好看？

因为云端演播室要先把你的摄像头画面编码一次才能送上去，做好的节目往外发时还要再编码一次——第二次是从一张已经被压过的画面开始的，这部分损失找不回来。SplitCam 只在本机编码一次。在同一台电脑、同一条网络上，这通常体现为画面运动时更干净。

换过来是不是就得放弃品牌叠加层和布局？

不用。场景、叠加层、图片、文字和字幕条都是 SplitCam 自带的，直播过程中随时可以切换。

SplitCam 的多平台直播会经过它自己的服务器吗？

不会。它是从你的电脑直接送到每个平台，所以既没有中转费用，链路上也没有多出一段网络跳转。

它能在 Chromebook 上运行吗？

不能。SplitCam 是 Windows 和 macOS 应用。在 ChromeOS 上，StreamYard 这类基于浏览器的演播室才是正确的选择。
