Stream Deck

用 Stream Deck 控制 SplitCam——或者用你早就有的那部手机。

Stream Deck 是一盒实体按键，省得你在直播途中到处找窗口。如果这些按键要做的事全都在直播软件里，那你口袋里的手机就能免费干同样的活：SplitCam Remote 可以切换场景、开始和停止直播与录制，并告诉你当前是否在直播中——全程走你自己的 Wi-Fi。

直播过程中手机实际能做什么

下面列出的都是 SplitCam Remote 有据可查的功能——不是一个控制台理论上可能做到的愿望清单。

在手上切换场景

这正是大多数人想要控制台的原因。换摄像头、换布局、切到幻灯片——不用走回电脑前，也不用在全屏游戏后面翻找窗口。

开始和停止直播与录制

开播、下播、开始或停止录制、抓拍快照、暂停或静音——正是那些一伸手去够键盘就会被观众看得一清二楚的时刻，你最需要的操作。

看清当前到底是什么状态

App 会把直播名称和状态回传到你手上，站在房间另一头也能确认是否正在直播，而不用靠猜。

几秒配对，只走你的局域网

扫描 SplitCam 设置里「Remote Control」标签页上的二维码，或者让 App 自己通过 Wi-Fi 找到你的电脑。扫码这条路径会经过我们的服务器来给两台设备牵线；Wi-Fi 自动发现则始终留在你自己的网络里。

为什么不买硬件也值得这么用

选手机的理由不是它更便宜，而是就这件事而言，它并不更差。

按键本来就在你口袋里

控制台之所以有价值，是因为不用移开视线就能够到。一部立在键盘旁边的手机，触手可及的程度和一盒实体按键完全一样，而且你根本不用另外掏钱。

标签随场景自动变化

实体按键的图标和文字得手动设置。而屏幕直接显示当前的场景列表，重命名场景之后，按键上不会留下一个过时的旧标签。

台上少一样可能出问题的东西

少一个 USB 设备，少一根线，换房间或把设备搬到场地时也少一样要拔的东西。

SplitCam 的其余功能同样免费

场景、面向 84+ 个平台的多平台直播、虚拟摄像头、特效和音频混音器都在同一个免费下载包里——控制 App 也不设任何付费门槛。

什么情况下你应该去买 Stream Deck

先老实想清楚你想按的是什么。如果这些按键需要做 SplitCam 之外的任何事——触发 OBS 的场景、从另一个 App 播放音效、运行宏、调暗灯光、静音 Discord、往聊天区粘贴链接——那么 Stream Deck 才是对的工具，手机 App 替代不了它，因为 SplitCam Remote 只控制 SplitCam，别的一概不管。同理，如果你想要不用看就能按到的实体按键、一块永远亮着、不会休眠也不会在直播中途来电话的常驻控制面板，或者每个按键上都有独立的常亮小屏幕，那也该选硬件。还有，如果你用的是 Android，配套 App 尚未发布，今天两者之中只有硬件对你可用。这些都不是小事——Stream Deck 是一款好产品，很多人确实应该买一台。

已经有 Stream Deck？接上它只需这几步

SplitCam 在 Elgato Marketplace 发布了官方插件。它免费，仅限 Windows，而且直接与正在运行的 SplitCam 通信——不用端口、密码，也不用配对。

1. 更新 SplitCam

Stream Deck 支持从 Windows 版 10.8.25（2025 年 1 月）开始加入。之后的任何版本都可以，当前正式版就行。

2. 安装插件

在 Stream Deck 应用（6.9 或更新版本）里打开 Marketplace 搜索 SplitCam，或直接从插件页面安装。由 SplitCam 官方发布，不是第三方作品。

3. 把操作分配到按键

开播/下播、切换场景、开始/停止录制、暂停场景、静音和抓拍快照。场景名称直接从 SplitCam 读取，所以每个按键都会显示它要切换到的场景；按键还会同步显示 SplitCam 的实时状态和本次会话时长。

4. 想串联也可以

这些操作可以放进 Multi Action，按一下就能切换场景、开始直播，再顺带触发该按键上的其他任何操作。SplitCam 的频道上有一段简短的设置教程视频——它是 2024 年底针对插件 1.0 录制的，所以现在以 Marketplace 上的插件页面为准。

这个插件做不到的事：它不能在 macOS 上运行——在 Mac 上，想用控制面板切换场景，要靠 iPhone 上免费的 SplitCam Remote 应用。它不支持旋钮，也不附带任何配置文件。除这六个操作之外的功能，请查看当前的插件页面，那里有插件自己的版本历史。

按键都能做什么

官方插件放到按键上的六个操作，按 SplitCam 自家插件页面上的写法列出。按键会显示 SplitCam 的实时状态，直播键还会显示你已经开播了多久。

切换场景

一个场景一个键。场景名称直接从 SplitCam 读取，所以每个按键上标的就是它要切换到的场景。

开始 / 停止直播

开播、下播，按一下键就行。直播期间，按键会显示本次会话时长。

开始 / 停止录制、抓拍快照

录制到文件，或者给当前场景抓一张快照，全程不用碰键盘。

静音、暂停场景

把声音静音，或者暂停整个场景——所有素材源同时停下——再用同一个键恢复。

这六个操作都能放进 Multi Action。没有旋钮（Stream Deck +）操作，也不附带配置文件。插件自己的 Marketplace 页面记录了版本历史；当前版本是 1.2。

没装插件？快捷键配任何 Stream Deck 都能用

在装不了插件的电脑上，Stream Deck 自带的「热键」（Hotkey）操作照样能控制 SplitCam。用全局快捷键——SplitCam 最小化或者其他窗口在前台时它们也能生效；Ctrl 组合键只有在 SplitCam 窗口处于焦点时才会触发。快捷键可以在 SplitCam 的设置里关掉，所以先确认它们是开着的。

SplitCam 做不到的事

这里每一篇对比文章都放了同一份清单，因为你应该能很快把我们排除掉，而不是下载之后才发现这些。

嘉宾无法通过链接加入

没有可以发给别人的浏览器链接。你可以用窗口捕获把嘉宾所在的 Zoom、Meet 或 Discord 窗口放进场景里，这确实可行，但那是变通办法，不是正式功能。

没有 Preview/Program 预监切换，没有多画面监看

你是直接切到某个场景，而不是先预监再切出。也没有一整面素材源预览墙。如果你习惯按正规切换台的流程导播，会立刻觉得别扭。

不能按摄像头分别录制，不支持 PTZ 控制

录制的是合成后的场景，而不是每个摄像头各存一个文件供后期剪辑。SplitCam 里没有任何功能能替你让摄像头平移、俯仰或变焦。

NDI 只进不出

你可以把 NDI 作为素材源接进来。但 SplitCam 不是 NDI 发送端，不能供另一台机器拾取。

部分素材源仅限 Windows

文档中注明仅 Windows 可用的有：Whiteboard、Application Audio、Replay 源和纯色 Color 源。场景、图层、虚拟摄像头、多平台直播和录制在两个系统上都能用。

手机遥控目前只有 iOS 版

SplitCam Remote 已上架 App Store；Android 版正在开发中，尚未发布。把手机当摄像头用是另一回事，并不限于 iOS。

关于 Stream Deck 替代方案的常见问题

SplitCam Remote 真的免费吗？

是的。它是 SplitCam 的配套 App，而 SplitCam 本身就免费，无水印，也没有付费版本。两者都没有需要解锁的东西。

它能完全取代 Stream Deck 吗？

只有当你要按的一切都属于 SplitCam 时才可以。它能切换场景、开始和停止直播与录制、抓拍快照和静音——但没法在其他应用里按按钮。如果你的工作流横跨多个程序，那就买硬件。

有 Android 版吗？

暂时还没有。SplitCam Remote 的 iOS 版已在 App Store 上架，Android 版正在开发中。

我已经有 Stream Deck 了，SplitCam 能配合它使用吗？

可以，在 Windows 上。从 Elgato Marketplace 安装免费的 SplitCam 官方插件（Stream Deck 应用 6.9 或更新版本），并把 SplitCam 更新到 10.8.25 或更高版本。按键可分配开播/下播、切换场景、开始/停止录制、暂停场景、静音和抓拍快照，并会显示 SplitCam 的实时状态。该插件没有 macOS 版本。

手机是怎么找到我的电脑的？

两种方式：扫描 SplitCam 设置里「Remote Control」标签页上的二维码，或者让 App 通过 Wi-Fi 自动发现你的电脑。两种都行；第一次连接时扫二维码更快。

连接会经过你们的服务器吗？

配对会经过 SplitCam 的服务器，由它把手机介绍给你的电脑。只有这一次握手会走服务器——两台设备找到彼此之后，控制指令就在你自己的两台设备之间传输。
