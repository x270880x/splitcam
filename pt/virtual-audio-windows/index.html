SplitCam/Áudio virtual para Windows
Áudio virtual · Windows

Áudio virtual para Windows — um microfone que outros programas podem escolher.

O SplitCam para Windows registra o seu próprio dispositivo de áudio virtual quando você o instala. Tudo o que você equilibra no Mixer de áudio continua alimentando a sua transmissão, e a mesma sessão é oferecida ao Windows como dispositivo de entrada — então uma chamada, um gravador ou uma aba do navegador podem ouvir o SplitCam bastando selecioná-lo numa lista de microfones comum.

A parte que confunde

Duas saídas, não uma.

O SplitCam sempre soube combinar áudio: o Mixer de áudio é onde um microfone, uma playlist de música, uma página do navegador e o som que o próprio Windows produz são equilibrados entre si, e é esse equilíbrio que a sua transmissão e a sua gravação levam. O microfone virtual não substitui nada disso. Ele é um segundo destino, paralelo, para a mesma sessão — o SplitCam o oferece ao Windows como dispositivo de entrada, e qualquer programa que liste microfones pode apontar para ele. O mixer decide como o SplitCam soa. O microfone virtual decide quem mais pode ouvir. No Mac, isso é um driver separado — veja o driver de áudio virtual para macOS.

🎚

Mixer de áudio — dentro do SplitCam

A strip per source, each with its own volume, mute and monitoring. Noise suppression on the microphone, and filters that belong to the individual source: VST plug-ins, Delay, Sound Offset and the Audio Compressor.

🎙

Microfone virtual — no nível do Windows

An audio input registered with Windows, sitting in the same list as your sound card and your headset. Programs do not integrate with it one by one; they enumerate the inputs Windows reports, and this is one of them.

Dentro do app

O que acaba indo pelo canal.

O painel do mixer tem um canal por fonte. A captura ao lado é uma sessão real com quatro deles: o microfone que o Windows informa como High Definition Audio Device, uma Audio Playlist com sua própria lista de faixas e controles de reprodução, uma página do navegador — aqui, www.youtube.com — e o System Audio, o som que o próprio Windows está produzindo.

Cada canal traz um botão de mudo, um controle de volume, uma chave de monitoramento e uma engrenagem para os seus filtros. Nesta sessão o microfone, a playlist e o navegador estão todos altos, enquanto o System Audio está bem baixo — um formato comum, porque sons de notificação e bipes de app ficam melhor embaixo da voz do que ao lado dela. O que este painel soma é o que a transmissão leva, e é a mesma sessão que o microfone virtual disponibiliza.

Fora do app

Ele aparece onde o Windows oferece escolha de entrada.

Não há integração para combinar nem plug-in para adicionar do lado de quem recebe. O programa abre a lista de entradas que o Windows entrega, e o dispositivo do SplitCam está nessa lista, ao lado do hardware.

Reuniões e chamadas

A conference program gives you one input and no way to add a second track to it. Selecting SplitCam turns that single input into everything you have balanced — the voice, the clip you are reacting to, the page you are demonstrating.

⏺

Gravadores e assistentes de notas

Anything that records from a microphone can capture the assembled session instead of just the room, which keeps a walkthrough and its sound in one file rather than two that have to be lined up afterwards.

🌐

Abas do navegador

Web apps ask the browser for a microphone and get the same Windows list. A recording page, a web meeting or a voice widget can take the SplitCam device without installing anything.

🎛

Outros programas de transmissão

If you also run OBS or a similar tool, it can add the SplitCam device as an audio input capture and treat the assembled sound as a single source instead of rebuilding the same routing twice.

O que pode ouvir

Tudo o que lista microfones pode usá-lo.

O dispositivo é registrado no próprio Windows, não em um programa de cada vez. Não importa como um programa chame a entrada dele — microfone, dispositivo de áudio, dispositivo de gravação —, ele está lendo a lista que o Windows mantém, e o item do SplitCam fica nessa lista, ao lado da sua placa de som. É esse o requisito inteiro: um seletor de entrada.

Da instalação à primeira chamada

Não existe etapa de driver.

1

Instale o SplitCam para Windows

O instalador registra o dispositivo de áudio junto com o aplicativo. No Windows não existe pacote de driver separado para baixar, e o dispositivo vai embora junto quando o SplitCam é desinstalado.

2

Monte o som que você quer levar

As fontes de áudio são adicionadas pelo menu Add new source layer, no submenu Audio Source, e depois equilibradas no mixer. Ajuste cada nível, silencie o que deve ficar de fora e acrescente filtros por fonte se precisar.

3

Escolha o SplitCam onde quiser o som

No outro programa, abra a lista de entrada ou de microfone e pegue o dispositivo de áudio do SplitCam no lugar do seu hardware. Se essa lista foi montada antes de o SplitCam ser instalado, reabra as configurações de áudio do programa para ele reler o que o Windows oferece.

Duas coisas que vale saber.

🎧O Accentuate Microphone reage a som, não a fala. A opção abaixa as outras fontes sempre que o microfone capta alguma coisa — mas, na versão atual, isso vale para qualquer som, não só para a sua voz, então ela funciona melhor com fone de ouvido do que com caixas abertas.
🛠Um problema no driver não derruba o SplitCam. O programa verifica na inicialização se o dispositivo de microfone virtual foi carregado e avisa se não foi. Nesse caso o SplitCam continua rodando normalmente; só o dispositivo fica indisponível até ser resolvido.
Questions

Áudio virtual no Windows, respondido.

O que o dispositivo é, e o que ele não é.

Do I have to download a virtual audio driver for Windows?

Não. O dispositivo de áudio é registrado pelo próprio instalador do SplitCam, então instalar o SplitCam para Windows já resolve tudo. Não há pacote separado para baixar.

How is this different from the Audio Mixer?

O Mixer de áudio é onde você junta as fontes dentro do SplitCam, e é essa combinação que a sua transmissão e a sua gravação levam. O microfone virtual é uma saída extra da mesma sessão: ele deixa o som disponível para o Windows como dispositivo de entrada, para que um programa que não sabe nada sobre o SplitCam possa selecioná-lo e ouvir.

Which programs can use it?

Qualquer programa que deixe você escolher um microfone ou uma entrada de áudio. Ele aparece na lista de entradas do Windows ao lado da sua placa de som, então apps de chamada, gravadores, navegadores e o OBS chegam nele do mesmo jeito.

Preciso baixar um driver de áudio virtual para Windows?

Não. A sua transmissão e a sua gravação continuam tirando o áudio do mixer como antes. O microfone virtual é um ouvinte a mais, não um substituto.

The device is missing from the list. What now?

O SplitCam verifica na inicialização se o driver foi carregado e mostra um aviso se não foi; nesse caso o programa continua rodando, mas o dispositivo fica indisponível. Se não apareceu aviso nenhum, o programa que deveria receber o som pode ter montado a lista de entradas antes de o SplitCam ser instalado — reabra as configurações de áudio dele.

Qual a diferença para o Mixer de áudio?

Sim. Ele faz parte da versão para Windows, não é um complemento, então nada nele fica atrás de uma chave de licença ou de uma conta.
