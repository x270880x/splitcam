## Что не открывается — и почему это не переезд

357 адресов не открываются через Cloudflare, **все 357 точно так же не открывались на
старом сервере**. 262 — сканирование ботами (`.env`, `.git`, `.ssh`, `wp-*`, `*.php`,
`*.zip`…), им и положено 403/404. Из оставшихся стоят внимания:

| Адрес | Запросов за 17.09 | Что это |
|---|---|---|
| `/win-download/images/images.xml` | **9 063** | Файл версии анимаций тип-нотификатора: программа при запуске проверяет, нет ли новых наборов. Папку `images/` не перенесли в июле («только установщики»). ✅ **Решение владельца 18.09: оставить 404.** Пользователи ничего не теряют — установщик во всех 12 ветках (10.9.4, 11.0.x…) несёт все 440 файлов анимаций и сам `images.xml`, ни один не исключён; последний набор (Blondie) добавлен в июне 2023. Сломано только одно: выпустить новый набор без новой версии программы нельзя |
| `/win-download/update/10.8.13_x64.msi` | 69 | Этой версии нет нигде — ни на хостинге, ни на GitHub. По правилу «старая ссылка ведёт только на ту же версию» 404 здесь верен |
| `/<язык>/null` (14 вариантов) | 75 | Переключатель языка `go(lang)` строит `"/"+lang+"/"+slug`; при пустом `slug` выходит `/ar/null` — краулеры вытаскивают строку из JS. ✅ **С 18.09 — 301 на главную языка** (все 34 языка + `/null`) |

✅ **Исправлено 18.09:** 301 на GitHub были только для установщиков 10.3–10.7.44.
Добавлены 14 версий 10.8.x (2, 3, 5, 25, 50, 55, 60, 61, 64–69) — каждая ведёт на
ТОТ ЖЕ файл на GitHub, все 14 проверены вживую: один 301, итог 200. Не включены:

## Как повторить проверку при следующем переезде

```bash
W=<рабочая папка>
# 1. список файлов вне git с сервера → $W/host_managed.txt
# 2. реальные пути за вчера из CF GraphQL httpRequestsAdaptiveGroups → $W/cf_paths_<день>_paths.json
python3 seo/migration_check/live_crawl.py "$W" --new <НОВЫЙ_IP> --old <СТАРЫЙ_IP> --cf-paths cf_paths_<день>_paths.json
python3 seo/migration_check/analyze.py "$W"
python3 seo/migration_check/drift_verify.py "$W" <НОВЫЙ_IP> <СТАРЫЙ_IP>   # если есть расхождения
```

Главный урок трёх переездов подряд: **«сервер отвечает» ничего не доказывает** —
старые машины продолжают отдавать сайт. Решают только DNS и сравнение по содержимому.
И **адрес сервера нигде не вписывать** — брать из A-записи Cloudflare.
