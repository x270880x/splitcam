# Снятые с сайта блоки, которые могут понадобиться снова

Здесь лежат готовые компоненты, убранные со страниц, но не выброшенные. Каждый — с разметкой,
CSS и переводами на все 35 локалей, чтобы вернуть его или переиспользовать под новую задачу
было делом одной вставки, а не заново прогонять конвейер перевода.

---

## `announce-strip.json` — полоса-анонс под hero

**Что это.** Цветная полоса сразу под первым экраном: пилюля-ярлык, строка текста и кнопка.
Плюс парная кнопка в панели SplitCam Remote на `/products/`.

**Откуда снято (2026-09-25).** Набор для вербовки тестеров Android-версии SplitCam Remote.
Владелец: приложение уходит в прод, тестеры больше не нужны. Полоса была на `/products/`
(35 локалей) и `/download/` (только EN); кнопка — на `/products/` (35 локалей).

**Почему сохранено, а не удалено.** В нём 35 переведённых носителями текстов и — что важнее —
**35 РАЗНЫХ ссылок на Google-формы, по одной на язык**. Такое не восстанавливается из английского
оригинала: формы заводились руками.

### Что внутри

```
{
  "css": "…8 строк: .rt-strip .rt-in .rt-pill .rt-txt .rt-cta…",
  "locales": {
    "en": {
      "strip_html":     "<div class=\"rt-strip\">…</div>",   ← готовая разметка
      "form":           "https://docs.google.com/forms/…",   ← своя форма локали
      "pill":  "Closed testing",
      "text":  "SplitCam Remote for Android needs testers — …",
      "cta":   "Become a tester →",
      "panel_btn_html": "<a href=… class=\"btn-store btn-store-2\">…</a>",
      "panel_small":    "Closed testing",
      "panel_bold":     "Become a tester"
    },
    "ru": { … }, …
  }
}
```

### Как вернуть или переиспользовать

1. **CSS** — вставить значение `css` в `<style>` страницы.
   🔴 **Только ПЕРЕД маркером `<!--RTLCSS-->`.** Правило вставки после `<!--/RTLCSS-->` уже
   съедало первое правило на ar/he/fa: HTML-комментарий не валиден в CSS, парсер глотает всё
   до следующей `{`. Именно на `.rt-strip` это и поймали 2026-07-18 — см. CLAUDE.md, «RTL trap».
2. **Разметка** — `strip_html` ставится сразу после закрывающего `</section>` блока hero.
3. **Под новую задачу** — менять только `pill`, `text`, `cta` и `href`. Структура и классы
   остаются: вёрстка проверена на 390 и 1440 px во всех локалях, включая RTL.
4. **Тексты переводить заново** — старые про тестеров и к новому поводу не подойдут. Прогон
   по правилу №1: перевод + вычитка носителем-филологом, который сам стримит.

### Чего в снимке НЕТ

Текст шага 02 в инструкции по подключению («версия для Android в закрытом тестировании —
вступите в программу») **остался на страницах** и снят не был: это не блок, а предложение
внутри абзаца, и его судьба зависит от того, появилась ли ссылка на Google Play для
SplitCam Remote. Решается отдельно.
