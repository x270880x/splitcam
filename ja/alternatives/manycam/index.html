ManyCam 代替

フル画質のまま、ずっと無料で使えるManyCam 代替。

ManyCam は Webカメラのエフェクトとバーチャルカメラ出力に特化していて、SplitCam と同じ仕事をします。違いが出るのは、多くの Webカメラツールが有料版をすすめてくる場面です：SplitCam は無料で、透かしが入らず、画質も出力数も機能もプランで制限しません。

手短に — ManyCam から SplitCam への乗り換え
  1. Windows 10/11 か macOS 13+ に SplitCam をインストールします。アプリ側で選べるカメラが1つ増えます。
  2. 画を組み立てます：Webカメラ、画面、ブラウザのページ、画像、スマホのカメラを、1つのキャンバスにレイヤーとして重ねます。
  3. AI背景除去と美顔フィルターをオンにします。グリーンバックもプラグインも要りません。
  4. Zoom・Teams・Meet・Discord など60以上のアプリで、カメラに「SplitCam Camera」を選びます。
  5. 配信もしたいなら、同じシーンを同じウィンドウから84以上のプラットフォームへマルチ配信できます。

Webカメラツールがたいてい課金を始めるところ

バーチャルカメラは、地味な仕事をする小さなソフトです：ソースを受け取り、合成し、その結果をふつうの Webカメラとして他のアプリに渡す。選択肢を分けるのは発想ではなく、どの部分がお金を払うまで取り置かれるかです。SplitCam は何も取り置きません。しかも2003年からずっと無料です。

画質を問わず透かしなし

映像には何も刻印されません。プレビューで見えているシーンが、そのまま会議アプリにも、録画にも、配信にも届きます。

出力数に上限なし

最大64本の同時出力に対応し、バーチャルカメラは60以上のアプリに認識されます — Zoom・Teams・Meet・Discord・OBS・Slack・Webex ほか。アプリごとのプラグインは不要です。

エフェクトはアドオンではありません

グリーンバックなしのAI背景除去、美顔・肌なめらか、カラーフィルター、マスクやオーバーレイ — GPUでライブ処理され、無料版で使えます。

配信機能もついてきます

多くのバーチャルカメラツールはカメラ出力で終わります。SplitCam は同じシーンを84以上のプラットフォームへピアツーピアでマルチ配信もするので、1つのツールで通話も配信もまかなえます。

実際に何を組み立てられるのか

SplitCam は、Webカメラの上に乗るフィルターではなく、カメラ出力を備えたシーン合成ツールです。レイヤーは1つのキャンバスに置かれ、その先のアプリはすべて完成した映像を受け取ります。

1つのキャンバスに重ねるソース

Webカメラ、画面または単一ウィンドウを最大4Kで、中をクリックできるブラウザのページ、画像、動画ファイル、RTSP の IPカメラ、あるいはネットワーク経由でスマホを2台目のカメラに。

名前を付けて、ライブ中に切り替えるシーン

レイアウトを一度組んで保存すれば、通話中でも配信中でも、カメラが途切れることなく切り替えられます。

音声も同じ場所で

マイクとシステム音声を、ソースごとの音量とノイズ除去付きでミックス。映像と音が別々の問題にならずに済みます。

ハードウェアエンコード

Windows では NVENC・QuickSync・AMF、Mac では VideoToolbox — エンコードは CPU ではなく GPU が担います。

ManyCam 代替に関するよくある質問

SplitCam は無料の ManyCam 代替になりますか？

はい。どちらも中心の仕事は同じで、ソースを合成し、その結果を Webカメラとして他のアプリに渡します。SplitCam は無料で、透かしが入らず、出力数もエフェクトも画質も有料プランの後ろに隠しません。

会議アプリはふつうのカメラとして認識しますか？

はい。アプリのカメラ設定で「SplitCam Camera」を選ぶだけです — Zoom と Google Meet は「設定 → ビデオ」、Microsoft Teams は「設定 → デバイス」。プラグインもアプリごとの連携もなしで、60以上のアプリに表示されます。

グリーンバックなしで背景を消せますか？

はい、AI背景除去を無料で内蔵しています。背景をぼかすことも、画像や動画に置き換えることもできます。

同時に何個のアプリがカメラを使えますか？

最大64本の同時出力なので、通話と録画ソフトとブラウザのタブが、同じ映像を同時に受け取れます。

配信もできますか、それともアプリに送るだけですか？

どちらも、同じウィンドウからできます。同じシーンを、お使いのPCから直接84以上のプラットフォームへマルチ配信します — 途中にクラウドの中継はありません。

動作環境を教えてください。

Windows 10 または 11、あるいは macOS 13 以降。ハードウェアエンコードは Windows で NVENC・QuickSync・AMF、Mac で VideoToolbox を使います。
