vMix の代替

vMix を必要としない人のための vMix 代替。

vMix はプロ向けのプロダクションスイートで、その価格に見合う価値があります：Preview/Program、MultiView、ISO 録画、PTZ 制御、リモートゲスト。ただ、ほとんどの配信はそのどれも使いません。あなたの配信もそうなら、SplitCam は実際に使う部分だけを担います — 無料で、しかも vMix がまったく動かない Mac でも。

手短に：あなたはどちら側か
  1. vMix が必要なのは、Program に切り替える前に Preview でショットを仕込む、MultiView の画面を見ながら進行する、カメラごとに別ファイルへ録画する、PTZ ヘッドを操作する、vMix Call でゲストを招く — そういう場合です。SplitCam にはどれもありません。
  2. 必要ないのは、配信がカメラ1〜2台と画面、いくつかのオーバーレイで、Twitch・YouTube・Facebook へ同時に流す — そういう場合です。それはシーン、レイヤー、マルチ配信であり、ここではすべて無料です。
  3. Mac をお使いなら。 vMix にネイティブの macOS 版はありません — Intel Mac の Boot Camp 上でのみ動き、Apple Silicon では動きません。SplitCam は macOS 13 以降で動きます。

お金を払わないことで手放すもの

ここは冷静に見てください。以下は vMix にできて SplitCam にできないことで、あなたの制作がそれに依存しているなら、どれも小さな差ではありません。

Preview/Program と MultiView

vMix は Preview ウィンドウと Program 出力を持ち、その間をカット・フェード・トランジションで切り替えられます。MultiView 出力も最大2つ、レイアウトは自由です。SplitCam はシーンへ直接切り替えます。仕込みのステップも、MultiView の画面もありません。

全入力の ISO 録画

vMix の MultiCorder は、後で編集できるように各入力を個別のファイルに書き出します — 4K・Pro・MAX エディションで。SplitCam が録画するのは合成済みのシーン、1ファイルです。

PTZ カメラ制御

vMix は 4K と Pro エディションで、VISCA 経由でパン・チルト・ズームカメラを操作できます。SplitCam にカメラを動かす機能はありません。

リモートゲスト

vMix Call はブラウザ経由でゲストを招きます — HD で1名、4K で4名、Pro と MAX で8名。Basic 系エディションにはありません。SplitCam にゲスト用リンクはありません。回避策は、ゲストの Zoom や Meet のウィンドウをレイヤーとしてキャプチャすることです。

代わりに無料で手に入るもの

放送スイートのうち、ほとんどの配信が実際に使っている部分です。

シーンとレイヤーをライブで切り替え

カメラ、画面、ブラウザページ、画像、動画ファイル、そしてスマホをシーン内のレイヤーとして配置し、シーン間はトランジションでつなぎます。人々が vMix を買う理由の核心はこれで、それはここにあります。

84+プラットフォームへのマルチ配信

お使いのマシンから各プラットフォームのインジェストへ直接、配信先ごとにビットレート・解像度・フレームレートを個別に設定できます。vMix も配信できます — Basic HD から最大5本同時 — ただしそれは $60 からです。

60+アプリで使えるバーチャルカメラ

合成したシーンが、Zoom・Teams・Meet・Discord・OBS で選べるカメラになります。vMix にもこの機能はあります。違いは、ここでは同じ無料ダウンロードに含まれていることです。

macOS にネイティブ対応

SplitCam は macOS 13+ で動きます。vMix は Intel ハードウェアの Boot Camp 以外では Mac でまったく動かず、開発元は macOS 版の予定はないとしています。

vMix 代替に関するよくある質問

SplitCam は無料の vMix 代替ですか？

シーン、オーバーレイ、バーチャルカメラ、マルチ配信を使う配信なら — はい、しかもフル解像度で。Preview/Program、ISO 録画、PTZ 制御、vMix Call に依存する制作なら — いいえ。それらは vMix の存在意義であり、SplitCam にはありません。

vMix は Mac で動きますか？

ネイティブでは動きません。vMix は macOS 版の予定はないとしており、Intel Mac の Boot Camp 上でのみ動き、Apple Silicon では動きません。SplitCam は macOS 13 以降で動きます。

vMix は無料ですか？

無料の vMix Basic エディションがあり、768×576、入力4本、同時配信3本に制限されています。HD 出力は $60 の Basic HD ライセンスからです。全機能版の60日間トライアルもあります。

SplitCam に Preview/Program や MultiView はありますか？

ありません。シーンへ直接切り替えます。仕込んでからカットする方式で演出しているなら、SplitCam はすぐに違和感があるはずで、vMix が正しいツールです。

カメラごとに別々に録画できますか？

SplitCam ではできません — 合成済みのシーンを1ファイルとして録画します。vMix の MultiCorder は 4K・Pro・MAX エディションで入力ごとの録画に対応しています。

vMix のライセンスには永久にアップデートが含まれますか？

vMix の永続ライセンスに含まれる無料アップデートは12か月分で、その後の更新は有料です。MAX サブスクは契約中はアップデートが含まれます。SplitCam のアップデートは無料です。
