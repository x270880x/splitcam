Restream 代替

お使いのPCの外に出ない、無料のRestream 代替。

Restream はあなたから1本の配信を受け取り、自社サーバーから各所へ送り直し、その仲介の対価を毎月請求します。SplitCam はお使いのマシンで1回だけエンコードし、各プラットフォームへ自分で接続を開きます — 84+の配信先、他人のサーバーを経由するものは何もなく、契約するものも何もありません。

手短に — Restream を SplitCam に置き換える
  1. すでに配信に使っているPCへ SplitCam をインストールします。Windows 10/11 または macOS 13+。
  2. 配信先を追加し、各プラットフォームのストリームキーを貼り付けます — 84+が設定済みです。
  3. 配信先ごとにビットレートを設定します。SplitCam がプラットフォームごとに選ぶ既定値のままでも構いません。
  4. 内蔵のアップロード速度テストを実行し、回線が合計の帯域をまかなえるか確かめます。
  5. 「配信開始」をクリック。各プラットフォームは、お使いのマシンから直接この配信を受け取ります。

その月額料金で実際に買っているもの

クラウドのマルチ配信サービスは中継です。あなたが1本の配信を送ると、サービスは自社サーバーにコピーを持ち、接続した各プラットフォームへそのコピーを転送します。その手軽さは本物ですが、裏側の仕組みも同じくらい確かです：あなたの配信は自分では管理できないインフラを通り、その月に4回配信しても1回も配信しなくても請求は届きます。

配信は遠回りをする

どのフレームも、まず中継サーバーへ行き、視聴者に届くのはその後です。ネットワークの経由地が1つ増え、配信中ずっと動いていなければならないサービスが1つ増えます。

請求は毎月、配信はそうではない

サブスクが課金するのはカレンダーであって、実際に配信した時間ではありません。ひと月に2回しか配信しなくても、配信しなかった26日分も同じように支払います。

上限を決めるのはあなたではない

画質も、配信先の数も、使える機能も、契約しているプラン次第です。そのどれかを変えることは、設定の変更ではなく料金の判断になります。

エンコードは、すでにお使いのPCがやっている

配信でコストがかかるのは映像のエンコードで、それはすでにお使いのマシンがやっています。フレームさえエンコードしてしまえば、1か所ではなく4か所へ送ることは、ネットワーク接続が4本になるだけです。SplitCam はその接続を自分で開きます — Windows では NVENC・QuickSync・AMF、Mac では VideoToolbox によるハードウェアエンコード、そして各プラットフォームの取り込みサーバーへの直接接続です。

エンコードは1回、送り先は複数

解像度とビットレートが同じ配信先どうしは、1回のエンコードを共有します。ある配信先に独自の設定を与えれば、その配信先には専用のエンコードが割り当てられます — 下にある配信先ごとの設定が、単なるスイッチではなく本物の機能なのはそのためです。

配信先ごとのビットレート

Twitch には6Mbps、Facebook には2.5Mbps にしたいですか。中継側の設定ひとつで全部をそろえる代わりに、配信先ごとに別々に決められます。

あなたとプラットフォームの間には何もない

プラットフォームが動いていて、あなたの回線がつながっていれば、配信は生きています。あなたの代わりに障害を起こしうる第三のサービスは、そこにありません。

84+のプラットフォームが設定済み

Twitch、YouTube、Facebook、Kick、TikTok、X ほかが、妥当な既定値とともにすでに一覧に入っています。

Restream のほうが向いているとき

これは直接送ることの正直な限界で、乗り換える前に知っておく価値があります。中継なら、あなたからのアップロードは1本で済みます。直接送る場合は、すべての配信先のビットレートの合計が同時に自宅の回線から出ていきます — 推奨設定の4プラットフォームなら、おおよそ19〜20Mbpsのアップロードです。Twitch に6、YouTube に4.5、Facebook に3、4つめに2.5 で映像が16Mbps、そこに約20%の余裕を足した数字です。回線がそれを支えられないなら、クラウド中継は手軽さの問題ではなく、マルチ配信を成り立たせている当のものです。SplitCam には決める前に確かめられるアップロード速度テストが付いていますし、配信先を減らしたりビットレートを下げたりすることもいつでもできます — けれども、アップロードが制約になっているなら、Restream は SplitCam には解けない問題を解いています。ホテルやモバイル回線のノートPCから配信する場合も同じで、そこでは回線の不安定さを視聴者に見せる代わりに中継が吸収してくれます。

Restream 代替に関するよくある質問

SplitCam は本当に無料の Restream 代替ですか？

マルチ配信の部分については、はい。SplitCam は無料で、透かしもサブスクもなく、84+のプラットフォームへマルチ配信します。違いは機能のグレードではなく構造です：SplitCam は各配信を、クラウドサービスから中継するのではなく、お使いのPCから送ります。

Restream より多くのアップロード帯域が必要ですか？

はい、そしてこれが最初に確かめるべき点です。中継はあなたから1本のアップロードを受け取りますが、直接送る場合は全配信先のビットレートの合計が同時に出ていきます — 推奨設定の4プラットフォームでおよそ19〜20Mbpsです。SplitCam にはアップロード速度テストが内蔵されているので、配信の途中で気づくのではなく、1分で確かめられます。

今使っているストリームキーはそのまま使えますか？

はい。各配信先には、プラットフォームが発行するのと同じストリームキーを入れます。チャンネルもその設定も何も変わりません — 変わるのは、接続がどこから出ていくかだけです。

シーンやオーバーレイはどうなりますか？

SplitCam の中で作ります：1枚のキャンバスにレイヤーとして重ねたソース、AI背景除去、エフェクト、オーバーレイ用のブラウザソース。OBS からの乗り換えでもあるなら、SplitCam は OBS のシーンコレクションをワンクリックでインポートします。

配信しながら録画できますか？

はい、お使いのマシン上にローカルで録画します。そしてそれは、そのときオンラインサービスがどうなっていようと動き続けます。

無料版に落とし穴はありませんか？

作成するアカウントも、時間制限も、透かしもありません。SplitCam は2003年からずっと無料で、現在のバージョンは v10.9.2 です。
