バーチャルカメラ

あらゆる会議アプリで使えるバーチャルカメラ。

無料のバーチャルカメラソフト。SplitCam を Zoom 用バーチャルカメラとして、Microsoft Teams・Google Meet・Discord・Telegram・WhatsApp・OBS など60以上のビデオアプリで使えます。シーン・AI背景除去・美顔フィルター・オーバーレイをのせた仮想Webカメラです。OBS バーチャルカメラ・ManyCam・Camo・ChromaCam・終了した Snap Camera の無料の代替。縦9:16・横16:9、最大64本の同時出力に対応。Windows・macOS・iOS・Android で動作します。

よく使われる5つの理由。

💼

Zoom・Teams のリモートワーカー

散らかった背景を、AIが認識するぼかしや好きな画像に置き換え — グリーンバックは不要です。美顔モードで肌を整え、画面と顔を同じ映像に。新しいカメラを買わなくても、きちんとした見た目になります。

🎮

Discord 通話をする配信者

配信に使っている SplitCam のシーンを、そのまま Discord のカメラに。Twitch のチャットには配信が、Discord の友だちにはオーバーレイやエフェクトをのせた同じカメラが見えます。設定を切り替える必要はありません。

🎓

オンライン授業の先生

ホワイトボード・スライド・動画・自分の顔を1つの映像に。描画ツールで授業中にそのまま書き込めます。ホットキーで動くタイマーは授業内のアクティビティに便利。すべて1つのWebカメラとして Zoom / Meet / Teams に出力されます。

📺

製品デモやインタビュー

通話中に、顔・スライド・ブラウザのタブ・Webカメラを切り替え。名前と肩書きのテロップを追加。ぎこちない画面共有の切り替えではなく、映画のようなトランジションで。

✨

ビデオ通話する VTuber

VTube Studio のアバターをクロマキー + AI背景で SplitCam に取り込めば、どの会議アプリでも本当の顔の代わりにアバターが映ります。ブラウザでも使えます。

📞

Webカメラの画質に悩む人

ノートPC内蔵カメラでも、美顔フィルター・明るさ補正・背景置き換えでぐっと良く見えます。買い替えられないハードへの、無料の処方箋です。

設定は2分

もっと良いWebカメラまで3ステップ。

1

SplitCam をインストール

Windows・macOS・iOS・Android 向けに無料でダウンロード。バーチャルカメラ・ドライバーは初回起動時に自動でインストールされます — 別途の設定も、管理者権限のひと手間も要りません。

2

シーンを作る

ソースを追加：Webカメラ・画面・ブラウザのタブ・動画ファイル。AI背景・美顔・オーバーレイをかけます。SplitCam にはビデオ通話向けのプリセット集があるので、選んで自分好みに調整するだけです。

3

会議アプリで「SplitCam Camera」を選ぶ

Zoom・Teams・Meet・Discord で「設定」→「ビデオ」→カメラの一覧を開き、「SplitCam Camera」を選びます。これで完了。あなたのシーンがそのままWebカメラになります。

バーチャルカメラとは？

スタジオまるごとを、1つのWebカメラに。

バーチャルカメラとは、物理的なWebカメラをエミュレートするソフトです。パソコンから見るとUSBカメラとまったく同じに見え、Webカメラ入力に対応したアプリ（Zoom・Teams・Meet・ブラウザ、何でも）はそれを認識し、ふつうのカメラとして扱います。

違いはこうです。カメラそのままの生映像の代わりに、バーチャルカメラは SplitCam で組み立てた映像をそのまま出力します — 本物のWebカメラに加えて、AI背景除去・美顔フィルター・画面キャプチャ・ブラウザのオーバーレイ・テロップ・音楽ビジュアライザー。シーンにあるものが、そのまま会議アプリに届きます。

Windows は通常、物理Webカメラを1つのアプリにしか割り当てません — Zoom 通話を始めると、Teams は真っ暗な画面になります。SplitCam のバーチャルカメラは、この制限を完全に取り払います。最大64個のアプリが同時に読み取れて、追加の遅延もありません。

会議の印象を変える機能。

縦も横も

横16:9（Zoom・Teams・Meet）と縦9:16（モバイルアプリ・縦型 Instagram Live）をワンクリックで切り替え。同じシーンで、両方の向きに対応します。

AI背景除去

ニューラルネットがあなたのシルエットをリアルタイムで検出。背景を置き換え・ぼかし・除去 — グリーンバックも設定も不要です。Zoom 内蔵のぼかしより高速です。

美顔エフェクト

肌のなめらか補正・肌色補正・顔トラッキング・髪色・リップ補正・目の拡大。配信モデル級のレタッチを、その場でかけられます。

複数アプリへの出力

最大64個のアプリが、SplitCam カメラの映像を同時に読み取れます。Zoom・Teams・Discord が同じ瞬間に同じ映像を使えます — Windows のロックはありません。

シーン切り替え

トークヘッド・ホワイトボード・スライド・マルチカメラなど、いろいろなレイアウトを用意して、通話中にホットキーで切り替え。テレビのスタジオでカメラを切り替えるように。

ハードウェア・アクセラレーション

デフォルトでGPUエンコーダー（NVENC・QuickSync・AMF）を使用。CPU負荷はゼロ — 会議アプリは、裏で処理が走っていることにすら気づきません。

よくある質問

バーチャルカメラについての質問。

ダウンロード前に知っておきたいこと、すべて。

SplitCam のバーチャルカメラは macOS で動きますか？

はい。SplitCam には macOS ネイティブのバーチャルカメラがあり、Zoom・Teams・Google Meet・Discord・Safari・Chrome など、システムのカメラAPIを使う macOS アプリすべてに表示されます。macOS 11 Big Sur 以降に対応しています。

Mac の Zoom でもちゃんと動きますか？

はい。macOS の Zoom は SplitCam をふつうのカメラとして扱います。Zoom →「設定」→「ビデオ」で一覧から「SplitCam Camera」を選んでください。AI背景除去・美顔フィルター・シーン切り替えは、すべて Zoom の通話中にそのまま使えます。

複数のアプリで SplitCam を同時に使えますか？

はい — 最大64本の仮想出力に対応します。Zoom・Teams・Discord・OBS・ブラウザが、同じ瞬間に SplitCam Camera から映像を読み取れます。Windows は通常、物理Webカメラを1つのアプリにしか割り当てませんが、SplitCam はこの制限を回避します。人気の組み合わせは、同じ映像で YouTube のライブ配信と Zoom 通話を同時に流すやり方です。

ブラウザのビデオ通話（Google Meet、Jitsi）でも動きますか？

はい。ブラウザは WebRTC のメディアAPIを通して SplitCam をふつうのWebカメラとして認識します。Google Meet・Jitsi・Around・Whereby など、設定なしで動きます。通話のカメラ一覧を開いて「SplitCam Camera」を選ぶだけです。

ふつうのWebカメラに戻すにはどうすればいいですか？

会議アプリの設定でカメラの一覧を開き、「SplitCam Camera」の代わりに物理Webカメラを選ぶだけです。再起動は不要です。通話中ならいつでも切り替えられます。

SplitCam のバーチャルカメラは4Kに対応していますか？

1920×1080（1080p）60fps までの出力は全プラットフォームで対応しています。4K出力は、ハードウェアエンコード（NVENC・QuickSync・AMF）対応の Windows と、Apple Silicon の macOS で利用できます。多くのビデオ会議アプリは、ソースに関係なく受信映像を720pや1080pに制限します。

遅延やラグはありますか？

バーチャルカメラの出力はGPU速度で処理されるため、追加の遅延は通常16ms以下（60fpsで約1フレーム）です。比較すると、Zoom 通話のネットワーク往復は100〜300msです。体感できるほどの遅れはありません。

SplitCam のバーチャルカメラは本当に無料ですか？

はい — 個人利用も商用利用も完全に無料です。AI背景・美顔エフェクト・シーン切り替え・複数アプリ出力など、すべての機能が使えます。映像に透かしは入らず、試用期間もアップセルもありません。

SplitCam は OBS バーチャルカメラや ManyCam、Snap Camera の代わりになりますか？

はい。SplitCam は OBS バーチャルカメラ（プラグイン設定なしでスタジオ機能が丸ごと内蔵）、ManyCam（有料に対して無料）、Camo（スマホなしで動作）、Snap Camera（Snap が2023年に終了）、ChromaCam、FineCam、mmhmm、XSplit VCam、Animaze の無料の代替になります。バーチャルカメラ・AI背景除去・美顔フィルターといった主要機能はすべて無料で使えます。詳しい比較は SplitCam と OBS の比較をご覧ください。

SplitCam のバーチャルカメラは Telegram や WhatsApp のビデオ通話でも動きますか？

はい。Windows・macOS の Telegram Desktop も WhatsApp Desktop も、任意のシステムWebカメラを選べます。SplitCam はカメラ設定に「SplitCam Camera」として表示されます。シーン・AI背景・美顔フィルター・オーバーレイを、Zoom と同じように Telegram や WhatsApp のビデオ通話にも適用できます。

AI背景除去にグリーンバックは必要ですか？

いいえ。SplitCam は端末上のAIで画面内の人物を検出し、リアルタイムで背景を除去します — グリーンバックもクロマキーの設定も不要です。グリーンバックをお持ちなら、専用のクロマキー機能でさらにくっきりした輪郭が得られます。

SplitCam を縦向き（9:16）のWebカメラとして使えますか？

はい。キャンバスを9:16の縦向きに切り替えると、SplitCam は縦動画を出力します。ブラウザでの TikTok Live、Web版 Instagram Live、縦向きWebカメラ入力に対応したアプリにぴったりです。デフォルトは横16:9です。
