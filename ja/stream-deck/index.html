SplitCam/Stream Deck
Stream Deck

Stream Deck から SplitCam を操作 — いま持っているスマホからでも。

Stream Deck は、配信中にウィンドウを探し回らずに済ませるためのボタンの箱です。そのボタンで操作したいのが配信だけなら、ポケットの中のスマホが同じ仕事を無料でこなします。SplitCam Remote なら、シーンを切り替え、配信と録画を開始・停止し、いま何が配信中なのかも手元で分かります — すべてお使いの Wi-Fi 経由で。

結論：スマホで足りるとき、足りないとき
  1. 何も買わずに済むことが要点です。SplitCam Remote は無料で、お使いのネットワーク上で動きます。ハードウェアもドングルもサブスクも、一切ついていません。
  2. 操作できるのは SplitCam だけです。本物の Stream Deck は、どんなプログラムのボタンでも押せます — OBS、ブラウザ、照明、マクロ。このスマホアプリにそれはできません。多くの人にとって、この違いが決め手になります。
  3. いまのところ iOS アプリです。Android 版は開発中で、まだ公開されていません。今日 Android をお使いなら、これはまだ選択肢になりません。
  4. すでに Stream Deck をお持ちなら、そのまま使ってください。Elgato Marketplace に SplitCam 公式の無料プラグインがあります — Windows 専用で、SplitCam 10.8.25 以降が必要です。

配信中、スマホが実際にやること

以下はすべて、SplitCam Remote が実際にできると明記されている内容です — コントローラーに理論上ありうる機能の願望リストではありません。

手元でシーンを切り替える

そもそも多くの人がコントローラーを欲しがる理由です。カメラを替える、レイアウトを替える、スライドに切り替える — PCまで歩いて戻ることも、全画面のゲームの裏に隠れたウィンドウを探すこともなく。

配信と録画の開始・停止

ライブを始める、配信を終える、録画を開始・停止する、スナップショットを撮る、一時停止やミュートをする — キーボードに手を伸ばす姿が視聴者にいちばん目立つ、まさにその瞬間に必要な操作です。

いま何が起きているかが分かる

アプリは配信名とステータスを手元に返します。部屋の反対側からでも、配信中かどうかを推測せずに確認できます。

数秒でペアリング、通信は自分のネットワーク内

SplitCam の設定にある「Remote Control」タブの QRコードを読み取るか、アプリが Wi-Fi 経由でPCを自分で見つけるのに任せるだけ。QRコードでのペアリングは、2台の端末を引き合わせるために当社のサーバーを経由します。Wi-Fi での自動検出なら、通信はお使いのネットワーク内にとどまります。

ハードウェアなしでやる価値がある理由

スマホを選ぶ理由は、安いからではありません。この仕事に関しては、劣らないからです。

ボタンはもうポケットの中にある

コントローラーの値打ちは、カメラから目を離さずに手が届くことにあります。キーボードの横に立てかけたスマホは、ボタンの箱と同じくらい手が届きますし、そもそも買う必要がありません。

ラベルはシーンに合わせて変わる

物理キーは、キーの表示を自分で用意する必要があります。画面なら現在のシーン一覧がそのまま出るので、シーン名を変えてもボタンに古いラベルが残りません。

本番で壊れるものが増えない

USB機器が1つ減り、ケーブルが1本減り、部屋を移るときや会場へ機材を運ぶときに抜くものが1つ減ります。

SplitCam の残りも無料です

シーン、84+プラットフォームへのマルチ配信、バーチャルカメラ、エフェクト、オーディオミキサーは同じ無料ダウンロードに入っています — 操作用アプリを閉ざす有料プランはありません。

それでも Stream Deck を買うべきとき

自分が何を押したいのか、正直に考えてください。ボタンで SplitCam の外側を操作する必要があるなら — OBS のシーンを呼び出す、別のアプリから効果音を鳴らす、マクロを走らせる、照明を落とす、Discord をミュートする、チャットにリンクを貼る — その場合は Stream Deck が正しい道具で、スマホアプリは代わりになりません。SplitCam Remote が操作できるのは SplitCam だけだからです。見ずに叩ける物理キーが欲しい、スリープにも着信にも中断されない常時オンの操作面が欲しい、キーごとの画面が点いたままであってほしい — こうした場合も同じです。そして Android をお使いなら、コンパニオンアプリはまだ公開されていないので、今日この2つのうち使えるのはハードウェアだけです。どれも小さな話ではありません — Stream Deck は良い製品で、買うべき人はたくさんいます。

すでに Stream Deck をお持ちなら：つなぎ方はこうです

SplitCam は Elgato Marketplace に公式プラグインを公開しています。無料で、Windows 専用で、起動中のアプリと直接やり取りします — ポートもパスワードもペアリングも不要です。

1. SplitCam を更新する

Stream Deck 対応は Windows 版のビルド 10.8.25（2025年1月）で追加されました。それより新しければどれでも動きます。現行リリースで問題ありません。

2. プラグインをインストールする

Stream Deck アプリ（6.9 以降）で Marketplace を開き、SplitCam で検索するか、掲載ページから直接インストールします。公開元はサードパーティではなく SplitCam です。

3. キーに操作を割り当てる

配信の開始・停止、シーンの切り替え、録画の開始・停止、シーンの一時停止、ミュート、スナップショット。シーン名は SplitCam から取得されるので、キーには切り替え先のシーンが表示されます。キーには SplitCam の現在の状態とセッションの経過時間も反映されます。

4. 必要ならつなげて使う

これらの操作は Multi Action の中でも使えるので、1回押すだけでシーンを切り替え、配信を開始し、そのキーに載せたほかの操作まで実行できます。SplitCam のチャンネルには短い設定手順の動画があります — 2024年末にプラグイン 1.0 向けに収録されたものなので、最新の情報は掲載ページを参照してください。

このプラグインにできないこと：macOS では動きません — Mac では、iPhone に入れた無料の SplitCam Remote アプリが、操作面からシーンを切り替える手段になります。ダイヤルには対応しておらず、プロファイルも同梱されていません。この6つの操作以外については、プラグイン自身のバージョン履歴が載っている最新の掲載ページを確認してください。

キーでできること

公式プラグインがキーに載せる6つの操作を、SplitCam の掲載ページにある通りに紹介します。キーには SplitCam の現在の状態が表示され、配信開始・停止のキーには配信を始めてからの経過時間が出ます。

シーンの切り替え

シーンごとにキーが1つ。シーン名は SplitCam から取得されるので、キーには切り替え先のシーンが表示されます。

配信の開始・停止

キーから配信の開始も終了もできます。配信中は、キーにセッションの経過時間が表示されます。

録画の開始・停止、スナップショット

キーボードに触れずに、ファイルへ録画したり、現在のシーンの静止画を撮ったりできます。

ミュート、シーンの一時停止

音をミュートするか、シーン全体を一時停止します — すべてのソースが一斉に止まります。再開も同じキーで。

6つすべてが Multi Action の中で使えます。ダイヤル（Stream Deck +）向けの操作はなく、プロファイルも同梱されていません。プラグインのMarketplace 掲載ページにバージョン履歴があり、現行リリースは 1.2 です。

プラグインなしでも、ホットキーならどの Stream Deck でも使える

プラグインをインストールできないマシンでも、Stream Deck 標準の「ホットキー」アクションで SplitCam を操作できます。使うのはグローバルショートカットです — SplitCam が最小化されていても、別のウィンドウがアクティブでも効きます。Ctrl 付きの組み合わせは、SplitCam のウィンドウにフォーカスがあるときだけ動きます。ホットキーは SplitCam の設定でオフにもできるので、オンになっているか確認してください。

SplitCam にできないこと

ここにある比較ページすべてに同じ一覧を載せています。ダウンロードしてから気づくのではなく、早い段階で私たちを候補から外せるようにするためです。

リンクで参加するゲストはいない

誰かに送れるブラウザのリンクはありません。ゲストの Zoom、Meet、Discord のウィンドウをウィンドウキャプチャでシーンに置くことはでき、それは動きますが、機能ではなく回避策です。

プレビュー／プログラムなし、マルチビューなし

シーンは切り替えるものであって、先にキューしてからカットするものではありません。ソースのプレビューを並べた一覧もありません。本格的なスイッチャーの流儀で演出しているなら、すぐに違和感を覚えるはずです。

カメラごとの録画なし、PTZ 制御なし

録画に収まるのは合成済みのシーンで、あとで編集するためのカメラ1台につき1ファイルではありません。SplitCam の中に、カメラをパン・チルト・ズームしてくれるものは何もありません。

NDI は受けるだけで、送り出さない

NDI をソースとして取り込むことはできます。SplitCam は、別のマシンが拾えるような NDI の送信側にはなりません。

一部のソースは Windows のみ

Windows 限定と明記されているもの：Whiteboard、Application Audio、Replay ソース、単色の Color ソース。シーン、レイヤー、バーチャルカメラ、マルチ配信、録画は両方で動きます。

スマホのリモートは現時点で iOS のみ

SplitCam Remote は App Store にあります。Android 版は開発中で、まだリリースされていません。スマホをカメラとして使う機能はそれとは別で、iOS 限定ではありません。

Stream Deck 代替のよくある質問

SplitCam Remote は本当に無料ですか？

はい。SplitCam のコンパニオンアプリで、SplitCam 自体もウォーターマークなし・有料プランなしの無料です。どちらにも解除するものはありません。

Stream Deck を完全に置き換えられますか？

押したいものがすべて SplitCam の中にある場合だけです。シーンの切り替え、配信と録画の開始・停止、スナップショット、ミュートはできますが、ほかのアプリのボタンを押すことはできません。複数のプログラムをまたぐ使い方なら、ハードウェアを買ってください。

Android 版はありますか？

まだありません。SplitCam Remote は iOS 版が App Store で公開中で、Android 版は開発中です。

すでに Stream Deck を持っています。SplitCam で使えますか？

はい、Windows で使えます。Elgato Marketplace から SplitCam 公式の無料プラグインをインストールし（Stream Deck アプリ 6.9 以降）、SplitCam を 10.8.25 以降に更新してください。キーには配信の開始・停止、シーンの切り替え、録画の開始・停止、シーンの一時停止、ミュート、スナップショットを割り当てられ、SplitCam の現在の状態も表示されます。プラグインの macOS 版はありません。

スマホはどうやってPCを見つけるのですか？

SplitCam の設定にある「Remote Control」タブの QRコードを読み取るか、アプリが Wi-Fi 経由でPCを自動検出するのに任せてください。どちらでも動きます。初回は QRコードのほうが手早いです。

接続は御社のサーバーを経由しますか？

ペアリングは、スマホをお使いのPCに引き合わせるために SplitCam のサーバーを経由します。サーバーを通るのはこの最初のやり取りだけで、お互いを見つけたあとは、操作の通信はお手元の2台の端末の間を直接流れます。
