예배 라이브 방송을 모든 플랫폼에 — 무료 프로그램 하나로.

예배를 Facebook + YouTube + 교회 웹사이트에 동시에 라이브 방송하세요. 장면이 있는 멀티 카메라, 설교자 하단 자막, 화면 위 찬양 가사까지. 구독도, 워터마크도, 시청자 제한도 없습니다. 교회에 이미 있는 PC나 노트북이면 충분합니다.

요약 — 5단계로 무료 예배 송출
SplitCam은 주일 예배를 Facebook Live, YouTube Live, 그리고 RTMP로 교회 웹사이트에 동시 송출하는 무료 프로그램입니다. 설정 방법:
  1. 음향실 PC(Windows 또는 macOS)에 SplitCam 설치.
  2. 카메라를 장면 레이어로 추가 — 풀샷, 강단, 찬양팀.
  3. 교회 믹싱 콘솔의 오디오를 USB 오디오 인터페이스로 연결.
  4. 하단 자막과 가사를 위한 브라우저 소스 추가(ProPresenter 네트워크 출력이면 됩니다).
  5. 각 플랫폼의 스트림 키 붙여넣기 → '방송 시작'. 스트림이 모든 플랫폼에 한 번에 나갑니다.

주일 예배 송출 — 단계별

완전한 교회 방송 구성은 약 10분이면 만들어집니다 — 그것도 처음 한 번만. 그다음부터 매주 송출은 클릭 한 번입니다. 카메라가 한 대든 네 대든 방식은 똑같습니다.

1
음향실 PC에 SplitCam 설치 ~ 2분

슬라이드를 띄우는 교회 노트북이나 음향실 PC에 SplitCam을 설치하세요 — Windows 10/11과 macOS 11+에서 작동합니다. 비용이 없고, 계정을 요구하지 않으며, 방송 시간을 제한하지 않고, 영상에 워터마크를 절대 넣지 않습니다.

교회에 '무료'가 중요한 이유: 대부분의 유료 솔루션(vMix, Resi, BoxCast)은 월 $60~$500 또는 일회성 $1,200입니다. 그 예산이면 두 번째 카메라나 무선 마이크 세트를 사는 편이 낫습니다.
2
카메라를 장면 레이어로 추가 ~ 3분

각 카메라를 PC에 연결해 소스로 추가하세요. SplitCam이 지원하는 것:

• USB 웹캠 — Logitech C920 / Brio는 $200 이하
• DSLR과 캠코더 — HDMI 캡처 카드(Elgato Cam Link 4K, 약 $130)를 통해
• 휴대폰 — Wi-Fi로 추가 앵글, iOS / Android용 SplitCam 앱으로
• 완성된 영상을 소스로(인트로, 세례 영상, 광고)

원하는 화면마다 장면을 만드세요: 풀샷, 강단, 찬양팀, 가사 슬라이드, 곧 돌아옵니다. 예배 중에 F1–F5 키로 전환합니다.

팁: 가사 슬라이드를 화면에 계속 띄우지 말고 별도 장면으로 두세요. 방송 운영자가 찬양이 시작되면 그쪽으로 전환하고, 목사님이 말씀하시면 설교자 카메라로 돌아옵니다 — 현장 프로젝터와 똑같이.
3
믹싱 콘솔에서 오디오 연결 ~ 2분

화질에서 가장 큰 향상은 여기에 있습니다. 방송 소리는 현장 울림을 잡는 PC 내장 마이크가 아니라 교회 믹싱 콘솔의 출력에서 와야 합니다.

USB 오디오 인터페이스(Behringer UMC22 약 $50, Focusrite Scarlett Solo 약 $120)를 마련해 콘솔의 aux/모니터 출력을 PC로 보내세요. SplitCam에서 이 인터페이스를 오디오 소스로 선택합니다. 회중이 현장에서 듣는 모든 것 — 설교, 찬양팀, 오르간 — 을 라이브 시청자도 듣게 됩니다.

소리가 화면보다 중요합니다. 시청자는 720p 설교 화면은 봐줍니다. 먹먹하고 먼 소리는 봐주지 않습니다. 예산을 먼저 소리에 쓰고, 네 번째 카메라는 그다음입니다.
4
하단 자막과 찬양 가사 추가 ~ 2분

설교자 자막(하단 자막): 설교자 이름과 설교 제목이 담긴 텍스트 소스를 추가하세요. 좌하단에 배치합니다. 표시 여부는 장면별로 설정됩니다 — 강단 화면에서는 자막이 보이고, 찬양 중에는 숨겨집니다.

찬양 가사: 가사 페이지를 불러오는 브라우저 소스를 추가하세요. 교회에 ProPresenter가 있다면 Network → Web URL 출력을 켜고 그 주소를 SplitCam에 지정하세요. 찬양 인도자가 슬라이드를 넘기는 대로 가사가 방송에 표시됩니다 — 무료 OpenLP도 스테이지 디스플레이 URL로 같은 방식으로 작동합니다.

저작권 관련: Facebook / YouTube에 찬양 가사를 송출하려면 스트리밍 라이선스가 필요합니다 — 예: CCLI Streaming License(보통 연 $50~$300). 라이선스는 플랫폼을 위한 것으로, 프로그램과는 무관합니다.
5
Facebook + YouTube + 교회 웹사이트에 동시 송출 ~ 1분

스트림 설정을 여세요. 원하는 플랫폼을 체크합니다:

• Facebook Live — Facebook 페이지 → Live Producer에서 스트림 키를 붙여넣기.
• YouTube Live — studio.youtube.com → '실시간 스트리밍 시작'에서 스트림 키를 붙여넣기.
• 교회 웹사이트 — 내 RTMP 주소 + 키 붙여넣기(Wowza, Vimeo, AWS IVS, 또는 자체 Nginx-RTMP).
• 더 많은 플랫폼 — Twitch, Kick, X/Twitter 등 84개+ 사전 설정 대상.

'방송 시작'을 한 번 누르세요. 모든 플랫폼이 동시에 방송을 받습니다. 스트림은 내 PC에서 중간 클라우드 서버 없이 직접 각 플랫폼의 인제스트 서버로 전송됩니다 — 월 요금도, 시청자당 추가 비용도 없습니다.

토요일 리허설: 전날 공개 범위를 '비공개'나 '나만 보기'로 두고 30분짜리 전체 테스트 방송을 해보세요. 소리 레벨, 카메라 구도, 가사 출력을 확인하세요. 첫 주일 방송은 마이크가 울거나 렌즈 캡이 씌워져 있다는 걸 발견할 때가 아닙니다.
교회에 동시 송출이 중요한 이유

성도마다 보는 플랫폼이 다릅니다. 어르신들은 교회 웹사이트 링크를 엽니다. 다른 도시에 흩어진 장성한 자녀들은 Facebook으로 봅니다. 청년들은 YouTube에서 봅니다. 외출이 어려운 분들은 태블릿에서 가장 빨리 열리는 것을 켭니다.

한 플랫폼만 고르면 나머지를 놓칩니다. SplitCam은 예배를 내 PC에서 직접 모든 곳에 한 번에, 무료로 송출합니다. 월 $19의 Restream과 월 $25의 StreamYard를 대체합니다.

매주 송출하는 교회들의 팁

방송을 아마추어가 아닌 프로답게 만드는 작은 디테일들.

🎤 항상 음소거로 시작하기

모든 방송을 마이크 음소거와 '환영합니다 — 예배는 10:30에 시작합니다' 슬라이드로 시작하세요. 예배가 실제로 시작될 때 소리를 켭니다. 그러면 일찍 들어온 분들이 "이거 되나?"를 듣지 않습니다.

📺 PC에 유선 인터넷

예배 도중 Wi-Fi 끊김은 방송을 망칩니다. 음향실까지 랜선을 연결하세요. 8m 케이블은 $10입니다. 안정성을 위한 가장 저렴한 개선입니다.

🎬 '전환용' 장면 만들기

장면 1: 음악과 함께 '예배는 10:30에 시작합니다'. 장면 2: 찬양 중 '함께 찬양해요'. 장면 3: 설교 중 강단. 장면 4: '함께해 주셔서 감사합니다 — 다음 주일 10:30'.

📊 통계를 맡을 사람 지정하기

SplitCam의 실시간 지표는 예배 내내 인코더 부하와 연결 상태를 보여줍니다. 표시가 빨갛게 변하면 비트레이트를 낮추세요 — 설교 내내 품질이 나빠진 방송이 흐르게 두지 마세요.

📝 토요일 리허설을 하세요

매월 첫째 주 토요일에 다음 날 예배 스트림의 전체 리허설을 진행하세요. 30분이면 충분하고, 공개 설정은 "일부 공개"로. 생방송 전에 문제를 미리 잡아냅니다.

⛪ CCLI 라이선스를 지키세요

찬송가와 워십 곡을 스트리밍하려면 CCLI Streaming License가 필요합니다(교회 규모에 따라 연 $50~$300). 없으면 Facebook과 YouTube가 스트림을 자동으로 음소거하거나 차단할 수 있습니다.

교회 스트리밍 자주 묻는 질문

교회용 무료 스트리밍 소프트웨어 중 가장 좋은 것은?

SplitCam은 교회를 위한 최고의 무료 옵션 중 하나입니다. Facebook + YouTube + 교회 웹사이트로 동시에 송출하는 기능 내장, 다중 카메라 장면 전환, Browser Source를 통한 하단 자막과 가사 오버레이, 워터마크 없음, 구독 없음. OBS Studio도 무료지만 동시 송출에는 플러그인이 필요하고 자원봉사 운영자가 익히기에는 학습 곡선이 더 가파릅니다.

주일 예배를 Facebook과 YouTube에 동시에 송출할 수 있나요?

네 — SplitCam에는 동시 송출 기능이 내장되어 있습니다. Facebook Live와 YouTube Live의 스트림 키를 붙여넣고 "방송 시작"을 한 번 누르면 두 플랫폼이 동시에 스트림을 받습니다. 동시에 RTMP로 교회 자체 웹사이트에도 보낼 수 있습니다. 스트림은 교회 PC에서 곧바로 피어 투 피어(peer-to-peer)로 전송됩니다 — 중간 클라우드 서버도, 월 요금도 없습니다. 동시 송출 자세히 보기를 참고하세요.

교회용 스트리밍 소프트웨어 비용은 얼마인가요?

SplitCam은 100% 무료이며 워터마크도, 시간 제한도 없습니다. 유료 옵션: vMix Basic HD $60 1회 구매(입력 4개 제한, 동시 송출 없음), vMix Pro $1,200 1회 구매(전체 기능), ProPresenter $499+(워십 중심이며 본격적인 스트리밍 인코더는 아님), Resi 월 $99~$249(클라우드 기반), BoxCast 월 $99~$499.

주일 예배를 스트리밍하려면 별도의 PC가 필요한가요?

꼭 그렇지는 않습니다 — 프로젝터 슬라이드나 ProPresenter를 구동하는 PC와 같은 컴퓨터에서 SplitCam을 실행할 수 있습니다. 단, CPU/GPU 여유가 충분해야 합니다(Intel i5 8세대+, 16GB RAM 권장). 1080p에서 카메라 3대 이상을 쓰는 구성이라면 프레임 누락을 막기 위해 전용 스트리밍 PC를 권장합니다.

교회 라이브 스트림에 곡 가사를 어떻게 넣나요?

SplitCam에 가사 페이지를 가리키는 Browser Source를 추가하세요. ProPresenter를 쓴다면 Network → Web URL 출력을 켜고 SplitCam의 Browser Source를 그 URL로 향하게 하세요. OpenLP나 다른 무료 옵션을 쓴다면 해당 스테이지 디스플레이 웹 URL로 향하게 하세요. 찬양팀이 슬라이드를 넘기는 동안 가사가 스트림에 실시간으로 표시됩니다. 참고: 저작권이 있는 가사를 스트리밍하려면 CCLI Streaming License가 필요합니다.

교회 스트리밍에 여러 대의 카메라를 쓸 수 있나요?

네 — SplitCam은 무제한 카메라를 장면 소스로 지원합니다. 각 카메라를 PC에 연결하세요(USB 웹캠, Elgato Cam Link 같은 HDMI 캡처 카드를 통한 DSLR, 또는 추가 무선 앵글로 SplitCam 모바일 앱을 실행하는 스마트폰). 전체 샷, 강단 클로즈업, 찬양팀, 가사 슬라이드 등의 장면을 만들어 두세요. 예배 중에 단축키(F1, F2, F3...)로 장면을 전환하세요.

오래된 교회 컴퓨터에서도 SplitCam이 작동하나요?

SplitCam은 Windows 10/11과 macOS 11+에서 작동하며, 하드웨어 요구 사항이 높지 않습니다. 1080p 다중 카메라 스트리밍에는 Intel i5 8세대나 Ryzen 5에 16GB RAM이면 넉넉합니다. 720p 단일 카메라 스트리밍이라면 i3 / 8GB RAM의 오래된 노트북으로도 가능합니다. 하드웨어 인코딩(NVENC / QuickSync / AMF)이 CPU 부하를 덜어 줍니다.

SplitCam은 주일 생방송 예배에 충분히 안정적인가요?

네 — SplitCam은 2003년부터 활발히 개발되어 왔으며 전 세계 교회와 방송 사업자가 사용합니다. 인코더는 안정성을 위해 하드웨어 가속을 사용하고, 상태 모니터는 프레임 누락을 실시간으로 보여주며, 동시 송출 구조는 피어 투 피어(peer-to-peer)입니다 — 한 플랫폼이 끊겨도 나머지를 끌고 내려가지 않습니다. 첫 주일 생방송 전에 토요일 리허설을 해 보세요.
