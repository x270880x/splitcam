유튜버용

유튜브 라이브 방송하는 법 — 무료 프로그램, 5분 설정.

완전한 단계별 가이드. 무료 SplitCam이 여러분의 인코더가 됩니다 — 가입도, 카드도, 스트림 워터마크도 없이. 장면을 구성하고 소스를 전환하며 1080p 60fps로 방송하세요. 보너스: 하나의 방송이 YouTube + Twitch에 동시에 나갑니다.

빠른 답변
5분 만에 유튜브 라이브 방송하는 법:
  1. SplitCam 다운로드(무료, 가입 불필요) — Windows / macOS / iOS / Android.
  2. 카메라 추가(웹캠, 화면 캡처, 게임 캡처)를 장면 레이어로.
  3. 스트림 키 복사: studio.youtube.com → 만들기 → 실시간 스트리밍 시작 → 스트림.
  4. 키 붙여넣기 SplitCam → 스트림 설정 → YouTube. 1080p 비트레이트는 4.5Mbps.
  5. SplitCam에서 '방송 시작', 그다음 YouTube Studio에서 '실시간 스트리밍 시작'. 이제 라이브입니다.

단계별: 유튜브 라이브 방송

제로에서 방송까지 약 5분. Windows 11과 macOS 14에서 검증했으며, 다른 플랫폼도 과정은 똑같습니다.

1
SplitCam 다운로드 ~ 1분

SplitCam은 YouTube와 어떻게 통신할지 이미 아는 무료 스트리밍 스튜디오입니다: RTMP 주소가 프리셋에 내장되어 있어 직접 입력할 필요가 없습니다. 설치 프로그램은 가볍고 Windows 10/11, macOS 11+, iOS 16+, Android 8+에서 작동합니다. 계정도, 카드도, 시간 제한도 없습니다.

일반 인코더보다 나은 점: YouTube 프리셋이 스트림 수동 설정을 덜어주고, 단축키로 Replay 소스가 직전 하이라이트를 잘라내며, 배경 교체가 그린 스크린 없이 기기에서 바로 작동합니다. 1인 크리에이터도 손 하나 더 빌리지 않고 깔끔한 방송을 만듭니다.
2
시청자에게 보일 화면 구성 ~ 2분

SplitCam을 열고 소스를 캔버스에 올리세요: 웹캠 — 얼굴 화면용, 게임 캡처 — DirectX/OpenGL 게임용, 화면 캡처 — 튜토리얼·리액션용, 브라우저 소스 — 오버레이용, 여기에 이미지, 클립, Wi-Fi로 연결한 폰의 두 번째 앵글까지.

이 레이어들을 인트로, 메인, 저스트 채팅, BRB 같은 여러 개의 이름 있는 장면으로 구성하고 각각을 단축키(F1, F2…)에 지정하세요. 방송 중에 즉시 전환할 수 있고, 더 영화 같은 화면을 원하면 Fade / Luma Wipe / Slide 전환을 쓰세요.

크리에이터 팁: 브라우저 소스를 알림 위젯에 연결하세요 — 신규 구독, 슈퍼챗, 목표 달성 바 알림. 모든 움직임이 시청자 눈앞에 그대로 남고, 별도 알림 앱이 리소스를 잡아먹지 않습니다.
3
YouTube 스트림 키 가져오기 ~ 30초

studio.youtube.com에 로그인 → 만들기(우상단) → 실시간 스트리밍 시작을 누르세요. 왼쪽 메뉴에서 스트림 탭을 엽니다.

방송 제목, 설명, 카테고리를 입력하세요. 오른쪽 설정 패널에서 스트림 키를 복사합니다(xxxx-xxxx-xxxx-xxxx-xxxx 형태).

⚠ 보안: 스트림 키는 비밀번호와 같습니다: 공개하지 말고 git에도 올리지 마세요. 키가 유출되면 누구나 여러분 채널로 방송할 수 있습니다. YouTube Studio에서 언제든 재설정할 수 있습니다.
4
SplitCam과 YouTube 연결 ~ 1분

SplitCam에서 스트림 설정을 열고 YouTube(사전 설정됨)를 선택하세요. 스트림 키를 칸에 붙여넣습니다. '연결 확인'을 누르면 — 초록색 체크는 모두 연결됐다는 뜻입니다.

SplitCam의 하드웨어 인코더는 실행 시 자동으로 감지됩니다 — Nvidia 카드는 NVENC, Intel 칩은 QuickSync, AMD는 AMF — 그래서 보통 인코딩 설정을 건드릴 필요가 전혀 없습니다. 인코딩은 그래픽카드 칩에서 처리되고 CPU는 방송 중인 게임이나 앱에 그대로 쓰입니다. 비트레이트 기준은 아래와 같습니다:

해상도프레임레이트비트레이트
1080p60 fps4,500–9,000 Kbps
1080p30 fps3,000–6,000 Kbps
720p60 fps2,250–6,000 Kbps
720p30 fps1,500–4,000 Kbps
팁: 먼저 내장된 업로드 속도 테스트를 돌리세요. 실제 회선에 맞는 안전한 비트레이트 상한을 알려줍니다. 안정적으로 3Mbps인데 6Mbps로 방송하면 = 프레임 손실과 끊김.
5
'방송 시작' 클릭 ~ 5초

SplitCam에서 큰 '방송 시작' 버튼을 누르세요. 스트림이 YouTube로 출발합니다. 약 10~15초 후 YouTube Studio에서 미리보기가 활성화되어 내 스트림을 확인할 수 있습니다.

미리보기가 괜찮아 보이면 YouTube Studio(우상단)에서 '실시간 스트리밍 시작'을 누르세요. 그 순간부터 시청자가 스트림을 봅니다. 이제 라이브입니다.

이게 전부입니다. 처음 설정은 약 5분. 그다음부터는: SplitCam을 열고 '방송 시작'을 누르고 YouTube Studio에서 확인. 10초 정도면 됩니다.
보너스 — YouTube + Twitch에 동시 송출, 그 이상

SplitCam에는 동시 송출이 내장되어 있습니다. 4단계 후 YouTube 외에 Twitch / Facebook Live / Kick / TikTok Live도 체크하세요. 각 플랫폼의 스트림 키를 붙여넣습니다. '방송 시작' 한 번이면 선택한 모든 플랫폼이 동시에 스트림을 받습니다.

중간 클라우드 서버도, 월 요금도 없습니다. 스트림은 내 PC에서 각 플랫폼의 인제스트 서버로 직접 전송됩니다. Restream(월 $19)과 StreamYard(월 $25)의 무료 대안입니다. 84개+ 플랫폼이 이미 사전 설정되어 있습니다.

베테랑 스트리머는 자동으로 하지만 초보자는 놓치는 것들.

🔇 방송 전 마이크 음소거

항상 마이크를 끈 채로 시작하고 준비되면 켜세요. 방송에 흘러나가는 "이거 되는 거 맞나?"를 막아줍니다.

🔌 유선으로 연결하기

방송에는 유선 이더넷이 Wi-Fi보다 항상 안정적입니다. Wi-Fi가 불가피하다면 공유기 가까이에 앉고 5GHz 대역을 쓰세요.

🔒 먼저 일부 공개로 테스트

YouTube Studio에서 첫 방송 공개 범위를 '일부 공개'로 설정하세요. 소리, 화면, 구도를 확인합니다. 다 괜찮으면 전체 공개로 전환하세요.

⏪ 하이라이트용 Replay 소스

SplitCam의 Replay 소스는 장면의 최근 5~10초를 저장했다가 단축키로 끼워 넣습니다. 즉석 슬로모션이나 멋진 게임 순간 리플레이.

📈 방송 통계 확인하기

SplitCam은 방송 중에 인코더 부하, 프레임 손실, 대역폭을 바로 보여줍니다. 문제가 보이면 화질을 살짝 낮추세요: 조금 부드러운 1080p가 끊기는 방송보다 낫습니다.

🎞️ 카메라 하나가 아닌 장면들

최소 3개 장면을 만드세요: '잠시 후 시작' / 방송 / '곧 돌아옵니다'. 이들 사이의 전환이 화면을 생동감 있고 프로답게 유지합니다.

YouTube 방송, SplitCam vs OBS

OBS Studio는 업계 표준이지만 진입 장벽이 있습니다. YouTube 시나리오에서 SplitCam이 시간을 아껴주는 지점은 다음과 같습니다.

뷰티 필터와 AI 배경✓ 내장없음

이미 OBS를 쓰시나요? SplitCam은 OBS 장면을 클릭 한 번으로 가져오므로 옮기는 데 1분이면 됩니다. 인코더, 오픈소스, 플러그인 생태계 등 기능별 전체 분석이 궁금하신가요? SplitCam과 OBS 전체 비교 보기 →

유튜브 라이브 방송 관련 자주 묻는 질문

SplitCam은 YouTube 라이브 방송에 무료인가요?

네 — 개인 및 상업적 용도 모두 100% 무료입니다. 스트림에 워터마크도, 시간 제한도, 'Pro 버전 결제' 압박도 없습니다. 첫날부터 모든 기능이 열려 있습니다.

YouTube 라이브 방송에 비트레이트는 얼마로 설정하나요?

1080p 30fps: 3,000~6,000Kbps. 1080p 60fps: 4,500~9,000Kbps. 720p: 1,500~4,000Kbps. SplitCam의 내장 업로드 속도 테스트가 방송 전에 회선을 확인해 줍니다.

YouTube와 Twitch에 동시에 송출할 수 있나요?

네 — SplitCam에는 동시 송출이 내장되어 있습니다. YouTube와 Twitch 스트림 키를 모두 추가하고 '방송 시작'을 한 번 누르면 두 플랫폼이 동시에 스트림을 받습니다. 중간 클라우드 서버도, 월 요금도 없습니다. 자세한 내용은 동시 송출 가이드를 참고하세요.

YouTube 채널에서 라이브 스트리밍을 어떻게 켜나요?

인증된 YouTube 계정(전화 인증)과 최근 90일간 라이브 스트리밍 제한이 없어야 합니다. 모바일 라이브 방송은 구독자 50명 이상이 필요합니다. PC 방송은 구독자 요건이 없어 인증된 계정이면 누구나 라이브를 켤 수 있습니다.

OBS가 필요한가요, 아니면 SplitCam이 대체하나요?

대부분의 유튜버에게 SplitCam만으로 충분합니다: 가상 카메라, AI 배경, 동시 송출, 장면 전환이 내장되어 있고, 이미 만들어 둔 OBS 장면 모음도 그대로 읽어 들입니다. 특정 OBS 플러그인에 의존하는 분이라면 OBS를 계속 쓰는 편이 더 편할 수 있습니다.

SplitCam을 켜면 게임 FPS가 떨어지나요?

체감될 정도는 아닙니다. SplitCam은 인코딩을 그래픽카드의 전용 하드웨어에 맡깁니다 — Nvidia는 NVENC, Intel은 QuickSync, AMD는 AMF — 실행 시 인코더가 자동 선택됩니다. CPU와 주요 렌더링 코어는 게임에 그대로 쓰이므로 프레임이 안정적으로 유지되며, 대부분의 환경에서 FPS 손실이 0~3%에 그칩니다.

휴대폰에서 YouTube 라이브 방송을 할 수 있나요?

네 — iOS·Android용 SplitCam으로 휴대폰에서 바로 YouTube에 방송할 수 있습니다. YouTube 모바일 라이브 방송은 채널 구독자 50명 이상이 필요합니다. 모바일에서는 세로 9:16 캔버스가 기본값이라 YouTube Shorts Live에 딱 맞습니다.

YouTube 라이브 방송 설정에 얼마나 걸리나요?

처음에는 약 5분을 잡으세요 — SplitCam 설치, 카메라 추가, YouTube 스트림 키 붙여넣기. 그다음부터는 모두 저장되어 거의 즉시 방송이 시작됩니다: 앱을 열고 '방송 시작'을 누르고 YouTube Studio에서 확인.
