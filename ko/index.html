동시 송출

모든 플랫폼에 한 번에 라이브.

여러 플랫폼에 동시 송출하되 인코딩은 한 번만 — Twitch, YouTube, Facebook, Kick 등 84개+ 플랫폼으로 P2P 방식으로 동시에 전송됩니다. 플랫폼별로 비트레이트를 따로 설정할 수 있습니다. 중간 클라우드 서버 없음, 월 요금 없음.

  • 84개+ 플랫폼 사전 설정 완료: Twitch, YouTube, Facebook, Kick, TikTok, LinkedIn, Rumble
  • P2P 직접 전송 — 제3자 서버 없음, 개인정보 걱정 없음
  • 플랫폼마다 독립적인 비트레이트 — 각 대상이 지원하는 만큼 (예: Twitch 6Mbps, YouTube 4.5Mbps, TikTok 2.5Mbps)
  • NVENC, QuickSync, AMF 하드웨어 인코딩 — 실행 시 자동 감지
  • 지원하는 모든 플랫폼에 RTMPS 보안 스트리밍

  • Tip Notifier: 직접 만든 이미지와 감사 문구가 들어간 움직이는 알림

프로 오디오 믹서

스튜디오급 오디오 체인.

VST 2/3 플러그인을 지원하는 완전한 믹서 — 노이즈 제거, EQ, 컴프레션 등 어떤 프로 플러그인이든 SplitCam 안에서 그대로 작동합니다. 뉴럴 노이즈 제거, 레이어별 A/V 싱크 보정, 마이크 강조 기능으로 방송을 켜는 순간부터 목소리가 방송 준비 상태를 유지합니다.

  • 무제한 오디오 소스: 마이크, 시스템, 브라우저 탭, 파일, 애플리케이션
  • VST 2·VST 3 플러그인 지원 — 어떤 프로 오디오 체인이든 그대로
  • Sound Offset 필터로 오디오 레이어별 완벽한 A/V 싱크
  • 마이크 강조 기능이 말할 때 배경 소리를 자동으로 낮춤
  • 뉴럴 노이즈 제거 + 멀티트랙 녹음으로 팟캐스트급 후반 작업

배경을 즉시 제거하거나 흐리게 하거나 교체하세요. 그린 스크린이 필요 없습니다 — AI가 실시간으로 윤곽을 인식합니다.

세로 캔버스

TikTok Live, Reels, Shorts, 세로 Instagram Live를 위해 캔버스를 9:16으로 전환하세요. 스튜디오 하나로 가로·세로 모두.

뷰티 효과

피부 보정, 피부 톤, 얼굴 추적·마스킹, 머리 색, 입술 색·크기, 눈 확대 — 방송용 뷰티 효과를 클릭 한 번에.

다양한 소스

웹캠, IP 카메라, 화면, 게임, 브라우저, NDI, 동영상, 이미지, PDF — 여기에 화이트보드, Replay, 타이머까지. 필요한 모든 소스가 다 있습니다.

OBS 프로젝트 가져오기

OBS Studio 장면 모음을 클릭 한 번으로 가져오세요. 소스, 장면, 전환 효과, 단축키가 그대로 유지됩니다.

폰을 카메라로

네트워크로 연결한 무선 스마트폰을 두 번째 카메라로. 캡처 카드나 추가 장비 없이 멀티캠 구성이 가능합니다.

5분이면 준비 완료

다운로드부터 방송까지 — 시청자가 들어오기 전에 끝.

인코더 설정 때문에 골치 썩을 일 없습니다. SplitCam은 주요 플랫폼별 프리셋을 기본 제공합니다 — 스트림 키만 붙여넣고 '방송 시작'을 누르세요.

STEP 01
~ 1분
설치

Windows, Mac, iOS, Android에서 사용 가능. 데스크톱은 가벼운 설치, 모바일은 앱스토어에서 — 가입도, 카드도, 워터마크도 없습니다.

STEP 02
~ 2분
소스 추가

웹캠, 화면 캡처, 브라우저, 게임, 폰, 동영상 파일 중에서 선택하세요. 드래그하고 크기를 조절해 장면에 배치합니다.

STEP 03
~ 2분
플랫폼 연결

Twitch, YouTube, Facebook은 사전 설정되어 있습니다. 스트림 키를 붙여넣거나 사용자 지정 RTMP 주소를 추가하세요.

STEP 04
~ 5초
방송 시작

버튼 하나로 선택한 모든 스트림이 한 번에 시작됩니다 — 모든 플랫폼에서 동시에 라이브.

크리에이터들의 활용법

같은 프로그램, 여섯 가지 스튜디오.

"OBS + Restream 조합을 SplitCam 하나로 바꿨어요. CPU 부하가 줄고 방송마다 30분씩 절약했죠 — 앱 사이를 오갈 일이 없으니까요."

빠른 답변.

다운로드 전에 알아두면 좋은 모든 것.

SplitCam은 정말 무료인가요?

네, 개인 및 상업적 용도 모두 완전 무료입니다. 워터마크도, 사용 시간 제한도, 'Pro' 버전 결제 유도도 없습니다. 첫날부터 모든 기능이 열려 있습니다.

어떤 운영체제에서 사용할 수 있나요?

SplitCam은 Windows 10/11, macOS 11+, iOS 13+ (iPhone 및 iPad), Android 8+에서 사용할 수 있습니다. 다운로드 버튼이 사용 중인 운영체제를 자동으로 감지합니다.

OBS Studio 장면을 가져올 수 있나요?

네, SplitCam은 클릭 한 번으로 OBS 장면 모음을 가져옵니다. 모든 소스, 장면, 전환 효과, 단축키가 그대로 옮겨지므로 처음부터 다시 만들 필요가 없습니다. 둘을 비교해 보세요: SplitCam vs OBS.

몇 개의 플랫폼에 동시에 방송할 수 있나요?

8개 채널까지는 무리 없이 가능하며, CPU/GPU와 업로드 대역폭이 전체 부하를 감당하는 한 사실상 제한이 없습니다. SplitCam은 내 PC에서 각 플랫폼으로 P2P 방식으로 직접 스트림을 전송합니다 — 중간 클라우드 서버도, 제3자 서버도 거치지 않습니다. 내장된 업로드 속도 테스트로 방송 전에 연결 상태를 확인할 수 있습니다.

SplitCam을 켜면 게임이 느려지나요?

아니요, SplitCam은 기본적으로 하드웨어 인코더(Nvidia는 NVENC, Intel은 QuickSync, AMD는 AMF)를 사용합니다. 인코딩은 전용 GPU 칩에서 처리되므로 CPU와 주요 GPU 코어는 게임에 그대로 쓸 수 있습니다. 대부분의 사용자는 프레임 저하가 0~3%에 그칩니다.

Zoom/Teams에서 SplitCam을 가상 카메라로 쓸 수 있나요?

네, SplitCam은 전체 화면(장면, 효과, 오버레이, AI 배경 제거 포함)을 Zoom, Microsoft Teams, Google Meet, Discord 등 60개 이상의 앱에서 가상 웹캠으로 표시합니다. 세로(9:16)와 가로(16:9) 모드를 모두 지원합니다.

어떤 사양이 필요한가요?

최소 사양: Intel Core i3 / AMD Ryzen 3, RAM 4GB, 내장 그래픽. 게임 방송 권장 사양: Intel Core i5+ / AMD Ryzen 5+, RAM 8GB, NVENC/AMF를 지원하는 외장 그래픽카드. 오래된 노트북에서도 원활하게 작동합니다.

SplitCam이 제 데이터를 수집하나요?

장면, 녹화 파일, 스트림 설정은 모두 내 PC에 남습니다. 기기 간 설정 동기화를 위해 클라우드 프로젝트를 직접 켜지 않는 한, SplitCam은 클라우드에 아무것도 업로드하지 않습니다.
